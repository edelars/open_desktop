# Name and trademark

The code is AGPL-3.0-only, and commercial licenses are available from the copyright holder (see the repository README). The name "Open Desktop" and the logos are not covered by the AGPL. These rules say how the name and the mark may be used. They are a draft for the project's trademark policy and need a legal review before they are published as a policy.

## Writing the name

- "Open Desktop": two words, both capitalized, in running text and in the wordmark.
- Never "OpenDesktop", "Open-Desktop", "opendesktop" or "OD" in public copy. "od-" is only the prefix of crate names (`od-isa`, `od-jit`, `od-machine`).
- Don't make it possessive or plural in product copy. "The Open Desktop app", not "Open Desktop's app".
- The app's display name is "Open Desktop". Bundle identifiers and file names may use a lowercase form.

## Use without asking

- Refer to the project by name in articles, talks, reviews, benchmarks and package listings, as long as it is clear the text is not from the project.
- Use the unmodified mark to link to the official repository or site.
- Distribute unmodified builds of an official release under the name, for example in a package manager.
- Say a product "is based on Open Desktop" or "uses the Open Desktop engine" when that is true.

## Ask first

- Any modified build, fork or commercial distribution that wants to use the name or the mark. Forks rename themselves and replace the mark and the app icon.
- Merchandise, event names and domain names containing "Open Desktop".
- Use of the mark next to another company's logo in a way that suggests partnership.

## Never

- Change the mark, combine it with another mark, or use it for another product.
- Use the name or mark in a way that suggests the project endorses a product, service or person it does not.
