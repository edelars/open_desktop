# Logos

- `od-mark.svg`: the full mark for light grounds. Bars in ink #1A2240, middle bar in trace #2F52CC. 24 px and up.
- `od-mark-reverse.svg`: the full mark for dark grounds. Bars in #E8ECF7, middle bar in #8FA4FF (dark-theme ink and trace). 24 px and up.
- `od-mark-mono.svg`: single ink #1A2240 for one-color print, photos and trace fills. Recolor the file to the one ink you need.
- `od-mark-small.svg`: the simplified mark drawn on a 16 px grid for 16–23 px: menu bar, favicon, small app icon sizes. Ink #1A2240, trace #2F52CC.
- `od-app-icon.svg`: the macOS app icon master, 1024 px canvas with an 824 px body, grid fill, protocol grid and the full mark at 672 px (bars span 448 px).
