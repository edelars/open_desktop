## 1. Что уже известно

- Роадмап, этап 11, список «Реализовать»: «Выбранные классы USB, печать и дополнительные устройства после основного набора». Роадмап, раздел «В первую версию не включаем»: «все разновидности USB».
- Плата v0.1 ([VIRTUAL_BOARD.md](VIRTUAL_BOARD.md), строка «Ввод»): один стандартный PCI xHCI контроллер (класс `0C0330`, xHCI 1.2) с USB HID-клавиатурой и мышью. «Дополнительных USB функций в v0.1 нет.» В разделе «Не включено» перечислены Audio, USB passthrough, GPU, IOMMU, SMP, hot-plug и миграция, отдельными пунктами. Общее правило той же строки: «Добавлять по отдельным требованиям и этапам, а не ради полноты».
- Ввод гостя уже опирается на xHCI и HID: клавиши — USB HID usage ID ([STAGE_10.md](../plans/STAGE_10.md), S10-16, строка 394).
- Гостевой драйвер любого USB-класса и принтера — часть гостевой ОС (этапы 5, 7, 8). Без гостя проверяется только host-сторона контракта.

Вывод: сверх HID в плате USB-классов нет, а печать не имеет устройства в плате. Ниже — варианты и рекомендация, не принятое решение.

## 2. USB-классы

| Класс | В v0.1 | Почему (рекомендация) | Что нужно, если войдёт позже |
|---|---|---|---|
| HID (клавиатура, мышь) | Да, уже в плате | Ввод гостя | Ничего сверх плана ввода и `VIRTUAL_BOARD.md` |
| Mass Storage (накопитель) | Не рекомендуется | Загрузочный диск уже даёт NVMe-контроллер платы. Файлы между host и гостем — через общие папки (S11-26, гостевой драйвер S11-29) | xHCI bulk-transport, SCSI-команды поверх USB Mass Storage Class (Bulk-Only Transport), host-backend через `od-storage`; отдельный scope |
| Printer | Не рекомендуется | Устройства печати в плате нет; путь печати — §3 | См. §3 |
| Audio | Не рекомендуется | Звук — отдельная задача S11-40 (класс устройства, решение владельца) | Решается в S11-40, не по умолчанию через USB |
| Hub, Video, Smart Card, Serial, прочие | Не рекомендуется | Нет требования; каждый требует своего гостевого драйвера и host-устройства | Отдельный scope по запросу |
| USB passthrough (реальное устройство Mac в гостя) | Не рекомендуется | В `VIRTUAL_BOARD.md` — «не включено»; нужно отдельное решение и ADR | Отдельное решение и ADR |

Объём: для классов сверх HID в host-части v0.1 — ноль, если они не вводятся в плату. Для возможного Mass Storage — один xHCI-путь (bulk-transport), один host-backend и один гостевой драйвер вне этапа 11.

## 3. Печать: варианты и рекомендация

| Путь | Как устроен | Плюсы | Минусы и зависимости |
|---|---|---|---|
| **A. Сетевая печать (IPP) на host** | Гостевая ОС отправляет задание по IPP (RFC 8010 и RFC 8011; для печати без драйвера производителя — PWG IPP Everywhere, название из памяти исполнителя) на принт-сервер host (CUPS на macOS) | Не нужен USB и новое устройство платы | См. ниже: зависимости |
| B. USB-принтер (USB Printer Class, xHCI) | Виртуальный USB-принтер на xHCI; host передаёт задания в систему печати | Выглядит как настоящий принтер для гостя | Нужен xHCI-путь (как для Mass Storage), класс Printer, host-передача в CUPS; объём больше A |
| C. «Печать в файл» через общую папку | Гостевой «принтер» пишет PDF или PostScript в общую папку (S11-26); host открывает файл | Не требует сети и USB | Не настоящая печать на принтер. Нужен гостевой драйвер общих папок (S11-29, blocked до этапов 5/8); host-части, специфичной для печати, нет |

**Зависимости пути A (не покрыты текущим планом):**
- NAT: трансляция и TCP/IP, S11-31a…S11-31d. S11-31e — только замер NAT на loopback, не сам NAT.
- Сетевое устройство гостя: NIC, S11-32, блокер S4-30.
- Доступ гостя к CUPS на host. Гость должен достучаться до порта 631 на адресе host, который виден из NAT. Текущие задачи S11-31a…d этого не описывают. На macOS общий доступ к принтерам по умолчанию выключен — это настройка пользователя. Без этого путь A не работает.
- Гостевой IPP-клиент и драйвер принтера — этапы 5/8, вне этапа 11.

**Рекомендация (не решение):** путь A как целевой, если владелец подтвердит сетевой стек (решение по ADR-0008, которого ещё нет; задача S11-30) и способ доступа гостя к CUPS на host (§6, вопрос 4). Путь C — как проверочный путь для гостевой части, если понадобится проверка без сети. Путь B не рекомендуется: объём сопоставим с Mass Storage, а пользы для целевой аудитории сверх пути A не даёт.

Для кода: ни один путь не требует изменений в `od-machine` или `od-host` в v0.1, кроме запланированных сети (S11-30…S11-33) и общих папок (S11-26).

## 4. Что не входит в scope

- Гостевые драйверы USB-классов, принтеров и общих папок: гостевая часть, блокер этапов 5, 7, 8.
- Сертификация принтеров и совместимость с конкретными моделями.
- Hot-plug и USB passthrough реальных устройств Mac.
- Печать из гостевых окон (интеграция окон — отдельный scope, S11-50).
- Любой путь печати без явного подтверждения владельца по §3.
