# Требования гостевой ОС: предварительный срез

**Версия:** 0.4. **Дата:** 22 октября 2026 года. **Статус:** requirement inventory S0-03 завершён для выбранных Windows/Linux candidates; непроверенные media, boot path и устройства записаны с источником, владельцем и планом проверки.

Этот документ отделяет публичные требования платформ от требований конкретного установочного образа, устройств и сертификации. Он не заявляет о загрузке Windows/Linux или о совместимости Open Desktop. Локальный ISO найден и захеширован; edition/build metadata и часть драйверов статически проверены, но boot path и работа устройств не проверены запуском.

## Windows 11 Pro x64 26H2 — кандидат

Microsoft публикует для Windows 11 общий минимум: совместимый 64-разрядный CPU не менее 1 GHz и с двумя ядрами, RAM от 4 GB, накопитель от 64 GB, UEFI с возможностью Secure Boot, TPM 2.0, графика DirectX 12 с драйвером WDDM 2.0. CPU должен соответствовать политике совместимости и опубликованному перечню поддерживаемых процессоров; одних частоты и числа ядер недостаточно. Отдельно Microsoft документирует конфигурацию Windows 11 VM: поколение 2, диск от 64 GB, Secure Boot и vTPM в Hyper-V, память от 4 GB и не менее двух vCPU. Это референс для поддерживаемых Microsoft VM-платформ, а не спецификация нашего custom VMM или подтверждение совместимости с ним. Общий минимум и VM-референс не задают полный список инструкций/CPUID для произвольного x86-64 CPU.

Реальное поведение выбранного build всё равно нужно снять с образа; общая схема не заменяет эту проверку.

## Linux x86-64 для ранней отладки

Кандидатный дистрибутив и ISO указаны в матрице поддержки. Для минимального стенда предпочтителен прямой Linux/x86 boot protocol, отдельный от будущей UEFI-загрузки Windows. Целевой профиль ОС принят как Ubuntu Generic `amd64`. Нормативное прочтение только ABI/ISA floor — baseline x86-64 psABI (x86-64-v1); v2/v3/v4 не входят в цель. Ubuntu публикует для обычного `amd64` baseline без расширений сверх исходных 64-bit AMD/Intel CPU, а отдельно описывает `amd64v3`; это обосновывает floor, но не задаёт полный профиль исполняемого kernel/CPU.

Выбрана синтетическая versioned reference CPU target `od-x86-64-v1-neutral-v0.1`; её vendor string, CPUID values, feature policy и ограничения описаны в [CPU contract](CPU_CONTRACT.md#ubuntu-generic-amd64-od-x86-64-v1-neutral-v01). Это спецификация будущего diagnostic target, не реализованная capability и не подтверждение совместимости/загрузки ОС. Полный MSR allowlist, initial CPU state, runtime branches и execution manifest остаются открытыми. Требования config, upstream source reachability, exact Ubuntu source/binary и реально наблюдаемое исполнение — разные уровни доказательств; см. [решение baseline](../reports/STAGE_2_LINUX_PROFILE.md#решение-по-generic-amd64-baseline) и [матрицу S2-40a](../reports/STAGE_2_LINUX_PROFILE.md#s2-40a--матрица-требований-ubuntu-generic-amd64). Initramfs, command line, device/topology manifest и критерий успеха также не закрыты.

22 октября 2026 года статически проверены exact `7.0.0-38.38` amd64 metapackage, signed kernel package и buildinfo с официального Ubuntu archive. Их bytes разобраны в памяти без установки или запуска; SHA-256, version/config и header приведены в [отчёте S2-00 Linux profile](../reports/STAGE_2_LINUX_PROFILE.md). Это уточнение входных данных, а не приёмка загрузки или полного CPU-профиля C/D.

## Разделение обещаний и открытые проверки

- **Минимальные требования ОС** — опубликованные требования установщика/платформы; сами по себе не подтверждают работу гостя.
- **Техническая загрузка** — один проверенный образ до определённой стадии с сохранёнными логом, конфигурацией и образом.
- **Поддерживаемый профиль** — набор ОС, CPU, устройств и security features, для которого есть законченные проверки.
- **Сертификация и распространение** — отдельные требования владельцев платформ и каналов поставки; этот документ не объявляет их выполненными.

В ISO `iso/Windows11_Client_x64_en-us_26300_9457.iso` подтверждены Windows 11 Pro x86_64 (индекс 6 из 11 в `sources/install.wim`), en-US, version 10.0, base build 26300.9457. Microsoft указывает cumulative update KB5127648/build 26300.9711 от 13 октября 2026 года для Windows 11 26H2; [матрица поддержки](SUPPORT_MATRIX.md) различает базу ISO и target build после обновления. Владелец сообщил, что ISO получен из официального канала Microsoft; URL и дата загрузки не сохранены, поэтому происхождение установлено по сведениям владельца, но не проверяется независимо. ISO штатно подключается в macOS в режиме read-only. До реализации guest boot остаётся проверить требования установщика/bootloader на выбранном build, завершить фактическую проверку драйверов и подготовить initramfs с хешем. CPU/board-профили остаются проектными до этих испытаний.
