# S3-20dj — exact address64 SIB dword loads with signed disp32

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `b395ff6` adds exactly four seven-byte singleton forms:
`8B 84 0B id`, `8B 84 4B id`, `8B 84 8B id`, and `8B 84 CB id`
(`MOV EAX,[RBX+RCX*1/2/4/8+signed disp32]`). The decoder-owned
`access_address_48` calculation combines full-width RBX and RCX at the encoded
SIB scale with signed disp32. Each checked read is four bytes; it writes EAX,
zero-extending into RAX and clearing `RAX[63:32]`. The guest boundary is
`A+7`.

The JIT fixture checks source/site identity across all four scales and the
four encoded displacement bytes for representative signed boundary and
positive/negative values. It checks the PC-map boundary. Host comparisons
cover ordinary interpreter parity, canonical-end `#GP`, u64 range overflow,
and a valid adjacent read ending at the canonical boundary. The two distinct
fault cases produce no read callback, guest-state commit, or retirement.
STOP and budget gates are covered. Three stale disp32-rejection negative cases
were removed from the existing S3-20dd/S3-20df/S3-20dh JIT fixtures because
the newly admitted disp32 forms are covered by this separate profile; their
exact prior positive JIT gates remain passing.
