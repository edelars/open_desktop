# S3-20dp — exact address-size-32 SIB Dword loads with signed disp32

**Status:** bounded partial implementation evidence; S3-20 and Stage 3 remain
open.

Runtime commit `45dedae` adds exactly four eight-byte typed-IR load singletons:
`67 8B 84 0B id`, `67 8B 84 4B id`, `67 8B 84 8B id`, and
`67 8B 84 CB id`, encoding
`MOV EAX,[EBX+ECX*1/2/4/8+signed disp32]`. Effective-address calculation
uses the decoder-owned address-size-32 operand: low32 EBX plus low32 ECX times
the selected scale plus signed disp32, wrapped to 32 bits and zero-extended
before canonical checking. High halves of RBX and RCX are ignored. Each access
is a contiguous checked four-byte read; writing EAX zero-extends into RAX. The
guest boundary is `A+8`.

JIT source/site checks cover the four scales and all disp32 source bytes,
including mutation rejection; PC-map, fault, STOP, and budget cases are
bounded to this exact profile. No broader addr32 SIB load family is claimed.
