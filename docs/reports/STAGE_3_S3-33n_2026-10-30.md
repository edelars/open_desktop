# Stage 3 S3-33n — composed `NativeRegisterV1`

**Status:** bounded implementation, independent code review, targeted checks,
and the full local suite are recorded. No hardware, performance, or Mini result

## Scope

Add one opt-in uncached `NativeRegisterV1Admission` and eager / demand-flags-
candidate compile and dispatch path. Its accepted language is the restricted
S0-09 baseline, the existing admitted bare NOP interpreter fallback, and only
the exact native forms committed by S3-33a–m:

| Form | Exact bytes |
|---|---|
| `INC RAX` | `48 FF C0` |
| `DEC RAX` | `48 FF C8` |
| `NEG RAX` | `48 F7 D8` |
| `NOT RAX` | `48 F7 D0` |
| `ADD RAX,sign-extended imm8` | `48 83 C0 ib` |
| `CMP RAX,sign-extended imm8` | `48 83 F8 ib` |
| `SUB RAX,sign-extended imm8` | `48 83 E8 ib` |
| `MOV RAX,sign-extended imm32` | `48 C7 C0 id` |
| `XCHG RAX,RBX` | `48 87 D8` |
| `LEA RAX,[RBX]` | `48 8D 03` |
| `LEA RAX,[RBX+disp8]` | `48 8D 43 db` |
| `LEA RAX,[RBX+RCX]` | `48 8D 04 0B` |
| `LEA RAX,[RIP+disp32]` | `48 8D 05 dd dd dd dd` |

The composed admission must construct one whole-code exact admission and
instruction-boundary map. Branch targets are accepted only at decoded starts
or exclusive code end; targets in any instruction interior are rejected even
when predecessor lengths vary. The admission retains decoder-owned operands
and exact source bytes. Only bare NOP may route through the established
interpreter fallback. Existing S3-33a–m admission and API behavior remains
unchanged; this slice adds no other form, width, register, prefix, memory data
operation, cache path, ABI change, or default-profile broadening.
