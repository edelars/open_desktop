# S3-20db — exact address-size-32 disp8 dword checked-memory store

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `1ff9c17` adds only the exact four-byte singleton `67 89 43 ib`
(`MOV [EBX+signed disp8],EAX`) to the shared typed-IR dword-store path. The
decoder-owned address-size-32 calculation wraps the signed displacement and
zero-extends the effective address. The store uses low32 RAX for one
contiguous checked four-byte write, and its instruction boundary is `A+4`.

The JIT contract binds all 256 signed-disp8 source values to their site. The
recorded fixtures also cover STOP, budget, fault, PC-map, and no-replay paths;
these checks do not open other addr32 store forms.
