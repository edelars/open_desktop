this is test-only and does not add a general framework or change production
validation. The test warms a `MOV RDX,imm64` block and its executable alias,
plus an unrelated cached entry. The existing committed store writes a new
immediate into the guest code backing and delivers the backing-generation
notification.

interpreter step over the full CPU state, bytes for every backing, and all
backing generations. It also records four invalidated prefix/tail entries
across the two guest aliases and confirms the unrelated entry remains reusable
without another publication. The test-only comparator classifies a controlled
old-immediate result as `StaleCodeResult` and a corrupted code backing version
as `BackingGenerationMismatch`.
