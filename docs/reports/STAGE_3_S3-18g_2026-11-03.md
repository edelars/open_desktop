# Stage 3 S3-18g: dependency-generation invalidation for retained Load→Load

Status: focused local ARM64 acceptance passed. Stage 3 remains partial; Mini
and stage-wide checks were not run.

## Scope

Extended the existing exact `MemoryPairProfile::LoadThenLoad` host regression.
After a resident entry is published, the caller advances only the dependency
backing version while keeping the execution-context generation and code bytes
unchanged. The test checks a replacement miss, compile and publication, one
resident replacement, and successful execution with new backing values. It
then calls again under the new dependency version with different CPU state,
RAM values, and access context; this call must hit the replacement entry.

Both executions are compared with the interpreter for complete
`LongModeState`, retired instruction count, and ordered memory callback records.
The expected load values and addresses are also asserted directly. The existing
cache path performs `clear()` before requesting publication on a replacement;
the regression proves the retained handle can be replaced and the fresh entry
can execute on this ARM64 host. This is limited to the current synchronous
fixture cache and does not add owner/MMU behavior, a profile or cache policy, or
a performance claim.

The Stage 3 harness now pins the new exact od-host test as
`s3_18g_load_load_dependency_generation_republishes`. Its self-check rejects a
missing or altered gate, bad invocation metadata, missing/zero-match result
evidence, and an omitted or altered manifest gate. Adding this gate changes
current harness totals to 325 Rust gates (307 local acceptance and 18 local
lifecycle), 343 local steps, and 150 harness self-tests.
