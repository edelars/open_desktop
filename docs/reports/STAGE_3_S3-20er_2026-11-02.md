# S3-20er: exact scaled RCX-indexed no-base SIB disp32 Dword loads

## Scope and semantics

This runtime slice admits only the exact seven-byte unprefixed Dword-load
singletons `8B 04 4D disp32`, `8B 04 8D disp32`, and `8B 04 CD disp32`
(`MOV EAX,[RCX*2|4|8+disp32]`). The address64 SIB has no base and uses RCX
as its index at scale 2, 4, or 8. The decoder-owned effective address uses
full-width RCX multiplied by the encoded scale, plus sign-extended disp32,
with wrapping u64 arithmetic. Each checked read is one contiguous four-byte
access; EAX zero-extends into RAX, and the guest instruction boundary is
`A+7`. Other prefixes, SIB scales, and encodings remain outside this exact
admission.

The exact JIT fixture is
`memory_load_v2::tests::ir_dword_rcx_index_no_base_sib_scaled_disp32_load_binds_all_source_bytes_to_its_site`.
The exact host fixture is
`tests::s3_20er_rcx_index_no_base_sib_scaled_disp32_dword_load_uses_full_width_scaled_index`.
These exact gates are pinned by S3-34cc; neither runtime gate was executed for
this slice.
