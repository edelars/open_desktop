# S3-33l: Exact native LEA RAX,[RBX+RCX]

## Scope

This slice admits only the uncached exact instruction bytes `48 8D 04 0B`: W64/address64, RAX destination, RBX base, RCX index, scale 1, displacement 0, length 4. The existing no-displacement and disp8 LEA profiles remain separate. Stage 2, owner/MMU, Mini, and performance work are outside this slice.

Lowering reads RBX and RCX before writing RAX, computes a W64 Add with `Preserve` flags, writes RAX, and emits one instruction commit. It does not access guest data memory or invoke a helper. Address values are ordinary operands; no canonicality check is part of LEA.
