# S3-20ct — exact dword checked-memory store with disp8

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `9b2b4ce` adds only the three-byte singleton `89 43 ib`
(`MOV [RBX+disp8],EAX`) to the shared typed-IR dword-store path. The decoded
memory operand supplies the signed displacement and effective address from
full-width RBX. The checked helper writes exactly the low four bytes of EAX;
the guest RIP and retirement commit after a successful write, then STOP is
observed. The exact source/site descriptor includes the three source bytes,
RBX base, dword operand and `A+3` continuation. All 256 disp8 byte values keep
their corresponding source/site identity.

This is a single checked-memory store form. The existing `89 03` (S3-20co)
and `89 00` (S3-20cq) identities remain separate. The slice does not broaden
the dword-store family or establish production owner/MMU, SMC, cache,
dispatcher, Mini, M1, Stage 2, physical-x86 or performance behavior.
