# Stage 3 S3-20bx: address32 no-base SIB with RSI/RDI index and disp32

Implemented the exact singleton qword MOV form `67 48 8B/89 /r sib disp32`: ModRM `mod=00/rm=100`, SIB base field `101` (no base), index RSI or RDI, scale 1/2/4/8, data RAX..RBP, length 9. Effective address remains decoder-owned through `MemoryOperand::access_address_48`: `(low32(index)*scale + signed disp32) mod 2^32`, zero-extended for the qword transfer. There is no base or RIP contribution, and the full RSI/RDI register is preserved.

The checked block builder, direct V2 compiler, shared IR verifier, runtime matcher, and bounded dispatcher now admit this exact profile. The runtime consumes decoder-built operand metadata and does not re-decode the displacement. Other prefixes, data/index forms, pair sequences, V3, and production owner/MMU integration remain outside scope.

## Evidence

- JIT descriptor matrix covers load/store × six data registers × RSI/RDI × four scales × signed disp32 values `MIN, -1, 0, 1, MAX`. It checks direct V2/shared IR descriptor equivalence, source match, decoded operand/width/length/next-RIP metadata, and windows 1..8 plus invalid neighbors.
- Host direct V2/shared IR/interpreter matrix checks full CPU/RAM parity, independently computed EA, callback address/width/count, and retirement. It covers high-half truncation, multiplication/addition wrapping, a contiguous qword callback crossing 4 GiB, and artifacts differing only in the final displacement byte.
- Host fault and guard cases cover architectural and backend failures without commit, successful store+STOP with exact payload, and STOP/stop-RIP/zero-budget entry guards.
- The bounded dispatcher test resumes at the actual end of the 9-byte singleton, then interprets a bare NOP and executes the frozen two-site pair; assertions verify retirement counts, final RIP, callback counts, and no repeated first read. Partial windows and an invalid no-index/non-unit-scale neighbor return without publication or memory effects.
