# S4-23e — atomic single-slot deadline replacement

## Result

Added a crate-private `EventQueue::replace_single` operation for an exclusively
owned queue with capacity one. A successful arm, rearm or cancel advances the
queue generation. This lets an owner reject a deadline that was extracted
before a later reprogramming, even when the same slot is reused.

The operation validates the expected generation, capacity and generation
overflow before changing the pending entry or sequence. The public EventQueue
API and existing multi-event scheduling behavior are unchanged. This is a
prerequisite for a Local APIC timer owner; it does not implement APIC registers,
clock ownership, timer dispatch, IRQ delivery or HLT wakeup.
