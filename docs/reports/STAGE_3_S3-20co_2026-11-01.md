# S3-20co — exact dword checked-memory store

**Status:** bounded implementation slice committed; S3-20 and Stage 3 remain
open.

Commit `38c5e4a` adds one exact checked-memory singleton through shared typed IR:
unprefixed `89 03` (`MOV [RBX],EAX`). The transfer is dword-width, the source is
the low 32 bits of EAX, and the decoded operand remains the source of memory
semantics. This is a narrow extension of the existing checked-memory path; it
does not add other dword stores, address forms, multi-instruction blocks, or a
general memory-lowering policy.

This boundary follows the architecture's placement of CPU/JIT implementation
in the Rust engine and localization of unsafe memory operations, with the JIT
contract's exact-shape checked-memory entries as the precedent for bounded
admission ([architecture](../ARCHITECTURE.md), [JIT contract](../specs/JIT_CONTRACT.md)).
The contract's existing qword profiles remain distinct from this added dword
fixture; this report does not claim a broad contract expansion.
