# S3-20fr: RCX-base Dword load signed disp8 `8B 41 ib`

## Scope and semantics

This slice admits exactly the three-byte form `8B 41 ib`
(`MOV EAX,[RCX+sign_extend(ib)]`): Dword operand, Qword address size, no
prefix, index, or SIB. The effective address is the full original RCX plus
the signed 8-bit displacement, wrapping modulo 2⁶⁴; ECX is not used. The
operation performs one contiguous checked four-byte read. The value
zero-extends into full RAX; RCX, other GPRs, RFLAGS, and RAM remain unchanged;
successful retirement advances RIP to `A+3`.

Canonicality and range preflight apply to the computed EA and the complete
read range. Existing guest/backend faults, entry guards, retry, and callback
STOP without replay remain part of the contract. RCX disp32, addr32, RDX-base,
other destinations, prefixes, and SIB forms are outside this slice.

## Implementation and coverage

The implementation adds exact compiler metadata, a separate
`CheckedDwordLoad` literal-byte gate, decoded/IR/runtime length3/i8 address
profiles, and exact source/site binding. Existing `[8B,00]` and `[8B,03]`
forms remain supported as distinct sites. The previously rejected
`[8B,41,00]` and `[8B,41,FF]` forms are admitted as successful compilations;
source/site mismatch checks bind them to their corresponding original forms.

Harness totals after this slice: 284 Rust gates (274 acceptance and 10

checked against the Rust test definitions and argv.

The host fixture covers signed displacement edges, full RCX versus a
low32 decoy, zero and unaligned effective addresses, canonical upper-half
addresses, wrapping arithmetic near `u64::MAX`, and rejection of a noncanonical
computed EA or overflowing full read range before the read callback. Faults
preserve state and have retry coverage; each entry guard has a successful
retry case; callback STOP has no read replay. The JIT fixture binds all 256
displacement bytes, checks signed metadata and the `A+3` PC-map boundary, and
rejects forged site metadata. These are implemented test cases; execution is
deferred as recorded below.

## Status and verification limits

Runtime implementation commits `b23f01b` and `0f2d87c`, plus harness commit
`2efd760`, are integrated. Runtime and harness both passed independent
Sol/high review. The host-fixture follow-up in `0f2d87c` corrected direct
propagation of errors while fetching the displacement byte. The pinned
identities and totals above match the implemented tests and harness.

Behavioral checks, builds, formatting, Cargo checks, and Python harness checks
remain deferred until the end of Stage 3. Mini checks are deferred until the
end of Stage 3, and the M1 regression was deferred by the user. This scope
does not include Stage 2 or production owner/MMU integration.
