# S3-20el: exact absolute SIB disp32 Dword load

## Scope and semantics

This runtime slice admits only the seven-byte unprefixed singleton `8B 04 25 id` (`MOV EAX,[disp32]`): SIB with no base or index, scale 1, Qword address size, and Dword transfer. The decoder-owned signed disp32 forms the 64-bit absolute effective address; displacement `-4` therefore resolves to `u64::MAX-3`. The checked operation reads exactly four bytes, writes EAX with zero-extension into RAX, and has the single guest boundary `A+7`. Other prefixes and neighboring encodings remain outside this admission.

The exact JIT identity is `memory_load_v2::tests::ir_dword_absolute_sib_disp32_load_binds_all_source_bytes_to_its_site`. Its fixture covers nine signed disp32 representatives, exact source/site binding for all displacement bytes, forged metadata, and rejected neighboring encodings. The exact host identity is `tests::s3_20el_absolute_sib_disp32_dword_load_uses_signed_absolute_address`. Its fixture checks the `-4` address and one width-four read, EAX zero-extension with RBX and RFLAGS preserved, entry STOP/budget without memory access, read-error state atomicity, `-3`/`-2`/`-1` range faults before callback, callback STOP after commit, and retry rejection without a second read.
