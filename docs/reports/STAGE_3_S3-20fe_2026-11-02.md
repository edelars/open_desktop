# S3-20fe: address32 scaled RAX-indexed no-base SIB Dword store

## Scope

This bounded runtime slice admits the eight-byte forms
`67 89 04 45/85/C5 disp32` for addr32 Dword stores at SIB scales 2, 4, and
8. The effective address uses the original low 32 bits of RAX:
`zero_extend_64((low32(original RAX) * scale + sign_extend(disp32)) mod
2^32)`. Both multiplication and addition wrap at 32 bits. The store payload
is low32 of that same original RAX. One contiguous checked four-byte write
is performed, other GPRs and RFLAGS are preserved, and successful retirement
commits `A+8`. Effective-address wrap does not wrap the bytes of a transfer
that crosses 4 GiB.
