# S3-20dn — exact address-size-32 SIB dword loads with signed disp8

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `a8309cf` adds exactly four five-byte singleton forms:
`67 8B 44 0B ib`, `67 8B 44 4B ib`, `67 8B 44 8B ib`, and `67 8B 44 CB ib`
(`MOV EAX,[EBX+ECX*1/2/4/8+disp8]`). The decoder-owned address-size-32
effective address adds low32 EBX, low32 ECX multiplied by the selected SIB
scale, and signed disp8; it wraps to 32 bits and zero-extends before canonical
checking. Each checked load is one contiguous four-byte read. Writing EAX
zero-extends into RAX. Exact source/site binding covers all four scales × all
256 signed disp8 values, with PC-map boundary `A+5`. Fixtures cover atomic
faults, STOP, and budget behavior.
