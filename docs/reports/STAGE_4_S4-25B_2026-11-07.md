# Stage 4 S4-25b: CPU-owned IA32_APIC_BASE enable

S4-25b adds the opt-in `od_isa::msr::ApicBaseCpu` profile for bare
`RDMSR`/`WRMSR` to `IA32_APIC_BASE` (`0x1B`) in Long64/CPL0. Its reset value
is `0xFEE00900` (fixed xAPIC base `0xFEE00000`, BSP set, global enable set).
The supported disabled value is `0xFEE00100`. `RDMSR` returns the value in
EDX:EAX. A successful `WRMSR` retires once and returns a typed
`ApicBaseEffect`. The machine-level `step_apic_base_msr` checks CPU/device
state consistency, executes one instruction and applies a retired write to
the `LocalApicHandle` before returning. Same-value writes preserve APIC
state. Disabling resets the local APIC, blocks its MMIO and acknowledge
operations, and re-enabling leaves it software-disabled until SVR is enabled.

Reserved low bits and physical-address bits above the fixed 36-bit profile
fault with `#GP(0)`. Values outside the profile's fixed supported values,
including relocation, BSP changes and x2APIC enable, fail closed without
retirement. The profile rejects an active STI shadow before fetch, and
unrelated invalid decoder forms remain outside its instruction contract.

The architectural basis is Intel's [64 and IA-32 Software Developer's Manual, release 093, Volume 3A](https://cdrdv2-public.intel.com/v1/dl/getContent/671190), §§13.4.3–13.4.5 and 13.4.7.1–2. The selected fixed profile uses the documented option that disabling the global APIC enable may lose initialization state. Software disable through SVR remains distinct and retains pending/service state.

## Limits

This profile is explicitly selected and does not change the existing general
MSR profiles. `ApicBaseCpu::step` returns a write effect for the caller to
apply before the next guest or device operation; `step_apic_base_msr` provides
that synchronous ordering for the fixed xAPIC device. The feature is not
integrated into `PagedVcpuSession` or default board wiring. APIC base
relocation, BSP changes, x2APIC, APIC Version/LVT, IOAPIC, timer, CPU
interrupt delivery, IF/IDT/handler behavior, HLT wakeup and Linux discovery
remain outside the slice. Parent S4-25 and Stage 4 remain open.
