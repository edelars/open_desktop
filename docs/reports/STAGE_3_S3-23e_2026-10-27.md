# S3-23e — Region-scoped executable-write notification and redispatch

**Status:** bounded fixture implementation; independent review pending. Physical Mac Mini checks remain deferred to the final Stage 3 gate.

## Implemented slice

A separately supplied code-region stamp lets the tracked fixture owner identify a committed executable-backing write that overlaps cached code, even when the current V2 artifact is only the standalone three-byte `MOV [base], r64` store. After the generated call returns and its result is decoded, the owner advances the backing version, applies the existing `CodeInvalidated` result to cache dependencies, and requires redispatch before another lookup. The committed store is not replayed.

The region must end exactly at the store's `next_rip`, so it covers only the already executed prefix plus the committing store, never a future tail. Before permitting overlap with that region, the owner separately rejects writes that overlap the store artifact's own source bytes, using backing-relative ranges so direct mappings and guest aliases are both covered.

The native/interpreter test warms prefix and tail artifacts at both guest mappings of one backing. The store updates the already completed immediate prefix. It checks exactly one write, the committed store RIP/retirement and full CPU/RAM parity against the interpreter checkpoint, removal of all four dependent cache entries, fresh tail execution, and fresh source execution through both aliases.

## Boundary

The prefix, store, and tail are separate compiled entries. No native tail is active during the store, and this does not implement S3-24 current-block retirement or claim stale-host-tail suppression. It demonstrates inter-entry code coherence and redispatch only. The bounded fixture is not a production MMU, DMA, MMIO, asynchronous writer, or SMP implementation. Intel SDM Vol. 3A (Order No. 253668-082US, December 2023) §9.1.3 describes the store, control transfer, then execution sequence; this slice implements only the notification/redispatch prerequisite ([official PDF](https://cdrdv2-public.intel.com/812386/253668-sdm-vol-3a.pdf)).
