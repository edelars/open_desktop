# S3-34cn: exact harness gates for S3-20fc addr32 RAX-indexed Dword store

## Scope

This harness slice pins the JIT source/site and host acceptance identities for
the eight-byte addr32 no-base SIB Dword-store form
`67 89 04 05 disp32` (`MOV [low32(RAX)+sign-extended disp32],EAX`). The exact
JIT identity is
`memory_load_v2::tests::ir_dword_addr32_rax_index_no_base_sib_disp32_store_binds_all_source_bytes_to_its_site`;
the host identity is
`tests::s3_20fc_addr32_rax_index_no_base_sib_disp32_dword_store_uses_wrapped_eax_address_and_low_dword_data`.
Their harness gate IDs are
`s3_34cn_ir_addr32_rax_index_no_base_sib_disp32_dword_store_source_binding`
and
`s3_34cn_host_addr32_rax_index_no_base_sib_disp32_dword_store_eax_address_and_data`.

The self-check verifies exact IDs and identities across gate registries,
manifest, invocation, and required-evidence validation. It rejects missing
gates and missing, ignored, failed, zero-match, or wrong-identity evidence.
This report describes harness pins and static review only.
