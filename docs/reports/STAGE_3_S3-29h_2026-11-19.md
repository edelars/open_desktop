# S3-29h native cached flags preflight

The stock signed ARM64 release from `8cdac54` passed the composed
NativeRegisterV1 preflight on Apple M1 Pro, macOS 14.6.1, with Rust
1.99.0. It rechecked 1,200 stored interpreter observations and passed
2,400 full-state comparisons with eager and demand flags. The ordered
input digest was `fnv1a64:172fb17b01c502df`. The input file SHA-256 was
`3fddc5c753f3d2884850468480ec68d13a6069d1aed16e8973e1acef56ffac1f`.
The benchmark ran under UID 501 at nice −5.

The demand variant published 14.3% more code on first dispatch and
13.1% more on second dispatch. These are cumulative byte counts from
correctness preflight. The second dispatch may compile and replace a
block in the one-entry cache.

## Local ARM64 preflights

Two bench-only patches on the same stock revision passed signed local
release preflights. Their exported source directories lacked Git metadata.
The archive records each exact patch, changed source hashes, build
messages, signature checks, and raw results.

- The split-window driver matched every stock per-case baseline,
  including both modes and both strategies across all 1,200 inputs.
  It can run one of the original measurement modes per process.
- The retained FIFO16 driver passed seven fixtures per strategy,
  including STOP and budget exits and a publication witness for the
  selected flags mode. In each strategy, the four-case subset published
  four blocks and registered 15 prewarm hits. Its untimed repeat made
  four dispatch calls, retired 41 native instructions in 19 blocks, and
  recorded 19 hits, zero misses, compilations, publications, evictions
  and interpreter retirements.

## Timing disposition

All four combined-mode attempts on the M1 Pro were rejected by the
host-load gate. The lowest overlapping idle probes were 73.6%, 72.9%,
73.3% and 72.8%, below the 80% floor. The attempt data remained on the
M1 Pro when SSH became unavailable. All three archived JSON preflights
report `timing_started=false`. S3-29 still needs accepted latency
measurements to select a flags strategy.

## Reproduce

Use clean `8cdac54e755a12e329ea491aa3baaeac3dadefb0` and the composed
inputs identified above. The stock preflight runs
`od-bench cached-native-flags-compare --corpus <corpus> --preflight-only --output <json>`.
For each local patch, apply its archived diff to a separate copy of the
same revision and build the specified binary from package `od-bench`
with `--release --offline --locked --target aarch64-apple-darwin` and
`MACOSX_DEPLOYMENT_TARGET=14.0`. Sign with Hardened Runtime and
`apps/vmhost/Configuration/vmhost-smoke.entitlements`.
