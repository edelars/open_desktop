## Workload and correctness

Both variants use the same ordinary `run_multi_cached` dispatcher and
prepared admission. Each variant fills its own FIFO16 cache via the normal
miss and publication path. The allocator choice applies at miss compilation.
The timed sides repeat the original five-case sweep order and measure the
warm dispatch calls, including resident lookups. Cold fill, fixture state
reset and validation are outside those call intervals. Each complete
side recorded 655,360 cache hits, zero misses, compiles, publications and
evictions, and five resident blocks. [Original warm workload](STAGE_3_S3-36l_2026-11-19.md)

The signed preflight matched each variant's full state, `CodeEnd` exit,
retirement and budget against the interpreter in all five cases. Cold
resident code measurements matched the emitted-size reference for every
block. The pressure block used 3,052 bytes with fixed homes and 3,064
with strict reuse. Total resident code was 7,500 and 7,512 bytes,
respectively. Both variants used 17,641 bytes of resident metadata and a
65,536-byte reserved arena. Previous static analysis attributed 33
allocator transfer sites to fixed homes and 20 to strict reuse in the
pressure block. [Static attribution and pending-flags checks](STAGE_3_S3-30d_2026-11-20.md)
