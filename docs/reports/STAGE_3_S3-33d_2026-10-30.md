# S3-33d — exact native ADD RAX, sign-extended imm8

## Scope and result

This slice adds an opt-in, uncached native path for exact bare `48 83 C0 ib`
(`ADD RAX, sign-extended imm8`). `S0_09NopAddRaxImm8Admission` admits all 256
immediate-byte values after cross-checking the decoder's sign-extended
`Operand::Immediate(u64)` against each source byte. Admission computes the
signed-byte value for that validation; lowering uses the stored decoder result
without recalculating it. The generic baseline and
INC/DEC/NEG admissions remain operation-specific. No Stage 2, `od-machine`,
owner/MMU, shared-cache, or default-policy changes were made.

Lowering reads RAX, uses the decoder-owned immediate as a W64 constant, emits
W64 `Add` with full `FlagEffect::Arithmetic`, writes RAX, and commits once.
Eager and demand-flags compile/dispatch APIs reuse existing IR, emitter, helper,
and pending-flags contracts. No performance claim is made.

The admission test exhaustively cross-checks `00..FF` source bytes against the
decoder's sign-extended values, and checks rejected neighbor encodings,
cross-operation admission isolation, and branches into the immediate. The
lowering test checks `00`, `01`, `7F`, `80`, and `FF` produce
the correct W64 constant and exact Add/flags/write/commit order. The compiler
test checks both strategies and a following JZ in the PC map. The host test
compares full state and retirement with the interpreter at zero, one,
`u64::MAX`, signed extrema, AF/PF edges, both incoming CF values, and DF/non-
arithmetic bits. Its CMP→ADD→JZ/JNZ cases have distinct taken/fallthrough state
changes, and the predecessor CMP flags are opposite to the ADD flags in each
case. The demand-candidate PC-map witness sees pending flags at the JZ
consumer; a successor ADD exercises the following full writer. Candidate
budgets and STOP before ADD, before JZ, and before the successor writer are
compared with the interpreter. Existing INC, DEC, and NEG host regressions
passed.

## Boundaries

Host execution covers signed immediate boundary bytes and representative
arithmetic states, while all 256 immediate bytes are exhaustively checked at
admission. Physical-x86 parity, Mini, performance, and full Stage 3 corpus
checks have not been run; Mini and performance remain deferred to the end of
Stage 3. Independent review identified and then cleared the branch-test
coverage, sign-extension wording, branch-target, and S3-33c documentation
findings. Targeted re-review completed with no remaining findings.
