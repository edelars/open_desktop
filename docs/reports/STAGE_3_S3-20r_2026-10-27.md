# S3-20r — Address32 no-displacement SIB in shared IR and bounded dispatch

## Scope

The borrowed memory path admits exactly `67 48 8B/89 /r sib`: ModRM
`mod=00,r/m=100`, RAX..RBX data/base/index encodings, SIB scale 1/2/4/8,
qword data, dword address size and exact length five. Address32 direct disp8
(`mod=01`), 64-bit SIB without `67`, and displacement-bearing SIB are separate
shapes. No-index/no-base specials, RSP/RBP or extended fields, extra prefixes,
and trailing bytes remain unsupported. The 9-byte address32 SIB disp32 source
is rejected by the fixed eight-byte source storage bound. The decoder's
`MemoryOperand` and `access_address_48` remain the only address/truncation,
wrapping, canonicality and contiguous qword-range semantics. No emitter, pair
profile, Stage2 or production owner changes were made.

## Evidence

- `od-jit` metadata tests enumerate both MOV directions and every supported
  data/base/index/scale combination, assert the decoded descriptor and exact
  source binding, and reject forbidden fields, displacement, prefix and tail
  shapes.
- Native direct V2, shared IR and interpreter compare full state and RAM for
  both operations across the complete register/scale matrix. Callback logs
  verify one qword access at the decoder-derived address. Inputs include
  ignored upper register halves, base/index aliasing, wraparound modulo
  2^32, and qword accesses crossing from `0xffff_fffc` into the next 4 GiB
  range without per-byte address wrap.
- Architectural load/store faults preserve exact payload and CPU/RAM/budget/
  retirement across direct V2, shared IR and interpreter. Backend errors stay
  host errors. A successful store followed by STOP preserves the committed
  bytes and retirement.
- Bounded dispatch composes address32 SIB → bare NOP fallback → existing pair
  for budgets 0..4, tests pre-entry STOP/stop-RIP/budget guards and partial
  windows, and resumes from the actual RIP without repeating the initial SIB
  access. Invalid no-index SIB is Unsupported without publication or memory
  effects.

## Validation

Focused checks passed:

- `cargo test -p od-jit --offline ir_address32_sib_no_displacement_has_exact_qword_descriptor`
- `cargo test -p od-host --offline v2_address32_sib_mov_matches_direct_ir_and_interpreter`
- `cargo test -p od-host --offline bounded_dispatch_composes_rip_relative_nop_and_pair_with_actual_rip_continuation`

Full `od-jit` passed 139 tests. Full `od-host` passed 67 unit and 12
integration tests; 2 environment-driven tests were ignored. Formatting,
`cargo check --workspace --all-targets --offline`, and
`cargo check --offline --target x86_64-unknown-linux-gnu -p od-host -p od-jit`
passed. The Linux check reports six existing dead-code warnings in the host
mapping/arena implementation. `graphify update .` and `git diff --check`
passed; changed-document links were checked. `python3 tools/check_layout.py`
did not pass: it reports `.git` as an unmapped root entry and two missing
historical Stage2 manifest targets referenced from the unchanged
`docs/reports/STAGE_2_REPORT.md` (`work/stage2-oracle/.../manifest.json` and
`work/stage1-oracle/.../manifest.json`). The Stage2 report, fixtures and tools
were not modified.

This is local ARM64 fixture evidence; production owner/MMU integration,
physical x86 verification, Mini measurements, and performance evidence remain
open. Independent review found no execution defects. Its only comment nit—a
negative-test comment describing a truncated no-base SIB as RBP-based—was
corrected and independently confirmed. Review closed with no open findings.
