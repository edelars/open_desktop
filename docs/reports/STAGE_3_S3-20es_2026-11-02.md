# S3-20es: exact scaled RCX-indexed no-base SIB disp32 Dword stores

## Scope and semantics

This runtime slice admits only the exact seven-byte unprefixed Dword-store
singletons `89 04 4D disp32`, `89 04 8D disp32`, and `89 04 CD disp32`
(`MOV [RCX*2|4|8+disp32],EAX`). The address64 SIB has no base and uses RCX
as its index at scale 2, 4, or 8. The decoder-owned effective address is
full-width RCX multiplied by the encoded scale, plus sign-extended disp32,
with wrapping u64 arithmetic. Each checked write is one contiguous four-byte
access containing low32 RAX; the guest instruction boundary is `A+7`. Other
prefixes, SIB scales, and encodings remain outside this exact admission.

The exact JIT fixture is
`memory_load_v2::tests::ir_dword_rcx_index_no_base_sib_scaled_disp32_store_binds_all_source_bytes_to_its_site`.
The exact host fixture is
`tests::s3_20es_rcx_index_no_base_sib_scaled_disp32_dword_store_uses_full_width_scaled_index`.
Harness S3-34cd pins both exact identities.
