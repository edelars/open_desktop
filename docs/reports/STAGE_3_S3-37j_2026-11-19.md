# S3-37j FIFO16 churn and process RSS on M1 Pro

The signed ARM64 release from clean `8cdac54` ran `cache-churn` on the
Apple M1 Pro with macOS 14.6.1 and Rust 1.99.0. The runner verified the
recovered S3-17 pathname list, exact historical trace and all 1,010
fixtures. Each of the three processes kept one FIFO16 runtime for
128 complete sweeps.

| Per process | Count |
| --- | ---: |
| Input calls | 129,280 |
| Native block executions | 169,216 |
| Guest instructions retired | 382,720 |
| Cache hits | 256 |
| Misses, successful compilations and publications | 168,960 each |
| Evictions | 168,944 |

The resident high-water counts were 16 entries, 21,640 emitted code
bytes, 50,124 logical metadata bytes and 65,536 reserved arena bytes
in every process. The ordered sweep receipts record the guest work,
cache counters and resident footprint across all 128 sweeps.

## Reproduce

The 24 preflight probes showed a minimum of 84.4% CPU idle and median
98.65%. Two probes overlapped the short series, covering its start and
end, with a minimum of 85.3%. The per-process overlap counts were
1, 0 and 1. All three stock PIDs ran under UID 501 at nice −5.

Run `cache-churn --relocated-s3-17-paths` with the recovered list and
trace. Restore the archive's `files` into a scratch directory and run
`python3 -B kit/run.py replay binding.json series-01` to reproduce
`audit.json`. The archive binds the source and signed binary, inputs,
ordered counters, RSS and priority receipts. Its SHA-256 is
`9c9fdcc1ffab583ae926d9f70439417f23527fea67b65e10f7142e90b3fe22c8`.
