# S3-20dd — exact address64 SIB dword checked-memory load

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `08fc77b` adds only the exact three-byte singleton `8B 04 0B`
(`MOV EAX,[RBX+RCX]`) through shared typed IR. The decoder-owned address64
SIB operand uses scale 1 and full-width RBX base plus full-width RCX index.
The checked access reads exactly four bytes and writes the result to EAX; the
32-bit write zero-extends into RAX and clears `RAX[63:32]`. Other registers
and flags are preserved. The guest boundary is
`A+3`.

The recorded fixtures cover exact source/site binding, the PC-map boundary,
checked faults, no replay, STOP, and budget behavior. This slice does not admit
other SIB shapes or establish production owner/MMU integration, broad memory
coverage, or a performance conclusion.
