# S3-34bn — exact harness gates for S3-20ec

## Scope

The harness pins the two exact Rust regression gates for the address64 RSP
signed-disp8 dword store:

- JIT source/site gate: `memory_load_v2::tests::ir_dword_rsp_sib_disp8_store_binds_all_signed_source_bytes_to_its_site`.
- Host checked-state gate: `tests::s3_20ec_rsp_disp8_dword_store_preserves_ss_fault_and_checked_state`.

It makes no separate PC-map claim and does not establish full `od-host`
acceptance or broaden the S3-20ec runtime contract. The runtime behavior and
full crate-suite results are documented in the
[S3-20ec runtime report](STAGE_3_S3-20ec_2026-11-02.md).

## Evidence

`od-host --lib` local-acceptance gates. The required self-test
`test_s3_34bn_rsp_disp8_dword_store_gates_are_pinned_and_fail_closed` verifies
that each gate appears exactly once in the registry and manifest with its
source identity and exact Cargo argv. It rejects missing manifest or summary
evidence, zero-match runs, ignored or failed tests, and a wrong test identity;
