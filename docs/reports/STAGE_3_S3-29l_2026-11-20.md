# S3-29l composed flags comparison and choice on M1 Pro

**Eager flags materialization is the default for the measured
NativeRegisterV1 scope.** The pooled paired medians favored eager in
the composed cold and repeat dispatch windows and in the independent
retained FIFO16 window. Demand also used more code and metadata. The
composed pair ranges crossed parity, so the decision uses the
per-process medians and footprint together.
[Resident FIFO16 measurements](STAGE_3_S3-29k_2026-11-20.md)

## Composed dispatch

Each mode accepted its first passing attempt in three rounds. Each
round contributed 20 alternating matched pairs over the frozen
1,200-input corpus. The 400 ms calibration target applied to these
standalone windows. Cold used 18 sweeps per side and repeat used 20.
The load rules and the 200 ms side floor were the same as in the
earlier split experiment.
[Earlier split-window receipts](STAGE_3_S3-29j_2026-11-19.md)

| Mode | Pairs | Eager median µs per input | Demand median µs per input | Paired demand/eager median [range] | Shortest side |
| --- | ---: | ---: | ---: | ---: | ---: |
| Cold | 60 | 18.6504 | 19.1148 | 1.02479 [0.97087–1.02973] | 391.104 ms |
| Repeat dispatch | 60 | 17.0739 | 17.4283 | 1.02166 [0.96469–1.04453] | 393.986 ms |

The three cold process medians of the paired ratios were 1.02459,
1.02468 and 1.02498. The three repeat medians were 1.02284, 1.02094
and 1.02193. Accepted overlapping idle minimums were 86.9%, 86.7%
and 86.5% for cold, and 82.9%, 85.3% and 85.5% for repeat. Two
additional cold attempts were rejected at 74.3% and 74.4% idle
during timing. One repeat attempt was rejected in preflight at
74.9% minimum idle. All eight timed processes ran as UID 501 with
effective nice −5. The archive preserves all nine dispositions.

Cold measures the first dispatch against a fresh capacity-one cache
for each input. Repeat measures the second dispatch after one
untimed dispatch on that input's cache. The two strategies had the
same hit, compilation, publication and replacement counts in each
mode. Repeat still compiled and published 1,518 blocks per sweep.
Each timing covers the full dispatcher call and its cache and
execution work.

| Cumulative published code per sweep | Eager | Demand |

| Cold bytes | 2,063,560 | 2,357,944 |

Demand published 14.27% more code in cold and 13.07% more in repeat.
Peak resident code was 2,452 bytes for eager and 3,144 for demand in
both modes. Peak logical metadata was 6,612 and 10,199 bytes.

## Replay

Restore the archive's UTF-8 `files` at their relative paths and
verify the `file_sha256` entries. The combined replays and all nine
attempt audits matched their recorded outputs byte for byte.

```sh
run="$root/s3-29-short-window-126d1b2f-run-02"
runner="$run/short-windows-v1/runner-check"
binding="$runner/overlay-binding.json"
for mode in cold repeat_dispatch; do
  python3 -B "$runner/run.py" combine "$run/$mode" "$mode" "$binding" |
    cmp - "$run/status/$mode-audit.json"
  for attempt in "$run/$mode"/round-*-try-*; do
    python3 -B "$runner/run.py" replay "$attempt" "$mode" "$binding" |
      cmp - "$run/status/$mode-${attempt##*/}-audit.json"
  done
done
```
