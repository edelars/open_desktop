# Stage 3 S3-33e: exact native CMP RAX, sign-extended imm8

**Date:** 2026-10-30  
**Status:** bounded implementation complete; independent review clean.

## Scope

Added a separate uncached opt-in profile for exact bare `48 83 F8 ib`
(`CMP RAX, sign-extended imm8`), where `ib` spans all byte values. The profile
admits S0-09 baseline instructions, bare NOP, and this CMP form only. Existing
generic, INC, DEC, NEG, and ADD-immediate admission profiles remain separate.

Lowering consumes the decoder-owned sign-extended immediate and emits
`ReadGpr(RAX)`, W64 `Const`, W64 `Compare` with `result=None` and full
`FlagEffect::Arithmetic`, then one instruction commit. It emits no GPR write.
Eager and demand-flags candidate compile/dispatch entry points are uncached and
reuse existing IR, helper, statepoint, and pending-flags mechanisms.

## Evidence

- Admission checks every immediate byte against the decoded sign-extended
  value and rejects wrong group selectors, registers, widths, encodings,
  prefixes, truncation, memory forms, and branch targets inside the immediate.
- Lowering tests assert the exact flags-only IR sequence and no `WriteGpr`.
- Compiler tests cover eager and candidate branch consumers and PC maps.
- Host differential coverage compares full `LongModeState` and retirement to
  the interpreter for equal and unequal values, `CMP ...,0`, `MAX` vs `FF`,
  `...80` vs `80`, varied old arithmetic flags, both incoming CF values,
  DF/non-arithmetic preservation, both JZ/JNZ paths, candidate pending-statepoint
  evidence, successor arithmetic, budgets, and STOP before the immediate CMP
  after its pending predecessor (`+3`), before JZ (`+7`), before JNZ (`+19`),
  and before the successor ADD (`+31`). Each STOP case compares full state,
  retirement, guest RIP, and `StopAddress` with the interpreter.
