# Stage 3 S3-20at: address32 indexed SIB with RBP base

## Scope and result

Added the bounded singleton qword MOV profile `67 48 8B/89 /r sib disp8|disp32`, with ModRM `mod=01/10,r/m=100`, SIB base RBP, index RAX..RBX, scale 1/2/4/8, and data RAX..RBP. Address calculation is Dword and transfer size is Qword; exact instruction lengths are six and nine bytes. Signed displacement, scaling, low-32-bit truncation, modulo arithmetic, and the contiguous qword range continue to come from the decoded `MemoryOperand` and `access_address_48`.

Admission is scoped to ModRM `mod=01/10`; `mod=00,SIB.base=101` remains the no-base special encoding and is rejected. No-index forms, extra prefixes, pairs, and V3 were not broadened. Existing RSP-base and no-index SIB profiles remain covered.

## Evidence

- JIT descriptor tests cover load/store, all six data registers, all four low index registers, all four scale values, and disp8 `-128/-1/0/127` plus disp32 `MIN/-1/0/MAX`. Direct V2 and shared IR descriptors agree on source bytes, decoded address/data sizes, base/index/scale/displacement, and next RIP.
- Host execution compares direct V2, shared IR, and interpreter state/RAM and callback address/count/retirement. Cases include data=RBP/base and data=index pre-state aliases, ignored high RBP bits, and qword crossing from `0xffff_fffc` in one callback.
- Architectural access failures preserve CPU/RAM/budget/retirement commit rules; backend failures remain host errors. A successful RBP-data store followed by STOP writes the complete old 64-bit RBP payload once and returns at the nine-byte next RIP.
- Two source sequences that differ only in byte nine are executed and checked against independent expected callback targets (`0x20` and `0x0100_0020`).
- The borrowed dispatcher runs an RBP-base disp32 load, explicit NOP bridge, and existing pair. Budget split resumes at the actual RIP with no repeated first access; budgets 0..4 match the interpreter. Partial source windows 1..8 return the boundary result with no publication, callback, state change, or retirement. The complete `mod=00/SIB.base=101` neighbor returns Unsupported with zero blocks/effects.
