# S3-20dy — address-size-32 RBP-base dword checked store with disp32

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `81243b8` adds only the seven-byte singleton `67 89 85 id`
(`MOV [EBP+disp32],EAX`) to the shared typed-IR Dword-store path. The
decoder-owned address-size-32 effective address adds signed disp32 to low32
EBP modulo 2^32 and zero-extends the starting address. A successful checked
write transfers exactly four contiguous bytes from low32 EAX and advances the
guest instruction boundary to `A+7`. Address-size wrapping applies to the
starting address; a write beginning at `0xffffffff` continues across the
4-GiB boundary rather than wrapping each byte independently.

The JIT source/site test exercises eleven representative signed disp32 values
and mutates each of the four encoded displacement bytes at each tested site.
This binds the tested encodings to their sites; it is not an exhaustive sweep
of all 2^32 possible disp32 values. The bounded host fixture covers ten
displacement/base tuples, each with both low and high full-width RBP values,
and compares native/interpreter CPU state and RAM. On an injected callback
error, the host callback is attempted once while CPU state and RAM remain
uncommitted.
