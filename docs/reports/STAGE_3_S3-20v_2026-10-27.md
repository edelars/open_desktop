# S3-20v — RSP-base exact no-index SIB qword MOV

## Scope

The bounded singleton profile admits only `48 8B/89 /r sib` with ModRM
`mod=00,r/m=100` and SIB exactly `0x24`: RSP base, absent index, scale 1,
zero displacement, data RAX..RBX, qword data, 64-bit effective address and
four-byte length. Decoder `MemoryOperand::access_address_48` remains the sole
effective-address/range implementation. No data-register RSP, displacement,
alternate SIB, address override, extra/segment prefix, extended register,
pair/V3 change, or host-SP/frame modification is included.

## Evidence

- The IR/direct V2 descriptor test covers both directions and all four
  supported data-register values. It verifies exact source identity, decoded
  RSP base, absent index, scale 1, zero displacement and four-byte next RIP.
  Negative cases include incomplete SIB, RSP data, present index, non-unit
  scale, disp8/disp32, `67`, reordered prefix and trailing bytes.
- Direct V2 and shared IR each match interpreter execution for load/store.
  Comparisons include complete guest state and RAM, callback target/count,
  retirement/budget, and unchanged RSP, RBP and flags.
- Noncanonical RSP start and qword last-byte crossing return #SS (vector 12,
  error 0, no linear address); equivalent RBX controls return #GP (vector 13,
  error 0, no linear address). The guest fault cases make no RAM callback and
  preserve state, RAM, RIP, budget and retirement.
- A canonical high-half qword range that overflows u64 retains the
  `MEMORY_ERROR_ADDRESS_OVERFLOW` host classification. A normal backend read
  failure retains `MEMORY_ERROR_BACKEND`. Entry STOP and zero budget prevent
  access; a successful store that raises STOP in its callback remains
  committed and retires once.
- Bounded dispatch composes the four-byte RSP singleton → bare NOP interpreter
  bridge → existing pair. Budgets 0..4 match interpreter state/RAM. A split
  run resumes from the returned RIP and does not repeat the first access.
  Partial instruction windows 1..3 return `BoundaryReached` without effects;
  invalid near-matches return `Unsupported`, execute zero blocks and perform
  no data callbacks. RSP, RBP and flags remain unchanged.
