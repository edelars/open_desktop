# Stage 4 S4-23c: bounded UART RX event delivery

## Result

Accepted bounded slice S4-23c connects the existing fixed-capacity `EventQueue`
to one UART RX endpoint through `UartRxEventPump`. The pump has fixed, bounded
payload capacity. It does not own deadline sorting or event ordering:
`EventQueue` owns generation checks, absolute deadlines, equal-deadline
insertion order, cancellation, rescheduling and reset invalidation.

Dispatch checks conditions in this order: expected generation, STOP, finite
event budget, then readiness of the earliest event at the current virtual
time. A successful delivery injects the byte exactly once and removes the
corresponding event and payload. If the UART receiver is busy, dispatch returns
`ReceiverBusy` and preserves the earliest event, its payload, deadline and
ordering position. After the guest reads the pending byte, a later dispatch can
deliver the same event without reordering or loss.

Reset and stale-generation behavior follow `EventQueue`, invalidating pending
work. The pump does not advance `VirtualClock`, mutate CPU state, execute guest
instructions or wake HLT.
