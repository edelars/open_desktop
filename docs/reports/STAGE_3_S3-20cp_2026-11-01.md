# S3-20cp — exact aliased dword checked-memory load

**Status:** bounded implementation slice committed; S3-20 and Stage 3 remain
open.

Commit `f4affe9` adds exactly one singleton encoding alongside the existing
`8B 03` fixture: unprefixed `8B 00` (`MOV EAX,[RAX]`). The effective address
uses the old full-width RAX value, including values above 4 GiB; only after a
successful four-byte read does the load write EAX and zero-extend into RAX.
The typed descriptor remains bound to those exact source bytes. Prefixes, SIB,
displacement, other register/address forms, truncations, and trailing bytes
remain outside the admitted shape.

The bounded map has one committed guest boundary at `A+2`, with helper/exit
phase classification. The host fixture checks full-width old-RAX addressing,
unaligned access across a page boundary, dword zero-extension, exact error
payloads without commit, noncanonical/overflow behavior, and absence of a read
under budget/STOP guards. See the [S3-20cp JIT testing reference](../testing/JIT.md).
