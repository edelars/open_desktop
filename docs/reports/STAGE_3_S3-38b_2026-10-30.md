# S3-38b — reproducible local VMHost process suite

## Result

Added a separately named `vmhost-process` suite to the Stage 3 harness. One run
passed all 33 process gates on macOS ARM64. A later report-inclusive run passed
the first 32 gates but failed at generated-fault with an inner timeout. The suite
is separate from `local_acceptance`; it does not change the V0 ABI or guest
profile. The passing generated-fault observation and later timeout establish
intermittent process behavior; ISSUE-027 remains open.

The suite reuses the existing control-race, helper-isolation, generated-fault,
and app-bundle smoke scenarios. It builds into a run-scoped Cargo target
directory; Swift binaries, module cache, signed app bundle, and process logs also
live under that run directory. Signing/inspection uses the exact absolute
`codesign` executable returned by `xcrun --find codesign`, whose path and hash
are saved in the summary. The bundle smoke copies the signed app before running
it; the harness hashes that preserved copy and binds it to the app-bundle step.
Only VMHost and the fault helper receive the JIT entitlement; launcher
entitlement inspection confirms that it does not.
