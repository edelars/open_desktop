# S3-20df — exact address64 SIB dword loads at scales 2, 4, and 8

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `fda237b` adds only the three exact three-byte singletons
`8B 04 4B`, `8B 04 8B`, and `8B 04 CB` (`MOV EAX,[RBX+RCX*2|4|8]`) through
shared typed IR. They keep RBX as full-width base and RCX as full-width index;
the SIB selects scales 2, 4, and 8. Effective address calculation follows
decoder-owned address48 `access_address_48`. Each checked read is four bytes;
the result writes EAX, zero-extending into RAX and clearing `RAX[63:32]`,
while other registers and flags are preserved. Each form has the `A+3`
instruction boundary.

Recorded fixture checks cover strict source/site binding, PC-map boundary,
faults, and guards. Coverage limit: no separate scale-specific canonical-end
or range-overflow fixtures were added. The shared preflight/helper are
unchanged, and no runtime defect is claimed.
