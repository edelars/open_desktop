# S3-31d. Cached dependency snapshot comparison

`TranslationKey` stores a validated, ordered dependency snapshot. The
selected implementation accepts a field-for-field match against that snapshot
without allocating or sorting. Different snapshots still pass through the
existing sort and validation, including reordered valid spans, version
changes, incomplete coverage and revoked execute permission. The dispatcher
continues to check source bytes separately.

## Local release comparison

Both builds ran the standard capacity-one cached dispatcher on the fixed
S3-36f LEA/XCHG recurrences with 1, 64 and 4,096 loop iterations. There were
three sequential process rounds, in orders baseline–candidate,
candidate–baseline and baseline–candidate. Each process retained 20
interpreter/native sample pairs per profile with alternating engine order.
Each pair used the same calls on its two sides. Each process calibrated its
own call count. The per-call guest state, code, seed, budget and retirement
were fixed across both builds.

The timer covered the full interpreter or cached dispatch call. Both untimed
preflights agreed on code, state, exits, budgets, retirement, resident sizes
and cache counters, including STOP and partial-budget boundaries. Timed
native calls were hit-only and checked complete state and expected guest
work. All 1,440 sample sides met the 200 ms floor, with a minimum of
201.967 ms.
Resident code and logical cache bytes stayed equal across the two builds.

The run used macOS 26.7.1 ARM64, an Apple M3 Max with 14 CPU cores and
36 GB RAM, and rustc 1.99.0 in the release profile. The CPU model and memory
were read with `system_profiler SPHardwareDataType` after timing. The
bench's separate `sysctl` probe returned unavailable. Both builds recorded
complete source hashes, and some runtime Git status probes timed out.

The baseline was clean revision `b62cd75844db83549d0cbd9574ead26146699677`.
The candidate used that revision with only the archived `translation.rs`
patch. Build source SHA-256 values were
`312bddb7de10489d07ecb2e6531c845f89fb3dacb55ab38d0fb86c77b506c4e0`
and `e322383f48919ff9dfe80337e946cc53c79e831b5f0bc7ab0a61f2d02814eca4`.

## Results and decision

The raw ratio divides the candidate's median native time per call by the
baseline's for each process round. The normalized ratio divides the
candidate's median native/interpreter sample ratio by the baseline's for
that round. Each table value is the median of three rounds with the full
round range in brackets. Values below 1 favor the candidate on the
respective scale.

| Profile | Raw candidate / baseline | Normalized candidate / baseline | Candidate JIT / interpreter median |
| --- | ---: | ---: | ---: |
| `a_1` | 0.8201 [0.7429, 0.8960] | 0.8534 [0.8329, 0.8541] | 1.2748 |
| `a_64` | 0.8828 [0.7326, 1.0592] | 0.8424 [0.8380, 0.8500] | 1.3427 |
| `a_4096` | 0.8834 [0.7346, 1.0440] | 0.8370 [0.8360, 0.8480] | 1.3383 |
| `b_1` | 0.8740 [0.8216, 0.8926] | 0.9044 [0.8991, 0.9103] | 1.2651 |
| `b_64` | 0.9130 [0.8660, 1.1176] | 0.9067 [0.8918, 0.9082] | 1.3006 |
| `b_4096` | 0.9198 [0.8669, 1.1428] | 0.9004 [0.8992, 0.9115] | 1.3007 |

Interpreter control ratios ranged from 0.8594 to 1.2449 across rounds and
profiles, and four raw ranges crossed parity. All 18 normalized comparisons
favored the candidate, with median reductions of 9.3–16.3% by profile. Adopt
the exact-match check for this shared validator. On these inputs the
standard cached dispatcher still took 1.27–1.34 times the interpreter's time
by rounded profile medians. The benchmark covers matching resident
snapshots. Non-matching snapshot cost and cold performance remain open.

## Reproduction and raw values

Build each source version with `cargo build --release --offline -p od-bench
--bin od-bench` and preserve the resulting executables separately. Run the
following from the same workspace, repeating the timed run for each build
in each documented process round.

```sh
./baseline-od-bench cached-native-loop --preflight-only --output baseline-preflight.json
./candidate-od-bench cached-native-loop --preflight-only --output candidate-preflight.json
./baseline-od-bench cached-native-loop --process-run 1 --output baseline-1.json
./candidate-od-bench cached-native-loop --process-run 1 --output candidate-1.json
```
