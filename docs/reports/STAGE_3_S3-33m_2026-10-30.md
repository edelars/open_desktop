# S3-33m: Exact native LEA RAX,[RIP+disp32]

## Scope and result

This slice adds an uncached opt-in profile for exactly `48 8D 05 dd dd dd dd`
(seven bytes, W64/address64). Admission binds the full source encoding to the
decoded RAX destination, `NextRip` base, no index, scale 1, and signed disp32.
Lowering computes the W64 wrapping sum from this decoded instruction's guest
`next_rip`, writes RAX, and commits once. It does not access data memory, check
canonicality, call a helper, or branch to the computed value. Flags, other GPRs,
and pending flags remain intact.

The slice is limited to local differential evidence for these exact bytes. It
does not claim a separate physical-x86 fixture result. Stage 2, owner/MMU,
Mini, and performance are outside this slice; Mini/performance remain deferred
until Stage 3 ends.
