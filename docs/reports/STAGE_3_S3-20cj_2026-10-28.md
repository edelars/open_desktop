# Stage 3 S3-20cj: address32 direct low-base MOV with RSI/RDI data

Implemented the exact singleton forms `67 48 8B/89 /r [disp8|disp32]`: ModRM `mod=00/01/10`, data RSI/RDI (`reg=6|7`), base RAX/RCX/RDX/RBX (`r/m=0..3`), Dword effective address, Qword transfer and lengths 4/5/8. SIB, extra prefixes/REX extensions, other base/data registers, pair and V3 forms remain unsupported. Address calculation remains decoder-owned and uses `(low32(old_base) + signed displacement) mod 2^32`; qword payload/result and full base register are preserved.

RSI/RDI `WriteGpr` stays scoped to the immediately preceding matching `CheckedLoad` temporary and exact Dword operand. Generic `ReadGpr`, arithmetic and the general GPR validator remain unchanged. Direct V2, shared IR, block predicates, runtime descriptors, source-byte matching and bounded dispatch now admit the same forms. Runtime source matching checks encoded displacement bytes against the decoder-owned signed displacement; the final disp32 byte is identity-bearing. Existing address64 direct forms retain their 3/4/7-byte profile.

Coverage added:

- JIT descriptor matrix covers both operations, both data registers, all four bases, mod00/01/10, signed disp8/disp32 boundaries, exact source/descriptor identity, forged address/base descriptors, partial windows 1..3/1..4/1..7, and forbidden SIB/prefix/REX/base neighbors.
- Host direct V2/shared IR/interpreter matrix covers all 48 opcode/data/base/form combinations. It compares complete CPU and RAM state, callback target/width/count, RIP and retirement. High base bits are present while EA truncates to 32 bits; an explicit `0xffff_ffff + 2` case wraps to address 1, and qword callbacks at `0xffff_fffc` remain continuous through `0x1_0000_0003`.
- Direct and shared-IR guards perform no callback at zero budget. Backend failures and guest architectural read/write faults leave CPU, RAM and retirement uncommitted. Successful store+STOP writes one full qword and commits the 5-byte RIP once.
- Bounded dispatch runs the 4/5/8-byte singleton forms from actual RIP once, with one callback and no replay.
- Existing 176-byte frame, 4096-byte emitted-code cap and 10×MOV output size of 3868 bytes remain covered by the JIT suite.
