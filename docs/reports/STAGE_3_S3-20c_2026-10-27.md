# S3-20c report: bounded SIB MOV load/store extension

Date: 2026-10-27

## Implemented local slice

- Extended the existing production V2 qword load/store compilers to admit
  exactly `48 8B/89 /r sib`, ModRM `mod=00,r/m=100`, with one SIB byte and no
  displacement, extra prefix, or tail. Data/base/index registers are limited
  to RAX..RBX; index `100` (no-index), base `101` (no-base), RSP/RBP, and
  extended registers remain rejected. Scales 1/2/4/8 are admitted.
- Kept `long_decode::decode` as the only decoder. The compiler checks raw
  ModRM/SIB fields against decoded instruction length, operation, data register,
  and `MemoryOperand` base/index/scale; it does not calculate effective
  addresses.
- Expanded source identity metadata to a bounded four-byte buffer plus explicit
  length. Host and runtime site validation accept the original three-byte
  direct-base form or the exact four-byte SIB form and validate the decoded
  base/index/scale profile. Helper ABI, V2 tags, store safety, and commit order
  are unchanged.
- The trusted Rust helper still calls
  `MemoryOperand::access_address_48`; effective-address wrapping and
  canonical48 validation remain there. V2 memory operations remain uncached.

## Verification

- `cargo test -p od-jit --offline` — 107 passed. Compiler tests enumerate all
  256 data-register/base/index/scale combinations for both load and store and
  reject truncated, tail, displacement, no-index, no-base, extended, and
  prefix forms.
- `cargo test -p od-host --offline` — 40 passed. The native differential test
  executes all 256 valid combinations per operation and compares full CPU/RAM
  snapshots with `od_isa::execute::step`. It also verifies exact little-endian
  store bytes, overlapping-register aliases, wrap-to-canonical addressing,
  noncanonical guest fault preservation, checked backend boundary failure, and
  STOP/stop-RIP/zero-budget no-effect guards.
- `cargo check --workspace --all-targets --offline` — passed.
- `cargo fmt --all -- --check` — passed.
- `git diff --check` — passed after the final documentation refresh.
- `graphify update .` — passed after code and documentation updates.
- Independent review — clean sign-off. The reviewer independently passed
  `od-jit` (107 tests), `od-host` (40 tests), workspace all-targets offline
  check, formatting, and diff check on the local ARM64 host.

No physical Mac mini check was run. Physical memory acceptance remains deferred
