# Stage 3 S3-20av: address32 absolute qword MOV through no-base/no-index SIB

## Scope and result

Added only singleton `67 48 8B/89 /r 25 disp32`: ModRM `mod=00,r/m=100`, SIB exactly `0x25`, data register RAX..RBP, Dword address size, Qword data size, and exact length nine. The decoded `MemoryOperand` and `access_address_48` remain the sole effective-address semantics. The target is the low 32 bits of the decoded signed disp32 result, zero-extended to the access address; the resulting eight-byte memory transfer is contiguous in 64-bit space and does not wrap per byte at 4 GiB.

Runtime source validation checks the fixed opcode/ModRM/SIB shape and consumes the displacement already retained in the immutable decoder-built artifact; it does not re-decode raw displacement bytes. The 64-bit absolute 20au profile remains supported. Indexed no-base, direct `rm=101`, other prefixes/SIB, moffs, pairs, and V3 remain unsupported. No owner/MMU integration, Stage2/od-isa change, Mini run, or performance claim is included.

## Evidence

- JIT descriptor tests cover load/store, all six data registers, and disp32 `MIN`, `-8`, `-1`, `0`, and `MAX`. Direct V2 and shared IR sites agree on operation, source snapshot, Dword address/Qword data, `base=None,index=None,scale=1`, signed displacement, and next RIP. Partial windows 1..8 fail admission; full indexed no-base, direct `rm=101`, and invalid prefix-order neighbors are rejected.
- Host parity compares direct V2, shared IR, and interpreter CPU/RAM/callback/retirement for both operations and all six data registers. Targets are checked against the independent modulo-2^32 displacement formula after changing guest GPRs and RIP; high noncanonical RSP/RBP values do not affect absolute addressing. Stores preserve complete 64-bit payloads.
- Disp `-1` targets `0xffff_ffff`, without AddressOverflow; disp `-4` accesses `0xffff_fffc..0x1_0000_0003` in one contiguous qword callback. Architectural faults preserve exact guest-fault payload and do not commit CPU/RAM/budget/retirement. Backend failures remain host errors without CPU/RAM commit, with exact read-versus-write callback address/count asserted. Successful store+STOP commits once and returns at RIP+9.
- Two immutable decoder-built artifacts whose source differs only in byte nine execute independently expected targets (`0` and `0x0100_0000`). This demonstrates displacement metadata transport, not raw displacement-byte comparison in the runtime matcher.
- The borrowed dispatcher executes the addr32 absolute singleton, NOP, and existing pair. Budgets 0..4 match interpreter state/RAM; a budget split resumes at actual RIP without repeating the first read. Partial windows 1..8 return `BoundaryReached` with zero blocks/effects, and a complete indexed no-base neighbor returns `Unsupported` with no callbacks.
