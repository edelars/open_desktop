# Stage 3 S3-20bz: address32 indexed SIB with RSI/RDI base and index

## Scope and implementation

Added only singleton `67 48 8B/89 /r sib [disp8|disp32]` with ModRM `mod=00/01/10,r/m=100`, SIB base and index each RSI/RDI, scale 1/2/4/8, data RAX..RBP, Qword transfer and Dword effective address. The exact lengths are 5/6/9 bytes. No extra prefixes, no-index forms, new data registers, pairs, V3, owner/MMU integration, or Stage 2/ISA changes are included.

The decoder's `MemoryOperand::access_address_48` remains the sole address implementation: `(low32(old_base)+low32(old_index)*scale+signed displacement) mod 2^32`, zero-extended before the contiguous qword transfer. When base and index are the same register, both terms read the same pre-instruction value. The full RSI/RDI state is preserved; the qword data value remains full width. Runtime validation keeps this Dword-address profile separate from Qword sites; a forged Qword indexed site of length 6 or 9 is rejected.

Admission is aligned across checked block construction, shared IR verification, direct V2 metadata, immutable runtime source matching, and bounded dispatcher compilation. The data-register whitelist remains RAX..RBP.

## Evidence

The JIT descriptor matrix covers both opcodes, four base/index pairs, four scales, six data registers, all three lengths, and signed disp8/disp32 edge values. It also rejects truncated windows and a neighboring unsupported data-register encoding.

The host matrix executes direct V2, shared IR, and the interpreter across load/store × all four base/index pairs × four scales × six data registers × no-displacement/disp8/disp32 forms. It compares complete CPU and RAM state, an independent low32 EA, callback address/width/count, and retirement. Same-register base/index combinations verify both contributions use the pre-state value. Dedicated cases check ninth-byte disp32 target identity, high-half truncation and modulo-32 product/add wrap, a contiguous qword callback crossing 4 GiB, architectural/backend no-commit for loads and stores, successful store+STOP with exact payload, entry guards, partial execution windows, and actual-RIP continuation through 5/6/9-byte singleton forms, NOP, and the existing frozen pair without replay.
