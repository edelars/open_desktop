# S3-20dz — exact RSP-based dword checked-memory load through SIB

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `bbbb4d0` adds only the exact three-byte singleton `8B 04 24`
(`MOV EAX,[RSP]`) to the shared typed-IR Dword-load path. The decoded
address64 SIB operand uses full-width RSP as its base with no index. A
successful checked read transfers exactly four bytes, writes EAX with
zero-extension into RAX, and advances the guest instruction boundary to
`A+3`.

The host fixture checks noncanonical RSP start and range-end `#SS` faults,
contrasted with a noncanonical RBX `#GP` control. It checks a width-four
`AddressOverflow` at `u64::MAX - 1` before the read callback, and confirms that
an injected read error leaves architectural state uncommitted. A callback
STOP after a successful read leaves the read and state committed. Retrying
the same published block with committed guest RIP `A+3` returns
`EntryRipMismatch { expected: A, actual: A+3 }`, leaves state unchanged, and
does not perform a second read. This is bounded fixture evidence and makes no
separate PC-map phase claim.
