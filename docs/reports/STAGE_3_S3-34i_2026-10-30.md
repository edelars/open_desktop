# Stage 3 S3-34i: exact local gates for native arithmetic slices

## Scope

Added nine mandatory exact Cargo test gates for the already implemented S3-33a–d
native INC RAX, DEC RAX, NEG RAX, and ADD RAX imm8 slices. Each gate pins its
step name, crate, complete test identity, exact Cargo arguments, result log, and
single passing test outcome in the existing local harness manifest and summary.
The input manifest explicitly pins SHA-256 digests for `od-jit`'s `block.rs`
and `block_compile.rs`, which contain the new admission/compiler tests. The
harness's whole-tree source fingerprint continues to cover its existing
tracked source set.

This report covers the four committed S3-33a–d profiles only. S3-33e CMP imm8,
the Mac mini, physical x86, performance, owner-backed, and Stage 2 suites are
outside this slice and remain unclaimed here.
