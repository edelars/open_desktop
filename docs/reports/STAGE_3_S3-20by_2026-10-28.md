# Stage 3 S3-20by: address64 SIB with RSI/RDI base and RSI/RDI index

Implemented the exact singleton qword MOV profile `48 8B/89 /r sib`: ModRM `mod=00/01/10,r/m=100`, SIB base RSI or RDI, index RSI or RDI, scale 1/2/4/8, data RAX..RBP, with instruction lengths 4, 5, or 8 bytes. Effective address uses the decoder-owned operand: `old_base + old_index * scale + signed displacement`, wrapping modulo u64. When base and index name the same register, both contributions use its same pre-instruction value and are added separately. RSI/RDI remain address-only and are preserved.

The direct V2 compiler, shared IR verifier, checked source profile, runtime matcher, and bounded borrowed-fixture dispatcher admit this exact profile. Other prefixes, address-size override, no-base/no-index forms, new register classes, pair/V3 changes, and production owner/MMU integration remain outside scope.

## Evidence

- JIT descriptor coverage exercises load/store × six data registers × four RSI/RDI base-index pairs × four scales × mod00/disp8/disp32 forms. Signed boundary displacements, descriptor/source metadata, decoded operand and next RIP are checked. Partial windows are checked for each actual length: 1..3 for the 4-byte form, 1..4 for the 5-byte form, and 1..7 for the 8-byte form; non-profile neighbors are rejected.
- Host parity coverage compares direct V2, shared IR, and interpreter for full CPU/RAM state across every displaced load/store × base/index pair × scale × data register combination, using signed disp8 and disp32 boundary cases. It checks independent effective-address formulas, callback address/width/count, and retirement. Cases cover same-register base/index aliasing (both terms use one pre-state value), high address bits and wrapping, and distinct artifacts whose final disp32 byte changes the target.
- Fault and guard cases verify exact architectural #GP payload at noncanonical start/end, separate address-overflow classification, backend load/store failure atomicity, full-width store payload, committed store with STOP, and stop-RIP/STOP/zero-budget entry guards.
- The borrowed dispatcher continues from actual RIP across the 4-, 5-, and 8-byte singleton forms, a bare NOP, and the frozen pair; it checks retirement, publication count, callbacks, and no replay. Partial byte windows for the 5- and 8-byte forms stop before publication or memory effects; invalid neighbors also produce no effects.
