# S3-20fo: address32 RAX-alias Dword store with signed disp32

## Scope and semantics

The planned slice admits only the seven-byte form `67 89 80 id`
(`MOV [EAX+disp32],EAX`). The displacement is signed little-endian `i32` and
is sign-extended in site metadata. Address calculation uses the original low32
RAX: `zero_extend((low32(RAX) + signed_disp32) mod 2^32)`. The write payload
is the original low32 RAX, independent of the displacement. Execution performs
one contiguous checked four-byte write; successful RIP is `A+7`. Full RAX,
other GPRs and RFLAGS remain unchanged on success. Only the starting address
wraps modulo 2^32; transfer bytes crossing 4 GiB continue contiguously above
the boundary.

The scope excludes load admission, SIB, other source/base forms, additional
prefixes, production owner/MMU expansion and Stage 2 work.

## Implementation status at this report revision

Runtime and harness implementations are being authored in isolated worktrees.
The agreed identities are:

- JIT: `memory_load_v2::tests::ir_dword_addr32_alias_disp32_store_binds_all_source_bytes_to_its_site`
- Host: `tests::s3_20fo_addr32_alias_disp32_dword_store_uses_wrapped_original_eax_address_and_payload`
- Harness gates: `s3_34cz_ir_addr32_alias_disp32_dword_store_source_binding` and `s3_34cz_host_addr32_alias_disp32_dword_store_wrapped_original_eax_address_and_payload`
- Fail-closed self-test: `test_s3_34cz_addr32_alias_disp32_dword_store_gates_are_pinned_and_fail_closed`

The runtime author is expected to retain source/site mismatch checks for the
newly admitted byte form in the addr64 RAX store, addr32 alias singleton, and
disp8 fixtures. The JIT fixture is expected to bind each displacement byte and
check the `A+7` boundary. Host scenarios cover address/payload separation,
signed extremes and wrap, zero/unaligned/boundary starts, 4 GiB crossing,
fault and guard retries, and callback STOP without replay. These identities and
coverage expectations are not yet confirmed against committed Rust tests.

The target harness totals after this pair are 278 Rust gates (268 acceptance
and 10 lifecycle), 296 local steps, and 123 self-test names.
