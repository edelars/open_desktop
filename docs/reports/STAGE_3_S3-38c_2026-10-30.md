# S3-38c — sequential cross-thread V0 handle lifecycle

**Status:** the targeted C ABI regression passed. This is partial S3-38
lifecycle evidence; it does not establish concurrent execution, persistent
cache reuse, process-suite stability, or full Stage 3 acceptance.

## Scope

The regression uses two persistent host worker threads and two immutable V0
handles. It calls the same idle first handle sequentially on both threads,
interleaves calls to the second handle after each synchronous return, and
checks full four-register state, RIP, flags, reason, and retirement count. It
then sends a pre-run STOP to the first handle, executes that request on the
other thread, verifies state preservation and one-time STOP consumption, and
successfully runs both handles afterward. Calls are serialized; no two
`od_fragment_execute` invocations overlap.

Since one process-wide MAP_JIT mapping may be live at a time, successful
execution of the second handle after the first synchronous call confirms that
the first call released its temporary arena/mapping before returning. The
implementation contract remains per-call cache/arena creation and drop. No
production ABI, cache-lifetime, `od-machine` owner/MMU, or VMHost process
behavior changed.

## Reproduction and environment

The focused change was based on source revision `5679965` while the S3-38c
regression and documentation edits were in the working tree.

```sh
cargo test -p od-host --lib c_abi_idle_handle_runs_sequentially_on_host_threads_and_releases_mapping --offline
```

- Host: Apple M3 Max, macOS 26.7.1, ARM64 (`aarch64-apple-darwin`).
- Toolchain: Rust 1.99.0.
- Result: 1 passed, 0 failed, 101 filtered out.
- `cargo fmt -p od-host` completed before the targeted test.

## Limits

This does not test concurrent execute calls, concurrent destroy, simultaneous
MAP_JIT mappings, persistent cache reuse, memory execution through the public
ABI, IPC behavior, or release distribution. S3-38b's process suite was not
rerun because ISSUE-044 remains unresolved and its diagnostics prohibit retry
without new evidence. Mini/physical x86 and Stage 2 checks were not run.
