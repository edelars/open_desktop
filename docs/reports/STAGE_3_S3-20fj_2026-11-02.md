# S3-20fj: exact address32 RAX-alias Dword load

## Scope and semantics

This bounded runtime slice admits only `67 8B 00` (`MOV EAX,[EAX]`), the
three-byte address-size-32 form where the base and destination alias. The
effective address is zero-extended low32 of pre-instruction RAX. The load
uses that original value for its address, performs one checked four-byte
read, then zero-extends the loaded Dword into RAX. Other GPRs and RFLAGS are
preserved; successful retirement advances RIP to `A+3`.

## Static review evidence

Runtime source `b1aa25d` passed independent Sol/high static review after host
fixture and retry-path fixes. The exact JIT fixture binds the three source
bytes to the decoded site, checks the RAX alias operand and address/transfer
sizes, and verifies the `A+3` PC-map boundary. The host fixture checks
interpreter parity, high-half truncation, unaligned addresses, reads at the
end of the 32-bit address space, exact callback address/width/count,
architectural and backend no-commit with retry, budget/stop/entry guards,
and callback STOP after commit without replay. Harness S3-34cu separately
pins the exact JIT and host test identities and passed independent Sol
review.

These are source-review findings, not executed results. No behavior tests,
builds, formatting, Cargo checks, or Python harness were run. The exact JIT
and host gates remain pending.
