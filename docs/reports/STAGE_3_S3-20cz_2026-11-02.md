# S3-20cz — exact address-size-32 disp8 dword checked-memory load

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `0f1dab2` adds only the four-byte singleton `67 8B 43 ib`
(`MOV EAX,[EBX+disp8]`) to the shared typed-IR dword-load path. The signed
disp8 and effective-address wrapping/zero-extension are decoder-owned for the
address-size-32 operand. The host fixture checks the wrapped EBX address and
one four-byte load. JIT coverage binds all source bytes to the site and
checks the PC-map boundary at `A+4`.
