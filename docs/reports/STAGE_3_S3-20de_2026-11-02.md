# S3-20de — exact address64 SIB dword checked-memory store

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `a5edf66` adds only the exact three-byte singleton `89 04 0B`
(`MOV [RBX+RCX],EAX`) through shared typed IR. The decoder-owned address64
SIB operand uses scale 1 and full-width RBX base plus full-width RCX index.
The store writes low32 RAX through one contiguous checked four-byte access;
registers and flags are preserved. The guest instruction boundary is `A+3`.

The recorded fixtures cover exact source/site binding, the PC-map boundary,
no replay, fault atomicity, STOP, and budget behavior. Other SIB shapes remain
outside this admission. This slice does not establish production owner/MMU
integration, broad memory coverage, or a performance conclusion.
