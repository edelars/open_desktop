# Stage 4 S4-25a: fixed-edge Local APIC register core

S4-25a adds a bounded one-CPU `LocalApic` device using the existing
`MachineBus` contract. The fixed xAPIC MMIO base is `0xFEE00000`; the APIC ID
is 0. Supported 32-bit register accesses use the 16-byte APIC stride: ID,
TPR, PPR, EOI, SVR and the ISR/TMR/IRR banks. The Version register is not
implemented, so this slice advertises no APIC version or LVT capability.

The control handle accepts fixed edge requests for vectors 16 through 255.
Repeated requests coalesce in IRR. Eligibility depends on the SVR software
enable bit and TPR/PPR priority. Read-only pending inspection does not consume
the request; explicit acknowledge moves one eligible vector from IRR to ISR.
EOI clears the highest in-service vector. Acknowledge is a Local APIC state
operation and does not execute guest code or deliver a CPU interrupt.

## Limits

This device is tested through an explicitly constructed `MachineBus`; default
board registration and a guest execution path are not established. The
Version register (`0x030`), LVT, APIC-base MSR/relocation, x2APIC, IOAPIC,
level-triggered routes, timer, CPU interrupt delivery, IDT/IF/shadow rules,
handler execution, HLT wakeup and Linux discovery/boot remain outside the
slice. Unsupported accesses return local `DeviceError` without changing the
model state. S4-25, S4-27 and Stage 4 remain open.
