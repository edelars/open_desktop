# Stage 3 S3-10 — staged integer data effects, 26 October 2026

## Implemented slice

`od-jit::emitter::emit_data_effects` accepts a verified decoder-derived linear
IR `Program` plus the `Allocation` built for that same Program. It emits checked
ARM64 data-effect bytes for the current W64 MOV immediate, ADD, SUB, and CMP
register profile. Reads of both arithmetic operands precede result writes,
including register aliases. CMP writes a dedicated observation scratch result;
it does not write a guest GPR. Allocation homes and spills are consumed by the
production emitter.

Generated code operates on a separate staging copy of four GPRs and an output
buffer. It returns `DATA_EFFECTS_UNCOMMITTED_V1`, not a `RuntimeExitTag`, and
does not update canonical `LongModeState`, RFLAGS, RIP, budget, or retirement
count. Flags are marked `ArithmeticIncomplete`. Branch terminals and exits
other than `BlockComplete` are rejected; even `BlockComplete` is not reported as
a successful guest exit. Eager flags and architectural retirement remain S3-11.

The native od-host test runs `CodeView → build_block → lowering → allocator →
emitter → PublishedCode → ARM64 execution` for homes budgets 0 through 4. It
checks staged registers, all temp outputs, CMP scratch, alias/equal operands,
overflow patterns (`SUB 0-1` wraps to `u64::MAX`; CMP compares distinct
nonzero operands in borrow direction and checks the wrapped scratch result),
multi-lane constants, spills, host register canaries, and unchanged canonical
state. Allocator unit coverage adds a `ReadGpr` value live through two explicitly
declared helper boundaries and verifies capture slot reuse.
