# S2-31dx — historical ZE for bounded m32/m64 FST/FSTP

## Реализация

Только точные bare `D9 10`, `D9 18`, `DD 10` и `DD 18` допускают входной
ZE. Предикаты конвертации m32/m64 теперь отклоняют `FSW & 0x80c0 != 0`, поэтому
SF, ES и B по-прежнему отвергаются. FCW, исходный tag/class, адрес и правила
конвертации не менялись. Отдельный FSTP m80fp предикат сохранил прежнюю маску.

ZE сохраняется при успешной записи. Существующая последовательность commit
оставляет новые флаги конвертации и C1 после завершённой атомарной записи;
ошибки записи и canonical-range отказ оставляют состояние и память без
изменений. Нового производителя ZE нет.

Схема schema-v2 распознаёт Unsupported для четырёх bare форм по FCW и маске
`0x80c0`; ZE само по себе не является допустимой причиной Unsupported.
Четыре interpreter fixtures проверяют буквальные байты результата, полный FSW,
tag/TOP, RIP, сохранность исходного регистра и FNSTSW AX после FSTP. JIT остаётся
закрыт.
