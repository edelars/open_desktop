# S3-34ck: exact harness gates for planned S3-20ez scaled RAX-indexed Dword load

## Scope

This harness slice pins the exact seven-byte, unprefixed address64 RAX-indexed
no-base SIB Dword-load forms with scales 2, 4, and 8:
`8B 04 45/85/C5 disp32` (`MOV EAX,[RAX*scale+signed disp32]`). It adds the
JIT source/site gate
`memory_load_v2::tests::ir_dword_rax_index_no_base_sib_scaled_disp32_load_binds_all_source_bytes_to_its_site`
and host gate
`tests::s3_20ez_rax_index_no_base_sib_scaled_disp32_dword_load_uses_original_scaled_rax`.
The registered gate IDs are
`s3_34ck_ir_rax_index_no_base_sib_scaled_disp32_dword_load_source_binding` and
`s3_34ck_host_rax_index_no_base_sib_scaled_disp32_dword_load_original_rax`.

The self-check verifies exact identities in both registries and the manifest,
matching evidence, fail-closed gate selection, and local-acceptance summary
membership. Runtime support for S3-20ez is not part of this harness-only slice.

## Manifest and review

Harness source commit `2dc2bc4` is integrated as `1b8ebba`. The static
manifest records 248 Rust gates (238 acceptance and 10 lifecycle), 266 local
steps, and 108 self-test names. Independent Sol/high review passed with no
findings.

No Python harness test, Cargo gate, or runtime execution was performed. The
gate pins are not runtime evidence.
