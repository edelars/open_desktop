# S3-36e — resident capacity-one cached checked-memory full-call profile

**Status:** implementation is committed and source-reviewed; release preflight
and calibration-only passed on Apple M3 Max. Three scored runs remain open. No
performance conclusion is available yet.

## Scope

The opt-in `od-bench two-site-memory-cache` profile uses only the two frozen
S3-34a sequences, `store_then_load` and `load_then_store`, with 1,200 inputs
per sequence. It excludes `load_then_load` and all other memory forms.

For each sequence it retains one capacity-one `MemoryPairCache` and one
published mapping. The full native timer covers `MemoryPairCache::run`,
including profile/context/source/dependency/key validation, lookup and cache
counters, and typed host execution. State/RAM/callback reset, counter snapshots,
and complete result validation are outside the call timer. Interpreter calls
are timed separately. The cache is cleared between sequence strata.

The implementation is commit `490c957d9f5c0ed5143ec2d46e1851e124497714`,
independently reviewed with no findings. The bounded runtime cache prerequisite
is `b1a6ccb130844c40a396155a8f84bda656bfa8c3`. This profile provides no
production owner/MMU, VMHost, SMC, general memory, or whole-system evidence.

## Calibration-only

One release calibration-only outer command completed with exit code 0 in
55.671 s; the benchmark report's `total_elapsed_ns` was 10.621381750 s.
Both sequences passed the 200 ms minimum side-time floor at 2,048 repetitions
per side after 12 retained attempts. The final attempt measured 299.291 ms
interpreter / 808.183 ms cached for `store_then_load`, and 289.805 ms / 807.221
ms for `load_then_store`. Each sequence accumulated 4,914,000 hit-only
calibration calls, with zero misses, replacements, compiles, or publications;
the final sequence counters remained 4,917,599 hits and one initial
miss/compile/publication. Resident high-water was one entry; the cache was
explicitly cleared/dropped before the next sequence or return (reported
`cache_drop_ns`: 10,292 and 18,750). The report contains no
scored sample pairs and records `calibration_only_unscored`.

Point-in-time monitoring snapshots recorded one-minute load averages from 2.16
to 2.61. Graphify was visible in the before/early snapshots. A Stage 2
`od-runner` test and its `rustc` child were visible in six later samples; the
sampled `rustc` CPU values were 18.8%, 29.3%, 0.0%, 0.0%, 0.0%, and 120.3%.
Stage 2 was not stopped. These sparse outer-command snapshots have no
per-call timestamps and cannot attribute overlap to measured calls. The
benchmark's runtime Git status probe timed out, so `working_tree_dirty` remains
unknown.
