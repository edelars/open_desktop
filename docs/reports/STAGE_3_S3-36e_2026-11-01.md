# S3-36e — resident capacity-one cached checked-memory full-call profile

**Status:** implementation is committed and source-reviewed; release preflight,
calibration-only, and all three scored runs passed on Apple M3 Max. The bounded
run set is complete; cross-run synthesis remains to be reviewed separately.

## Scope

The opt-in `od-bench two-site-memory-cache` profile uses only the two frozen
S3-34a sequences, `store_then_load` and `load_then_store`, with 1,200 inputs
per sequence. It excludes `load_then_load` and all other memory forms.

For each sequence it retains one capacity-one `MemoryPairCache` and one
published mapping. The full native timer covers `MemoryPairCache::run`,
including profile/context/source/dependency/key validation, lookup and cache
counters, and typed host execution. State/RAM/callback reset, counter snapshots,
and complete result validation are outside the call timer. Interpreter calls
are timed separately. The cache is cleared between sequence strata.

The implementation is commit `490c957d9f5c0ed5143ec2d46e1851e124497714`,
independently reviewed with no findings. The bounded runtime cache prerequisite
is `b1a6ccb130844c40a396155a8f84bda656bfa8c3`. This profile provides no
production owner/MMU, VMHost, SMC, general memory, or whole-system evidence.

per side after 12 retained attempts. The final attempt measured 299.291 ms
