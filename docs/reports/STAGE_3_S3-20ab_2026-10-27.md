# S3-20ab — RBP as qword MOV data and disp8 base

## Scope and implementation

Admitted only the four-byte singleton forms `48 8B/89 6D ib`: ModRM
`mod=01`, `reg=RBP`, `r/m=RBP`, signed disp8, qword data and 64-bit effective
address. The existing decoded `MemoryOperand` and `access_address_48` remain
the sole address authority. Generic GPR validation, frame layout, C ABI,
pair/V3 forms, and Stage2 are unchanged. Existing RBP-data-only,
RBP-base-only, and RSP-data profiles remain exact separate forms.

## Evidence

- Descriptor/direct V2/shared IR admission covers load and store at disp8
  -128/-1/0/127 and verifies exact bytes, RBP base, no index, signed
  displacement and data register RBP. Malformed, truncated, SIB, prefix,
  disp32 and RSP-data near-matches remain rejected.
- Direct V2, shared IR and interpreter compare full CPU/RAM state, callback
  address/count and retirement. The target assertion is calculated from the
  entry RBP; loads commit a different value into RBP only after success, and
  stores use the old RBP as both address base and complete 64-bit payload.
- A current noncanonical access returns #SS (vector 12, error code 0, no
  linear address) before a backend callback and preserves CPU/RAM/budget/
  retirement. Dispatcher budget split and callback STOP both retain the
  first successful RBP load, resume at the actual next RIP without a repeated
  read, then fault on the following RBP-based access while preserving that
  first commit.
- On the local ARM64 macOS host, the exact shared-IR alias profile also runs
  through the x19 ABI canary for success, budget guard, and architectural
  fault returns; frame layout and public ABI are unchanged.

## Validation

- Focused descriptor and host tests passed, as did the existing RBP data-only,
  RBP-base disp8 and RSP-data regressions.
- `cargo test -p od-jit -p od-host --offline -- --quiet` passed: 150 `od-jit`
  tests, 70 `od-host` tests, and 12 memory corpus tests; 2 environment-driven
  corpus tests were ignored. Doc tests passed.
- `cargo fmt --all -- --check`, `cargo check --workspace --all-targets --offline`,
  Linux x86_64 `cargo check -p od-host -p od-jit --target
  x86_64-unknown-linux-gnu --offline`, and `git diff --check` passed. Linux
  check reported six existing platform-specific `od-host` dead-code warnings.
- Graphify query preceded source reads and `graphify update .` completed. It
  reported the existing `include/open_desktop/host_abi.h:68` extraction
  warning and skipped non-code files.
- Changed documentation links were checked locally; independent review is
  complete with no findings.

Evidence is local ARM64 fixture only. Production owner/MMU integration,
physical x86 verification, Mini runs and performance measurements remain
deferred.
