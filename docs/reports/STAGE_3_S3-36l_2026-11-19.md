# S3-36l Warm S3-14 FIFO on M1 Pro

The signed ARM64 release from clean `9405ff4` ran `warm-branch-helper`
on an Apple M1 Pro with macOS 14.6.1 and Rust 1.99.0. The exact S3-14
profile contains four branch boundary cases and one helper case. The
runner verified the tracked list, recorded trace and all five fixtures.

Warmup compiled and published each of the five blocks once. Every timed
sweep made five calls, retired 14 guest instructions and executed five
native blocks on the FIFO side. FIFO recorded five hits and zero misses,
compilations, publications or evictions per timed sweep. Architectural
state, exit, retirement and budget checks accompanied the matching
interpreter workload. Initialization, publication, warmup, state reset
and validation occur outside the scored calls.

Three independent processes supplied 20 paired intervals each. The two
sides within each pair used the same sweep count. Round counts were 65,021,
65,034 and 65,218 sweeps per side. All 120 intervals passed the 200 ms
floor. The shortest was 200.188 ms.

| Per five-case sweep | Median | Range |
| --- | ---: | ---: |
| Warm FIFO | 5.675 µs | 5.656–5.697 µs |
| Interpreter | 3.089 µs | 3.078–3.098 µs |
| Paired FIFO/interpreter ratio | 1.8374 | 1.8283–1.8479 |

The interpreter was faster in all 60 pairs. The warmed FIFO held five
entries, 7,500 emitted code bytes and 17,641 logical metadata bytes. The
arena reservation was 65,536 bytes.

The measured PIDs ran under UID 501 at nice −5. Every accepted process
passed its own 24-probe preflight, and the lowest overlapping CPU idle
sample was 85.9%. The first attempt for each round was rejected at 74.1%,
73.4% and 72.8% idle. The collection retains all six attempts.

## Reproduce

Use `warm-branch-helper` with the tracked S3-14 list and trace. Restore
the archive's `files` into a scratch directory and run
`python3 -B kit/run.py combine attempts-v1` to reproduce `audit.json`.
The archive includes the runner, build receipt, fixture hashes, process
priority receipts, load logs and raw paired reports. Its SHA-256 is
`a66c599f81f3e759b8a35c106ddc0489eff8d26c7d46b5af42880c575d59af68`.
