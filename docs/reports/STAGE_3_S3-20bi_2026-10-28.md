# Stage 3 S3-20bi: direct RSI/RDI qword bases with signed displacement

## Scope

Added singleton `48 8B/89 /r disp8|disp32` with ModRM `mod=01/10`, `rm=110` (RSI) or `rm=111` (RDI), data RAX..RBP, Qword address/data and exact lengths four/seven. RSI/RDI remain base-only. No SIB, address override, added prefixes, data/index expansion, pair or V3 form was added. The decoder-owned `MemoryOperand::access_address_48` remains the only EA/canonicality/range implementation.

## Evidence

- JIT descriptor/compiler tests cover both operations, both bases, all six data registers, disp8 MIN/-1/0/MAX and disp32 MIN/-1/0/1/MAX. They assert decoded displacement, source bytes, lengths and site metadata. Partial windows 1..3/1..6, SIB/address32 forms, and RSI/RDI-as-data forms are rejected.
- Host direct V2/shared IR/interpreter matrix checks complete state/RAM parity, retirement and one exact qword callback for every accepted form. It independently asserts `old_base.wrapping_add_signed(displacement)`; bases are chosen so each expected target is readable. Loads write only the destination; stores preserve the full qword; RSI/RDI remain unchanged.
- Two immutable disp32 sources differing only in the final displacement byte reach separately asserted targets `0x40` and `0x0100_0040`. The dispatcher resumes at actual RIP from a disp8 load to a disp32 load with budget 1 and does not repeat the first read.
- Noncanonical start/end load and store cases produce #GP before callbacks and preserve CPU/RAM with zero retirement. Canonical qword overflow remains AddressOverflow with no callback. Backend load/store failures preserve host classification and do not commit. Successful disp8/disp32 store+STOP writes once; entry STOP, stop-RIP and zero budget perform no access.
