# S3-20fz: Address32 RCX-base Dword load signed disp32 `67 8B 81 id`

## Scope and contract

This document records the requested bounded slice. Implementation and
independent review are pending; this report does not claim that the behavior
or tests exist.

The exact instruction is seven bytes `[67,8B,81,id0,id1,id2,id3]`:
`MOV EAX,[ECX+signext(disp32)]`. `67` is the sole prefix; data and address
sizes are Dword; RCX supplies the addr32 alias base; there is no index and
scale is 1. The displacement is signed little-endian i32. The starting
effective address is
`zero_extend((low32(RCX) + signed_i32_disp32) mod 2^32)`.

Execution performs one contiguous checked four-byte read. The value is
zero-extended into full RAX. RCX, every other GPR, and RFLAGS are preserved;
successful next RIP is `A+7`. Only computation of the starting EA wraps at
32 bits. Transfer bytes after `0xffffffff` continue contiguously above 4 GiB.
Existing memory/backend faults, entry guards, retry, and callback STOP after
the successful read without replay remain in scope. Instruction-fetch errors
are checked through the demand interpreter path; published IR execution uses
immutable compiler-issued source.

The explicit exclusions are RCX disp32 store, every other base register,
SIB/index forms, additional prefixes or REX, and all other encodings. Supported
neighboring forms such as `67 8B 01` and `67 8B 41 ib` must retain distinct
source/site bindings. Truncated and trailing-byte forms remain rejected.

## Planned acceptance identities

The following are requested target names, not verified Rust definitions:

- JIT: `memory_load_v2::tests::ir_dword_addr32_rcx_disp32_load_binds_all_source_bytes_to_its_site`
- Host: `tests::s3_20fz_addr32_rcx_disp32_dword_load_uses_wrapped_ecx`
- Harness JIT gate: `s3_34dk_ir_addr32_rcx_disp32_dword_load_source_binding`
- Harness host gate: `s3_34dk_host_addr32_rcx_disp32_dword_load_wrapped_ecx`
- Fail-closed self-test: `test_s3_34dk_addr32_rcx_disp32_dword_load_gates_are_pinned_and_fail_closed`

Acceptance should bind all seven source bytes, signed displacement metadata,
and the exact site through compiler, decoded, IR, runtime, and host publisher
admission. It should prove distinct identity from supported addr32 RCX
singleton and disp8 forms, reject forged metadata and truncated/trailing
sources, and pin the PC-map boundary `A+7`. Host parity should cover signed
disp32 edges, low32 address wrap, full-RCX and low32 decoys, one contiguous
checked read across 4 GiB, zero-extension to RAX, preservation of CPU/RAM,
fault/backend atomicity and retry at the original EA, each entry guard, and
callback STOP without replay.
