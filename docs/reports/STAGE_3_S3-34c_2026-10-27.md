# S3-34c — bounded two-site mismatch reducer

**Date:** 2026-10-27  
**Base revision:** `00a327572a20f4a4196a56c59b0297ed1fac9b6e`  
**Host:** macOS 26.7.1 (25G241), Darwin arm64  
**Toolchain:** `rustc 1.99.0 (b940084d7 2026-09-28)`, `cargo 1.99.0 (5f94df478 2026-08-27)`

## Scope and behavior

Added a test-only reducer in the existing `od-host` memory corpus module for
the two version-1 S3-34b profiles. It reads a saved report and repeats the
original case twice through independent native and interpreter execution
before proposing reductions. If either replay is unstable or the original
mismatch classes do not recur, it records an explicit stop reason and performs
zero reduction attempts. Missing native support and malformed reports fail
before execution.

Candidate operations are deterministic: first zero 8-byte GPR/RAM groups, then
individual bytes, then bits. Address GPRs are skipped; the source sequence and
bytes, address fields, RAM size/layout, alias/overlap relation, budget, STOP,
fault injection and continuation protocol are copied unchanged. Only
non-address initial GPR values and RAM contents can change. Complexity is the
popcount sum of those GPRs and RAM bytes. Every attempted candidate must
strictly lower that measure and a fresh real native/interpreter replay must
produce the same ordered mismatch-class vector for every phase, including
GPR/RAM indices and continuation phase. A class moving from the first entry to
continuation is rejected even if flattening would produce the same labels. The
bound is 512 attempts.

Version-1 replay reports with a continuation protocol now require both paired
phase snapshots. Named continuation diagnostics serialize the budget-limited
first entry and resumed entry, even when the first phase has no mismatch; the
decoder rejects reports whose snapshot count does not match their protocol.
The final-phase regression constructs a report through `mismatch_report`,
serializes and parses it, then confirms the phase-aware reducer replay reproduces
an empty first phase and the same GPR mismatch in continuation.

An explicit ignored entry uses `OD_JIT_REDUCE_CASE`; it saves a new
`.reduced-<pid>.json` report with original/reduced envelopes, both initial
replays, the final fresh backend observations, classes, attempts, limit and
stop reason. It creates the result with `create_new` and leaves the original
file intact. The reduced envelope is exercised through ordinary S3-34b replay
in the reducer self-test.

The generic candidate logic does not special-case GPR[11]; it can reduce that
register to zero when the mismatch predicate allows it. The primary positive
reducer self-test uses a clearly named synthetic corruption: after fresh
backend execution it flips GPR[10] in the native first-phase observation when
initial GPR[11] is nonzero. Clearing the marker then naturally removes the
class and the candidate is rejected by the normal phase-aware comparator. This
test-only path proves useful reduction and class preservation; it does not
indicate a real JIT defect. Negative coverage checks changed/eliminated
mismatch classes, same class moved between phases, malformed input, unavailable
native backend, and the attempt cap.
