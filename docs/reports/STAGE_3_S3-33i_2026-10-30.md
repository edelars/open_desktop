# Stage 3 S3-33i: exact native XCHG RAX,RBX

Date: 2026-10-30  
Status: bounded implementation; independent review and full local harness
passed.

## Scope

This slice adds a separate uncached opt-in profile only for exact bare bytes
`48 87 D8` (`XCHG RAX,RBX`). Admission binds decoded W64 register operands to
the full three source bytes. It rejects `48 87 C3`, `48 93`, self-exchange,
other register pairs or widths, memory forms, LOCK/other prefixes, truncation,
interior branch targets, and unrelated unsupported instructions. The bounded
profile also retains the already-supported S0-09 forms and exact bare NOP.

Lowering reads old RAX and RBX into distinct temporaries before either write,
then writes RAX from old RBX and RBX from old RAX and commits once. The emitter
allows two GPR writes only for this exact ordered dual-write window. Structural
negative cases reject wrong mappings, write-before-second-read, duplicate
destinations, a third write, and mixed arithmetic. Allocation gives the two
pre-exchange values separate homes, and both remain live through their later
write uses.

Intermediate PC-map ranges are replay-only or inadmissible; none can expose a
canonical snapshot containing only one updated GPR. Native execution retires
one guest XCHG. No flags/helper operation is added, and all RFLAGS, definedness,
and pending-writer descriptors and operands are preserved. This is register
exchange evidence only and makes no memory-atomicity claim.
