# Stage 3 S3-34q — retained-hit state-only reducer

## Scope

This slice adds bounded reduction and replay for saved S3-34p `retained_hit`
semantic mismatches at failing input index 1. The existing version-1 failure
envelope and `replay_cache_trace_failure` reader remain strict: the failing
input must still equal the canonical retained-hit corpus input. S3-34q writes a
separate versioned artifact that binds the raw source failure file digest,
source failure digest, source observation corpus digest, strategy, and exact
warmup prefix.

Reduction changes only initial GPR values and the permitted arithmetic flags
and DF bits. Code bytes, cache bindings, execution context, dependency
generations, RIP, budget, stop controls, and all other input fields remain
fixed. The reducer accepts only a strict decrease in initial-state popcount and
the same GPR, flags, RIP, or auxiliary-state mismatch kind and class. Exit,
retirement, remaining-budget, and cache-counter-only failures are ineligible.
It caps candidate evaluations at 256, replays the source and each candidate
twice from a fresh cache, and
requires the warmup to prove one miss/compile/publication and the failing call
to prove one hit with no additional compile/publication. Reduced input is
written only after the exact mismatch reproduces; a separate status record
reports `not_reproduced` or `evaluation_limit` when applicable.

The local self-check labels its input-dependent injected mismatch as test-only.
It exercises reduced replay and rejects altered warmup/prefix, cache-hit
counters, code, context, source corpus, mismatch class, and artifact digest,
plus unstable and backend-error trials. It does not claim a JIT defect.
