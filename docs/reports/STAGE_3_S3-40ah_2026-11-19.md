# S3-40ah System instruction guards in interpreter RUN on M1 Pro

Four stack samples of the exact signed S3-40ag builds used 7-second,
1 ms sessions with two repeats per revision and reversed process
and workload order. In the current `5bc5ec6` image, 69 of 206
directly mapped `Operation::eq` samples led to the adjacent RDTSC,
CPUID, SYSCALL and SYSRET predicates in STEP. The four respective
counts were 18, 21, 13 and 17. A further 527 current equality
samples lacked a reliable direct call-site mapping. The sampling
receipts establish call-site attribution. The timing experiment
measures the complete public RUN path separately.
[Historical comparison](STAGE_3_S3-40ag_2026-11-19.md)

The candidate replaces those four fieldless comparisons with
individual `matches!` predicates. It preserves the guard order
and instruction bodies. The ARM64 linked RUN STEP has 86 static
`Operation::eq` calls, down from 90, with all four target calls gone.
The stock source is pinned at `ef44df6` and has the same
`execute.rs` as `5bc5ec6`. Both versions passed all 6,007
`od-isa` tests locally. On M1 Pro both builds passed all 2,400
frozen MOV inputs at each of budgets 0, 1 and 2 and the
unmapped-code control at budget zero. The untimed checks compare
CPU state, defined flags, RAM, ordered memory callbacks, retirement
and budget exit.

## Results

Six paired rounds alternated build and sequence order. Each process
ran all six permutations of budgets 0, 1 and 2. The two workloads
used a fixed 4,374,000 and 4,339,200 RUN calls per interval.
The series retained 432 intervals and 1,882,051,200 RUN calls.
The shortest interval was 103.490 ms against a 45 ms floor.

Adopt the four predicate changes. Time fell by 5.91–6.70% by
paired median at budgets 1 and 2. Every one of those paired rounds
improved on both workloads. The budget-zero ranges included unity.
The historical gap stays open in ISSUE-521.

## Environment and reproduction

MacBookPro18,3, Apple M1 Pro, eight logical CPUs, macOS 14.6.1
(23G93), Xcode 15.4 (15F31d), Rust and Cargo 1.99.0, and Python 3.12.5.
Both native ARM64 release builds target macOS 14.0 and passed strict
signature checks with Hardened Runtime and `allow-jit`. AC power was
connected. All twelve timing processes recorded UID 501, nice −5
and QoS `0x21`. The 24 preflight probes measured 92.8–99.3% idle CPU, with a
median of 98.8%. The 38 in-run probes measured 73.6–86.7%, with a
median of 86.3%.

Extract the timing archive’s harness files to
`work/tmp/s3-40-mov-system-guards/` in a checkout with the pinned
stock commit and the S3-40m, S3-40w and S3-40z data archives. The
archived `README.md` gives build, correctness and measurement commands.
`python3 offline_audit.py /path/to/evidence.json.gz` recomputes the
outcome from the retained CSV data and signed-build checks.
