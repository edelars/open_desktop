# Stage 4 S4-21c: bounded paged vCPU owner

## Результат

Реализован `PagedVcpuSession` для фиксированного `Stage4FlatProbeV1` image.
Loader создаёт согласованные CPU, RAM, bus и UART. Синхронные bounded quantum
и RX dispatch вызываются владельцем; автоматических циклов нет. Host lifecycle
отдельно от активности CPU: pause/resume сохраняют halted, STOP идемпотентен
и блокирует исполнение и dispatch, в том числе после HLT или terminal exit.
Defined-mask берётся из последнего отчёта quantum.

Reset сначала строит и проверяет новый image и CPU/paging profile без fetch.
Затем существующий pump атомарно проверяет и увеличивает generation, очищает
pending events и payloads и переключает UART. Новая машина заменяет старую
после успешного reset pump. Время и deadlines остаются в домене caller;
обычный токен поколения наружу не выдаётся. Это повторный вход в профиль,
а не архитектурный reset x86.

## Проверки

`cargo test -p od-machine --lib --offline`: 120 passed, including the four
new owner tests. `cargo test -p od-machine --test paged_probe_quantum --test
uart_rx_events --offline`: 28 passed (21 + 7). Покрыты STOP до fetch и после инструкции, pause/resume, store и OUT,
HLT/STOP, отказ dispatch при pause/HLT/STOP, reset из paused/stopped/halted/
faulted, stale generation, due/future payload, замена RX/TX и отказ invalid
image без изменения очереди. Store case меняет код через приватный тестовый
доступ после загрузки: штатный image допускает только load/OUT/HLT.
Исчерпание поколения проверено существующим низкоуровневым тестом EventQueue,
но не инжектировано через owner. CPU fault в тесте создаётся приватным
изменением page table после загрузки. Независимое Sol/high code review прошло
без замечаний P0–P3; предложенные дополнительные owner tests являются
необязательным усилением покрытия.

Проверки `cargo fmt --all -- --check`, `cargo check -p od-machine --all-targets --offline` и `git diff --check` прошли. `python3 tools/check_layout.py` не прошёл: существующий корневой каталог `smoke` отсутствует в карте проекта ([ISSUE-056](../KNOWN_ISSUES.md#issue-056-layout-check-unmapped-smoke-root)). Результаты также записаны в [manifest](data/stage4/s4-21c-paged-vcpu.json). `graphify update .` обновил code graph: 27 609 nodes и 69 357 edges; semantic extraction документации не проводилась.

## Границы

Нет runner integration, отдельного completion/cancellation predicate, IRQ
wakeup или общего scheduler. S4-21 и Stage 4 остаются открытыми. Результат
не подтверждает boot ядра или Linux.
