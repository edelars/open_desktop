# S4-27a — caller-driven APIC interrupt entry

## Result

Added `DiagnosticVcpuSession::deliver_interrupt_and_step` as a synchronous
diagnostic bridge from one APIC-eligible vector to the existing
`od-isa::deliver_maskable_interrupt` entry helper, followed by a handler run
with an instruction budget of one. This attempts at most one instruction;
fetch/execute can fault, halt or return unsupported before retirement. Delivery
uses the session's flat
identity `MachineBus` adapter. It executes against a candidate CPU state;
after successful IDT entry, the exact selected vector is revalidated and moved
from IRR to ISR while the CPU candidate is published under the APIC owner lock.
The APIC mutex is not held during descriptor reads or frame writes.

The caller certifies a fresh completed-instruction boundary, no pending
synchronous exception/debug/NMI event or other interrupt inhibition, serializes
the entire call with APIC/IOAPIC operations, and supplies the private
synchronous RAM guarantees required by the ISA entry helper. The supported profile is
Long64/CPL0, Running, IF=1, clear STI shadow, same-CPL present interrupt gate,
IST=0, and the underlying helper's descriptor/state constraints.

No eligible APIC vector, IF=0, blocking STI shadow, or TPR ineligibility leaves
the request and CPU state untouched. An ISA `OutsideProfile` result does not
acknowledge the request. A `DeliveryAborted` may leave a committed stack-write
prefix; the session becomes terminal, APIC remains pending, and retry is
blocked. Once IDT entry succeeds, CPU entry and APIC acknowledgement remain
committed even if the one-instruction handler run faults or is unsupported. On
successful level entry, Remote IRR remains set through handler execution and
clears only on EOI.

## Boundaries

This is one caller-driven, flat identity diagnostic path. It does not add
automatic instruction-boundary polling, general event queues, paged interrupt
entry, MOV SS/NMI handling, HLT wakeup, IRET/guest EOI execution, JIT exit
integration, board registration or Linux acceptance. Parent S4-27 and Stage 4
remain open.
