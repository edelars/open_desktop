# S3-20ez: address64 scaled RAX-indexed no-base SIB Dword loads

## Scope and semantics

This bounded runtime slice admits only the seven-byte unprefixed forms
`8B 04 45/85/C5 disp32` (`MOV EAX,[RAX*scale+signed disp32]`) for scales 2,
4, and 8. The SIB has no base, RAX as index, Qword address size, and Dword
transfer width. The effective address is `(original full64 RAX * scale +
sign-extended disp32) mod 2^64`; multiplication and addition wrap, and the
address uses the original RAX before EAX writeback. One contiguous checked
four-byte read writes EAX and zero-extends RAX. Other GPRs/RFLAGS are
preserved, and successful retirement advances RIP by seven bytes.

The JIT source/site fixture is
`memory_load_v2::tests::ir_dword_rax_index_no_base_sib_scaled_disp32_load_binds_all_source_bytes_to_its_site`.
The host fixture is
`tests::s3_20ez_rax_index_no_base_sib_scaled_disp32_dword_load_uses_original_scaled_rax`.
Harness S3-34ck pins both identities.
