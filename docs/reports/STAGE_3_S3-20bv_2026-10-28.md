# S3-20bv: address32 indexed SIB with RBP base and RSI/RDI index

## Implemented slice

The borrowed memory compiler and dispatcher admit only singleton qword MOV load/store forms `67 48 8B/89 /r sib disp8|disp32`: ModRM `mod=01/10,r/m=100`, SIB base RBP, index RSI or RDI, scale 1/2/4/8, data register RAX..RBP, instruction length 6/9 bytes. `mod=00` with SIB base field 5 is the no-base encoding and is not admitted by this profile.

Effective-address semantics remain owned by the decoder's `MemoryOperand::access_address_48`: `(low32(old RBP) + low32(old RSI/RDI) * scale + signed displacement) mod 2^32`, zero-extended for the contiguous qword transfer. Data=RBP uses the pre-instruction value for address calculation and store payload; a load commits RBP only after a successful read. RSI/RDI remain unchanged. This is the borrowed fixture dispatcher path; it does not add a production memory owner/MMU integration.

## Evidence

The JIT descriptor tests and host differential matrix cover load/store × six data registers × two index registers × four scales × signed disp8/disp32 edge values. Host comparisons use independent target formulas and check complete CPU/RAM state, callback address/width/count, and retirement against direct V2, shared IR, and the interpreter.

Additional exact-profile host cases cover low-32-bit base/index truncation and wrap, contiguous qword access across 4 GiB, displacement-byte identity, architectural and backend errors without partial commit, successful store followed by STOP, entry STOP/stop-RIP/zero-budget guards, partial byte windows, unsupported no-base neighbor encodings, and actual-RIP continuation from a 6-byte instruction to a 9-byte instruction without replay.
