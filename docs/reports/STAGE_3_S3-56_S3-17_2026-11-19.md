# S3-56 cold FIFO and generic on the recovered S3-17 corpus

The same signed release binary ran FIFO and generic register dispatch on
1,010 S3-17 inputs and 1,322 recorded visits. The trace SHA-256 and every
ordered fixture byte match the historical S3-35a inputs. The original
`cases.txt` pathname list is unavailable. The replacement list has its own
SHA-256 and requires `cold-first-run --relocated-s3-17-paths --case-list`.
The benchmark validates the historic trace, the identities, order and raw
hashes of the fixtures, the expected outcomes and retirements, and the
native-only eligibility of generic dispatch before collecting timings.
[S3-17 input recovery](STAGE_3_S3-17-lookup-measurements-2026-10-26.md#exact-input-recovery-2026-11-19)

Each process ran 20 paired JIT and interpreter samples on the same case
sequence, with equal sweep counts within a pair and a 200 ms floor per
interval. Process order was FIFO/generic, generic/FIFO, FIFO/generic. All
240 intervals met the floor (minimum 200.006 ms). Calibration selected
317–330 sweeps per interval across the six processes. Each JIT sweep includes
fresh arena/cache initialization and timed dispatch calls. Fixture loading,
admission, oracle preparation, state resets, validation and teardown were
outside the intervals. Both JIT modes retired all 2,990 instructions per
sweep natively, with zero interpreter steps or fallback helper calls. For
generic, the helper count follows from rejecting bare NOP at admission and
checking zero interpreter retirement on every successful dispatch. Both
modes had 2 hits, 1,320 misses/compilations/publications, 1,304 evictions and
1,322 native block executions per sweep. They had identical high-water
counts of 16 entries, 21,640 code bytes, 50,124 logical metadata bytes and
65,536 bytes of reserved arena.

The generic/FIFO ratios of JIT medians were 1.104, 1.098 and 1.049. Dividing
the medians of the paired JIT/interpreter ratios gives 1.101, 1.094 and
1.085. The generic paired-ratio range was above the FIFO range in all three
rounds. Cache counts matched, and timings include the benchmark wrappers.
Phase attribution remains open. Both JIT modes were slower than the paired interpreter in
every interval pair.

Against historical S3-35a FIFO on the same inputs, the first two generic
ranges were higher and the third overlapped the historical ranges. The
interpreter medians moved from 0.164–0.166 ms to 0.619–0.639 ms across builds.
The historical JIT/interpreter ratio therefore includes a substantially
different interpreter baseline. Use the same-binary results above for the
comparison between dispatch routes. The separate five-case S3-14 comparison
includes cold, warm and interpreter results on a common corpus, and compares
warm against S3-36b on those same five inputs.

## Host and reproduction

Apple M3 Max (Mac15,11, 14 cores), macOS 26.7.1 (25G241), rustc 1.99.0,
`aarch64-apple-darwin` release. The measured build used the `5275d67` export,
the archived candidate patch and a measurement-only QoS hook. The ad-hoc
signature enabled Hardened Runtime and `allow-jit`. Every measured process
reported UID 501, nice −5 and user-interactive QoS (`0x21`). CPU idle over 60
probes during the series ranged from 33.1% to 89.5%, with a median of 60.7%.
Two earlier attempts were excluded after sustained drops to 0% idle. Before
the retained series, both modes rejected a missing opt-in, a changed trace,
a swapped or shortened list and a fixture with changed raw bytes. All ten
rejection runs exited without producing a measurement report.

The archive contains the candidate patch, build and signing records, input
digests, launch commands, load logs, raw reports and replay scripts. Extract
`offline_audit.py`, `audit.py` and `stage_qos.py` from its `files` into one
scratch directory and run `python3 offline_audit.py /path/to/the/archive`.
The replay output matched the live audit byte for byte. Use the recovered
S3-17 input archive and the commands in the benchmark guide for a fresh run.
This is a cold native-register workload. The result leaves Stage 3
acceptance and the deferred physical checks open.
