# S3-20em: exact absolute SIB disp32 Dword store

## Scope and semantics

This runtime slice admits only the seven-byte unprefixed singleton
`89 04 25 id` (`MOV [disp32],EAX`): a SIB operand with no base or index,
scale 1, Qword address size, and Dword transfer. The decoder-owned signed
disp32 forms the 64-bit absolute effective address. With displacement `-4`,
EA is `u64::MAX-3`; one checked four-byte write ends at `u64::MAX` and
stores the low 32 bits of RAX. The instruction retires at `A+7`. Displacements
`-3`, `-2`, and `-1` fail checked-range validation before the write
callback. Prefixes and neighboring encodings are not included.

The exact JIT identity is
`memory_load_v2::tests::ir_dword_absolute_sib_disp32_store_binds_all_source_bytes_to_its_site`.
Its fixture binds nine signed displacement representatives and every encoded
displacement byte to the expected source/site metadata. The exact host
identity is
`tests::s3_20em_absolute_sib_disp32_dword_store_uses_signed_absolute_address`.
The fixture checks the `-4` address/payload, one callback and committed write,
unchanged GPRs/RFLAGS, RIP `A+7`, entry STOP/budget without memory access,
range-fault no-callback behavior, and injected backend-error state atomicity
with a successful retry. A callback-triggered STOP follows the committed
write; re-entry does not perform a second write.
