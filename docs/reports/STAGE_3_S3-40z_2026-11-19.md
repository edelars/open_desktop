# S3-40z interpreter RUN at budgets 0, 1 and 2 on M1 Pro

The same public RUN driver compared historical `d24865d` and current
`5275d67` on the two frozen S3-34a sequences. Each sequence has 1,200
inputs. Every comparison holds the sequence and budget fixed. The driver
checks the CPU state, RAM, ordered memory accesses, defined flags, exact
retirement count and budget exit against the expected instruction prefix.
[Earlier interpreter controls and corpus](STAGE_3_S3-40m_2026-11-19.md)

Six paired process rounds alternated build and sequence order. Each
process used all six permutations of the three budget sides. The pilots
selected 4,374,000 and 4,339,200 calls per interval, respectively. The
retained series contains 432 intervals and 1,882,051,200 RUN calls. The
shortest timed interval was 80.565 ms, above the 45 ms floor.

The current build took longer in every paired round at every budget.
The zero-retirement gap was 5.3 ns in both sequences. At one retirement,
the gap was 80.7 and 80.2 ns. At two retirements, it reached 157.9 and
157.5 ns. The measured gap grows once the path executes guest
instructions. Attribution among RUN control, decode and execution stages
remains open in ISSUE-521. These results cover the two bounded sequences
and the runs on this M1 Pro.

## Environment and reproduction

MacBookPro18,3, Apple M1 Pro, eight logical CPUs, macOS 14.6.1 (23G93),
Xcode 15.4 (15F31d), SDK 14.5, rustc and Cargo 1.99.0, Python 3.12.5. The
signed ARM64 release binaries had minimum macOS 14.0 and used the
standard Rust Apple ARM64 target CPU with LSE. Both passed strict
signature verification with Hardened Runtime and `allow-jit`. All 14
processes, including the two pilots, recorded UID 501, nice −5 and QoS
`0x21`. The 24 preflight probes had 84.7–99.1% CPU idle. During scoring,
32 probes gave 73.1–94.3% CPU idle, with a median of 86.45%.

Extract archived `files` into a scratch directory and place the harness
scripts under `work/tmp/s3-40z-run-budget/` in a repository with both
pinned revisions and the S3-40m and S3-40w input archives. Use an isolated
Cargo home with the lockfile dependencies. Build from the harness
directory with these settings.

```sh
export MACOSX_DEPLOYMENT_TARGET=14.0
unset RUSTFLAGS CARGO_ENCODED_RUSTFLAGS CARGO_BUILD_RUSTFLAGS
unset CARGO_TARGET_AARCH64_APPLE_DARWIN_RUSTFLAGS
zsh build.sh historical
zsh build.sh current
```

Use a fresh name with `python3 run.py run-NAME` and monitor host load.
The archived runner checks the effective priority in every process.
`python3 offline_audit.py /path/to/evidence.json.gz` reproduced the
saved audit both on the M1 Pro and after transfer. The archive retains
all intervals, raw logs, build records and comparison inputs.
