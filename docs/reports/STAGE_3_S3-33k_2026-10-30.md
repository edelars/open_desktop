# Stage 3 S3-33k: exact native MOV RAX,sign-extended imm32

## Scope

S3-33k adds a bounded opt-in uncached profile for bare `48 C7 C0 id`, and only
that seven-byte encoding. Admission requires decoder-owned W64 `MovImmediate`
to RAX, `/0`, exact instruction length and opcode/register bytes, and agreement
between the decoded sign-extended value and the four little-endian source bytes.
The decoder-owned value is retained for lowering. The existing `48 B8 imm64`
profile remains unchanged, and its exact encoding is outside the new selector.

Lowering is Constant→WriteGpr(RAX) with one instruction commit. It preserves
other GPRs, incoming full RFLAGS/definedness and pending flag-writer state. It
emits no arithmetic, data-memory, or helper operation. Host differential
coverage includes preceding register ADD/CMP writers, MOV, and distinguishable
JZ/JNZ consumers. The host also checks eager/candidate execution over eight
representative immediates and varied incoming RFLAGS, plus MOV;NOP native to
interpreter fallback parity, budget boundaries, and STOP before entry and at
RIP+7. The compiler gate asserts that MOV;NOP exits with `NeedInterpreter`.
Eager and demand-flags candidate compilation and dispatch use separate
uncached APIs.

## Evidence and limits

This exact `48 C7 C0` form has no physical x86 oracle in the current fixtures.
The result therefore rests on decoder-owned metadata, the exact source-byte
admission, and local interpreter differential evidence. The sampled immediate
set is representative and includes sign-boundary, endian, bit-pattern, and
high-bit cases; it is not an exhaustive walk of all 2^32 values.
