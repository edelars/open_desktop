# S3-20ex: address64 RAX-indexed no-base SIB Dword load

## Scope and semantics

This bounded runtime slice admits only the exact seven-byte unprefixed form
`8B 04 05 disp32` (`MOV EAX,[RAX+signed disp32]`). The SIB has no base,
RAX as index, and scale 1; the transfer width is Dword and address size is
Qword. The effective address uses the original full-width RAX plus the
sign-extended disp32 with wrapping `u64` arithmetic. One contiguous checked
four-byte read writes EAX and zero-extends into RAX; successful retirement
advances RIP by seven bytes. Other GPRs and RFLAGS are preserved.

The JIT source/site fixture is
`memory_load_v2::tests::ir_dword_rax_index_no_base_sib_disp32_load_binds_all_source_bytes_to_its_site`.
The host fixture is
`tests::s3_20ex_rax_index_no_base_sib_disp32_dword_load_uses_original_rax`.
Harness S3-34ci pins both identities.
