# S3-20ey: address64 RAX-indexed no-base SIB Dword store

## Scope and semantics

This bounded runtime slice admits only the exact seven-byte unprefixed form
`89 04 05 disp32` (`MOV [RAX+signed disp32],EAX`). The SIB has no base, RAX
as index, and scale 1; address size is Qword and transfer width is Dword.
The effective address uses the original full-width RAX plus sign-extended
disp32 with wrapping `u64` arithmetic. One contiguous checked four-byte write
stores low32 of that original RAX. RAX, other GPRs, and RFLAGS are preserved;
successful retirement advances RIP by seven bytes.

The JIT source/site fixture is
`memory_load_v2::tests::ir_dword_rax_index_no_base_sib_disp32_store_binds_all_source_bytes_to_its_site`.
The host fixture is
`tests::s3_20ey_rax_index_no_base_sib_disp32_dword_store_uses_full_rax_address_and_low_dword_data`.
Harness S3-34cj pins both identities.
