# S3-20d report: bounded signed displacement MOV forms

Date: 2026-10-27

## Implemented local slice

- Extended the existing production V2 qword load/store profiles to direct
  base and supported SIB forms with ModRM `mod=00/01/10`: no displacement,
  signed disp8, and signed disp32. Exact source lengths are 3/4/7 bytes for
  direct addressing and 4/5/8 bytes with SIB.
- The immutable compiler artifact and host metadata carry a bounded
  `[u8; 8]` source buffer plus explicit length. `next_rip` comes from the
  existing `long_decode::decode` result.
- Added one shared `MemorySiteV2` validator for decoded-site profile, raw
  ModRM/SIB/source-shape consistency, and host/runtime admission. The validator
  does not reinterpret displacement bytes or calculate addresses; the decoded
  `MemoryOperand` and `access_address_48` remain the sole semantic source.
- Unsupported forms remain rejected: ModRM mod11, RIP-relative/base-less,
  no-index SIB, RSP/RBP/R8+, extra prefixes or address-size override, and tails.
  V2 helper ABI, V1 tags, load/store safety boundaries, and commit ordering are
  unchanged.

## Verification

- `cargo test -p od-jit --offline` — 109 passed. Compiler tests exhaustively
  cover the mod00 SIB register/base/index/scale combinations for both
  operations, validate direct and SIB site shapes across mod00/01/10, and test
  disp8 `-128/-1/0/1/127`, disp32 min/max and neighbors, equivalent
  disp8/disp32 effective addresses with different next RIPs, and rejected
  encodings.
- `cargo test -p od-host --offline` — 40 passed. The ARM64 native differential
  matrix runs 1,632 success cases across load/store, direct/SIB, all three ModRM
  modes, and supported registers/scales. It compares full CPU/RAM snapshots
  with `od_isa::execute::step`; additional cases cover signed displacement
  boundaries, store bytes, aliases, wrap-to-canonical, final noncanonical and
  endpoint overflow, Unmapped/PermissionDenied/Backend failures, no-effect
  guards, and late STOP after one committed store.
- `cargo check --workspace --all-targets --offline` — passed.
- `cargo fmt --all -- --check` — passed.
- `git diff --check` — passed after the final documentation refresh.
- `graphify update .` — passed after code and documentation updates.
