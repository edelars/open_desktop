# S3-20cv — exact RIP-relative dword checked-memory load

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `2876f9b` adds only the six-byte singleton `8B 05 id`
(`MOV EAX,[RIP+disp32]`) to the shared typed-IR dword-load path. The decoder's
`NextRip` is `A+6`; effective address calculation uses this decoded next
instruction address with the signed disp32. Source bytes bind to the site and
the PC map has one guest instruction boundary at `A+6`. This does not admit
other RIP-relative/dword forms or a general memory family.
