# S3-34dt Generated cache failure reduction for a GPR mismatch

The NativeRegisterV1 test harness can reduce one generated cache-trace
failure class. It replays the saved prefix from an empty cache, checks
the original mismatch twice, and then tries zeroing incoming GPR values.
Each accepted input preserves the code and branch targets, flags input,
cache bindings and counters, exit, retirement, budget, terminal RIP and
the set of differing GPRs. The interpreter and uncached results must
agree on each trial. The cached result can differ only in those GPRs.

The reducer keeps the original failure envelope and writes the reduced
input and fresh interpreter, uncached and cached observations to a new
file. The reduced record binds the original artifact bytes. Replay checks
both trials against all three saved observations. The existing retained-hit
reducer and canonical gate identities still apply.

## Signed verification

The signed optimized ARM64 unit test executable targeted macOS 14.0 and
ran on local macOS 26.7.1 (25G241) with Rust 1.99.0. The test bundle used
base `963a0f6` and the exact patch archived below. All four selected Rust
gates passed. The generated self-check replayed two real cached prefix
steps, altered one observed GPR in the test, then required successful
reduction and replay and rejection of a mutation to each backend record.
A separate ordinary invocation rejected a deliberately altered failure
with exit 101 and created no reduced artifact.

The positive check injects an observation. A naturally occurring
generated mismatch and reduction for other generated failure classes
remain unverified. Broader S3-34.2 acceptance remains open.

## Replay and reduction

For the exact signed test binary, use the gate
`tests::native_register_v1_corpus::cached_failure_trace_replays_saved_prefix_and_failure`.
Set `OD_JIT_NATIVE_REGISTER_V1_CORPUS_DIR` to a scratch artifact directory and
`OD_JIT_NATIVE_REGISTER_V1_GENERATED_GPR_FAILURE` to the saved failure. After
successful reduction, `generated-gpr-reduction-v1.json` appears in the artifact
directory. To replay, keep the original failure variable set and also set
`OD_JIT_NATIVE_REGISTER_V1_REPLAY_GENERATED_GPR_REDUCTION` to the reduced file.
The archived `verify.sh` records the signed verification commands.
