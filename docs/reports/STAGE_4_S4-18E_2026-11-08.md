# S4-18e: bounded paged MOV DS/ES/FS/GS, 2026-11-08

Статус: реализовано и проверено локально; независимое ревью без P0–P1, замечания P2/P3 исправлены (см. «Ревью»).
S4-18 и этап 4 остаются открытыми.

Перенесено из линии `stage4` (коммиты paged MOV DS/ES/FS/GS и матрица segment load) и переписано
поверх дизайна `main`: сами загрузчики дескрипторов (`load_*_gdt_selector`, `read_gdt_descriptor`)
уже были в `main`, поэтому перенесены только paged-обёртки и RAM-only память (`PagedDescriptorMemory`).

## Что сделано

- `od-isa`: `step_paged_mov_ds/es/fs/gs` (общее тело `step_paged_mov_sreg`) — профиль как у
  LGDT/LIDT/LTR; точные байты `8E D8/C0/E0/E8`; fetch только внутри страницы RIP.
- `od-machine`: `step_paged_mov_ds/es/fs/gs` (+ `PagedSegmentMovReport`, `PagedSegmentMovError`) в
  `paged_descriptor.rs`; `PagedDescriptorMemory` читает 8-байтовый дескриптор (`DescriptorTable`
  origin) и пишет один байт accessed-бита, оба RAM-only. Дескриптор через границу страницы —
  `Unsupported` с `CrossesPage`.

Источник: Intel SDM Vol. 3A §3.4.5 и Vol. 2 (`MOV Sreg`). Не физический oracle.

## Тесты

`tests/paged_segment_mov_step.rs` (14 тестов × 4 регистра): успешная загрузка (cache, selector,
`fs_base`/`gs_base`, RIP; A-бит записан одним байтом после D leaf, порядок callbacks); уже accessed
дескриптор без записи и без D; readable code, conforming code с RPL 3, DPL3 data с RPL 3; отказы
дескриптора (за пределом GDT, not present, system, execute-only code, RPL > DPL) без изменений
CPU/памяти; null/LDT селекторы, другой ModRM, префиксы (66/67/F0/F3/2E/48) и отсутствующий cache —
`Unsupported`; неканонический/переполняющийся адрес дескриптора (`#GP(selector)` до walk); CPL3,
профиль CR0/GDTR/STI, Halted и RIP у конца страницы до любого walk; read-only GDT (`#PF` W,
CR2 = адрес+5), already-accessed на read-only без записи, not-present GDT; последний допустимый
offset 0xff8 и пересечение страницы на 0xff9; дескриптор вне RAM, в ROM, в MMIO (без вызова
устройства) и в частично доступном RAM; alias дескриптора со страницей таблиц (порядок A → D →
accessed-байт, без потерь).

## Не входит и открыто

Null-селекторы (архитектурно допустимы в 64-битном режиме, здесь `Unsupported`), LDT, SS/CS,
system descriptors, TLB/JIT, CR0.WP=0 профиль. Снимок cache после изменения GDT и композиция
LGDT → MOV Sreg отдельно не тестируются (были в `stage4`).

## Ревью

Независимое ревью выполнено агентом Claude Opus (effort medium) по `AGENTS.md`. P0–P1 не найдено:
ModRM, порядок проверок профиля, коммит состояния только после чтения и записи accessed-бита,
коды ошибок и RAM-only семантика корректны. P2: матрица тестов была беднее `stage4` — добавлены
alias, границы 0xff8/0xff9, префиксы, неканонические адреса, ROM/MMIO/частичный RAM, readable/
conforming/DPL3 и Halted. P3 исправлены: doc-комментарий про GDTR, уточнение «Unsupported после
fetch walk», допуск чтения/записи дескриптора в адаптере теперь по флагу `segment_load` вместо
сравнения имён, формулировка про alias заменена точным порядком эффектов (аналог `TableAlias` из
LTR не нужен: потерь A/D нет).
