# Stage 3 S3-20bt: address64 indexed SIB with RBP base and RSI/RDI index

## Implemented profile

Added the exact singleton `48 8B/89 /r sib disp8|disp32` profile: ModRM `mod=01/10,r/m=100`, SIB base RBP, index RSI or RDI, scale 1/2/4/8, data RAX..RBP, and instruction lengths 5/8. ModRM `mod=00` with SIB base field 5 remains the separate no-base encoding. The decoded `MemoryOperand::access_address_48` remains the sole effective-address implementation: old full RBP + old full RSI/RDI×scale + signed displacement, wrapping u64. Loads commit the destination only after a successful read; stores use the pre-instruction source value.

Exact admission is wired through the checked block builder, shared IR verifier, direct V2 descriptor/source validation, runtime source matcher, and bounded dispatcher. This does not widen generic register whitelists, no-base forms, pairs, V3, prefixes, or production owner/MMU integration.

## Evidence

- The JIT descriptor matrix covers load/store, data RAX..RBP, both index registers, all four scales, and signed disp8/disp32 boundaries. It checks direct V2/shared IR descriptor agreement, immutable source bytes, decoded base/index/scale/displacement, instruction length, and the independent `access_address_48` target. No-base, address32, extra-prefix, and truncated source neighbors are rejected.
- The host matrix compares direct V2, shared IR, and interpreter execution across the full supported SIB matrix and verifies full CPU/RAM parity, callback address/count, and retirement.
- Exact-profile fault cases verify #SS for noncanonical RBP starts and canonical starts whose qword crosses into the noncanonical range, with no callback or instruction commit. A low-GPR base control using the same RSI index is #GP. A separate canonical target at `u64::MAX-3` reports AddressOverflow without a callback.
- Architectural and backend load/store failures preserve CPU and RAM state. Backend failures retain exact target and qword callback width. A successful indexed store that raises STOP commits the exact eight-byte payload once, retires once, and returns at the five-byte instruction's next RIP.
- Two immutable disp32 sources differing only in byte 7 produce the independently expected targets `0x100` and `0x0100_0100` in direct V2 and shared IR.
- Dispatcher coverage resumes from the actual RIP across a five-byte disp8 singleton and an eight-byte disp32 singleton, with one callback per instruction and no replay. Entry stop-RIP, cooperative STOP, and zero budget make no callback. Partial windows 1..4 and 1..7 return the fixture boundary without publication or memory effects.
- Historical negative fixtures that used the newly supported RBP+RSI shape were changed to an unsupported no-index SIB or an extra-prefix neighbor. Existing no-base cases and prior profiles remain tested.
