# S3-40ai Historical interpreter RUN residual after S3-40ah

The frozen comparison uses the unmodified interpreter and decoder
from `d24865d` and `de1f446`. The current revision includes the
RDTSC, CPUID, SYSCALL and SYSRET predicate change adopted in
S3-40ah. The shared driver and workload match S3-40ag. The
separate untimed checks verified the 2,400 S3-34a MOV inputs at
budgets 0, 1 and 2 and an unmapped instruction at budget zero.
Both builds passed CPU state, defined flags, RAM, ordered data
callback, retirement and budget-exit checks on M1 Pro.
[Previous historical comparison](STAGE_3_S3-40ag_2026-11-19.md)

## Results

Six paired rounds alternated the two builds and the two instruction
sequences. Each process ran all budget permutations and used fixed
counts of 4,374,000 and 4,339,200 RUN calls per interval. The series
retained 432 intervals and 1,882,051,200 RUN calls. The shortest
interval was 80.568 ms against a 45 ms floor.

The absolute columns show pooled medians [min, max] in nanoseconds
per RUN call. The last column shows the median [min, max] of six
current/historical ratios of process medians.

The current/historical ratio at budget 2 was 1.8436–1.8499.
The difference in pooled medians was 117.6–118.0 ns at
budget 2, 58.1–60.7 ns at budget 1 and
4.7 ns at budget 0. These results cover both
complete RUN workloads. ISSUE-521 remains open.

## Environment and reproduction

MacBookPro18,3, Apple M1 Pro, eight logical CPUs, macOS 14.6.1 (23G93),
Xcode 15.4, Rust and Cargo 1.99.0, and Python 3.12.5. The native ARM64
release builds use minimum macOS 14.0. Both passed strict signature checks
with Hardened Runtime and `allow-jit`. The machine was on AC power.
All twelve timing processes recorded UID 501, nice −5 and QoS `0x21`.
The 24 preflight probes measured 95.3–99.2% idle CPU (median 98.8%).
The 30 in-run probes measured 84.2–86.8% (median 86.5%).

Extract the archived harness files into
`work/tmp/s3-40ai-final-historical-residual/` in a checkout with both
pinned builds and the S3-40m, S3-40w and S3-40z archives. The archived
`README.md` gives build, correctness and measurement commands.
`python3 offline_audit.py /path/to/evidence.json.gz` validates the
archive and recomputes the table from the raw intervals.
