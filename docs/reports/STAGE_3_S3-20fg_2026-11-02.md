# S3-20fg — RAX-base disp8 Dword store

**Date:** 2026-11-02. **Status:** implementation and independent static review complete; behavioral checks deferred.

## Scope

Add the exact unprefixed three-byte `89 40 ib` form to the existing typed-IR
Dword-store path. The effective address is full old RAX plus sign-extended
disp8 modulo `2^64`; the data is the low Dword of old RAX. RAX, other GPRs and
RFLAGS are preserved, and successful execution advances RIP to `A+3`. No
additional addressing family or owner/MMU integration is included.

## Implementation evidence

- Added exact RAX disp8 profile checks to compiler IR admission and runtime
  source/site validation.
- Added the exact byte family to both the `CheckedDwordStore` block byte
  whitelist and the host executable publisher whitelist.
- Added a JIT provenance case covering all 256 displacement bytes, `A+3` PC-map
  boundary, forged site fields, truncation, trailing bytes, prefixes and
  neighboring opcode/base/source forms. Updated the `89 00` case to check
  `89 40 00` as a site mismatch instead of an invalid encoding.
- Added a macOS/aarch64 host regression with interpreter parity, full-width RAX
  addressing, signed displacement edges, wrap and zero EA, guards with retries,
  callback STOP, backend error/retry, noncanonical #GP and address-range
  overflow cases.
- Independent `gpt-6.1-sol/high` review passed after the reviewer findings in
  the source-site neighbors and host fixture were corrected. No actionable
  implementation findings remain.
