# Stage 3 S3-20az report

## Scope and implementation

Added the exact singleton profile `48 8B/89 /r sib disp8|disp32`: ModRM `mod=01/10,r/m=100`, base RAX..RBX, index RBP, scale 1/2/4/8, data RAX..RBP, and instruction lengths 5/8. The previous no-displacement S3-20ay profile remains a separate exact branch. No generic index whitelist change, address-size override, stack/no-base base, other index, pair/V3, owner/MMU, Stage 2, or ISA behavior was added.

Direct V2, shared IR, runtime artifact validation, host publication, and bounded dispatch accept this same profile. Effective address calculation remains owned by the decoder's `MemoryOperand` and `access_address_48`: full-width `base + RBP * scale + signed displacement`, wrapping modulo u64. Runtime uses the immutable decoded artifact metadata and does not independently decode displacement bytes.

## Evidence

- The JIT descriptor matrix covers load/store × six data registers × four low bases × four scales × disp8 `-128/-1/0/127` and disp32 `MIN/-1/0/MAX`; direct V2 and shared IR metadata/source match. It rejects partial windows, other bases/indices, extra/reordered prefixes and unsupported displacement forms.
- The host matrix compares direct V2, shared IR and interpreter CPU/RAM state, exact callback address/count/width, and retirement for the same profile. Its independent oracle is `base.wrapping_add(rbp.wrapping_mul(scale)).wrapping_add_signed(displacement)`. High RBP bits and aliases `data=RBP`/`data=base` use pre-instruction values.
- Exact-profile faults cover #GP at noncanonical start/end with no memory callback or architectural commit, endpoint AddressOverflow, and backend errors with target/width and no guest/RAM commit. A successful store followed by callback STOP retains the qword write once.
- Two immutable disp32 sources differing only in the last displacement byte execute at distinct independently expected targets. Bounded dispatch splits after the 8-byte singleton and resumes from returned RIP through NOP and the existing pair without repeating the first read. Partial windows 1..7 return the fixture boundary with no blocks or memory effects.
- The no-displacement S3-20ay descriptor and host profile tests remain green.
