Each gate is assigned to `local_lifecycle` and uses the exact
`cargo test --offline -p od-host --lib <identity> -- --exact --test-threads=1`
invocation. The source manifest now fingerprints
`crates/od-host/src/session.rs` alongside the existing Rust gate sources.

The dedicated harness self-check verifies each gate appears once in the gate
registry, manifest, local steps, and synthetic summary. It checks the exact
Cargo arguments and source pin, and rejects any omitted manifest gate, source
pin, or execution record, as well as zero-match, ignored, failed, wrong-identity,
and wrong-argv evidence. The general harness summary checks also require every
session gate.

At S3-34dp integration, the manifest had 312 Rust gates (298 acceptance and
14 lifecycle), 330 local steps, and 140 harness self-test identities. The
current manifest after S3-34dr has 324 gates (306 acceptance and 18 lifecycle),
342 local steps, 149 self-tests, and 18 source pins. Each of the four exact
Rust gates passed 1/1, and the pinned S3-38e fail-closed harness self-test
passed with exit 0. The full Stage 3 harness, build, and formatting checks were not run.
Mini/physical-x86 checks remain unavailable after the documented SSH timeout;
M1 remains deferred.
