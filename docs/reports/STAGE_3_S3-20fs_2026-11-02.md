## Контракт

Поддерживается только ровно трёхбайтовая форма `[89,41,ib]` без prefixes: `MOV [RCX+sign_extend(ib)],EAX`. Address size — Qword, operand size — Dword, base — RCX, index отсутствует, scale равен 1. Signed displacement — `i64::from(source[2] as i8)`. Effective address вычисляется из полного исходного RCX с wrapping addition modulo 2⁶⁴; low32 RCX не используется. Payload — low32 исходного RAX, независимо от вычисленного EA.

Успешный store выполняет одну checked contiguous запись шириной 4, сохраняет полный RAX, RCX, остальные GPR и RFLAGS и продвигает RIP до `A+3`. Canonicality и range preflight проверяются для вычисленного EA и всей ширины записи. Ошибки guest/backend не должны частично менять RAM или CPU; успешные retry и callback STOP после commit без replay сохраняются. Не входят RCX disp32, addr32, SIB и альтернативные базы/source registers.

## Планируемое покрытие

- JIT: все 256 disp8 байтов, signed metadata, точный source/site binding, forged site fields и PC-map boundary `A+3`; уже поддержанные Store формы остаются distinct sites, unsupported encodings остаются закрыты.
- Host: полный RCX против low32 decoy; независимый low32 RAX payload и неизменный full RAX; signed displacement, нулевой и unaligned EA, canonical upper-half и арифметика вокруг `u64::MAX`.
- Ошибки и границы: noncanonical вычисленный EA, crossing canonical boundary и range overflow до вызова write callback; write failure с retry; отдельный successful retry после каждого entry guard; callback STOP после write без replay.
- Fetch: ошибка чтения displacement byte должна распространяться как ошибка, без подстановочного значения или fallback.
