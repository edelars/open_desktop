# Stage 3 S3-20ck: RIP-relative qword MOV with RSI/RDI data

Implemented the bounded singleton forms `48 8B 35/3D disp32` and `48 89 35/3D disp32`: ModRM `mod=00,r/m=101`, data RSI/RDI (`reg=6|7`), Qword address/data, exact length seven. The effective address remains decoder-owned through `AddressBase::NextRip` and the signed displacement. No SIB, address override, additional prefix, other data register, pair, V3 or generic RSI/RDI arithmetic/read support was introduced.

The exact profile is admitted by direct V2, shared IR and bounded dispatch. Runtime source-byte matching binds all seven instruction bytes to the decoded site, including the final disp32 byte. RSI/RDI writes remain scoped to the immediately preceding matching checked load and temporary; checked stores accept RSI/RDI only with this exact decoded address shape.

Coverage added or extended:

- JIT descriptor coverage compiles both operations with data RSI/RDI across signed disp32 edge values and compares direct and shared-IR sites. It rejects descriptor mutations to displacement, base/source identity, index, scale, address/data size, and instruction length; rejects mismatched final disp32 bytes; and checks every partial source window of length 1..6.
- Host coverage executes load/store × RSI/RDI with the direct executor, shared IR executor and interpreter, including identical instruction bytes at different guest RIPs with independently mapped targets. State and callback comparisons cover full CPU/RAM, flags, callback counts/widths, RIP and retirement.
- Dedicated direct/shared-IR checks inject architectural faults and backend failures into all four RSI/RDI forms. They verify the exact guest fault address/error, remaining budget and retirement, one attempted callback, and unchanged CPU/RAM. Zero-budget guards make no callback and preserve state. The qword store+STOP scenario verifies one complete write and a single commit for both RSI and RDI in direct V2 and shared IR. Noncanonical RIP-relative loads verify #GP with no memory access.
- A second executed artifact pair differs only in the final disp32 byte; both direct and shared IR accesses reach separately mapped targets and match the interpreter for loads and stores.
- Bounded dispatch covers RSI data on the seven-byte singleton, then resumes at actual RIP through the NOP and frozen pair without repeating the first access; budgets 0..4 are compared with the interpreter.
- Existing frame 176, emitted block cap 4096 and 10×MOV size 3868 regressions remain in the JIT suite.
