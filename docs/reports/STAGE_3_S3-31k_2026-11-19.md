# S3-31k Explicit arguments for a resolved warm JIT cache hit

The experiment uses `de1f446` and its S0-09 Session with the FIFO
executable cache. The stock resolved-hit path builds a stack
environment containing references to the memo and selected index.
The candidate passes the cache, selected index and memo address
directly. The existing hit count, LRU index repair and warm
transition rules apply to both builds. The observer ends its
measurement before a cache error is returned.
[Previous memo experiment](STAGE_3_S3-31j_2026-11-19.md)

The signed M1 Pro image goes from ten to four caller instructions
through the hit call. Four closure pointer loads disappear before the
callee's FIFO branch. The candidate's FIFO return carries the hit
index without loading the memo. The archived disassembly binds these
observations to the exact signed binaries. Xcode 15 defaults to
decimal immediate operands, so the harness requests
`llvm-objdump --print-imm-hex` before applying the same instruction checks.

Both builds passed six targeted Rust tests covering repeated and
alternating RIPs, FIFO order, eviction and LRU rebasing, STOP, and
observer ordering on success and counter overflow.

## Warm results

Six rounds used each ordering of stock, candidate and a second run of
the same signed stock file. Each process collected eight alternating
JIT/interpreter pairs for each of the seven S3-31i profiles. The paired
comparison uses JIT times first. For the last column, each process
takes the median of its eight JIT/interpreter ratios. The candidate
and stock medians are then divided within each round. Each column
reports median [min, max] across the six rounds.

Adopt the explicit hit arguments. The paired JIT medians fell by
1.99% and 2.49% on the two long same-RIP profiles and by 2.62% and
3.25% on the two alternating-RIP profiles. Each of those candidate
ranges is below its same-file A/A range. The raw JIT ranges for
`same_1`, `same_3` and `three_64` include unity. The measured code
and logical metadata footprints match. ISSUE-520 remains open for
a direct comparison against the pre-memo dispatcher.

## Environment and reproduction

Apple M1 Pro, eight logical CPUs, macOS 14.6.1 (23G93), Xcode 15.4
and Rust and Cargo 1.99.0. Both native ARM64 builds target macOS
14.0 and passed strict ad-hoc signature checks with Hardened Runtime
and `allow-jit`. The machine was on AC power. Effective UID 501,
nice −5 and QoS `0x21` were verified in all scored processes.
The series retained 2,016 timed intervals. The minimum
was 57.209 ms against a 30 ms floor.
The 24 preflight probes measured 95.1–99.2% idle CPU, with
a median of 98.8%. The 37 in-run probes measured
84.5–86.6% idle CPU, with a median of 86.3%.

Extract the archived harness to `work/tmp/s3-31k-cached-hit-args/`
in a checkout with `de1f446` and the committed S3-31i archive.
The archived `README.md` includes build, untimed, monitor and
scoring commands. Use `offline_audit.py` with the archive to
recompute the results from the raw interval records and
recheck codegen, source, priority and binary bindings.
