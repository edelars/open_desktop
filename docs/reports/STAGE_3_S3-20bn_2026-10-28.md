# Stage 3 S3-20bn: address64 indexed SIB with RSI/RDI base and RBP index

## Scope

This slice adds singleton `48 8B/89 /r sib [disp8|disp32]` forms with ModRM `mod=00/01/10,r/m=100`, SIB base RSI or RDI, index exactly RBP, scale 1/2/4/8, data RAX..RBP, and exact lengths 4/5/8. Effective addresses use the existing decoder-owned `MemoryOperand::access_address_48`: old full-width base + old full-width RBP × scale + signed displacement, wrapping u64. RBP used as data remains a pre-instruction value until a successful load commits.

This is an exact profile exception. It does not widen the generic index whitelist and does not add address32, no-index/no-base, other base/index registers, prefixes, pair/V3, production owner/MMU, Stage 2/ISA, Mini, or performance behavior.

## Evidence

- JIT descriptor tests cover both operations, RSI/RDI bases, all four scales, six data registers, no-displacement, signed disp8 and signed disp32 boundaries; they verify exact decoded site/profile fields, direct and shared-IR compilation, source bytes, and partial/forbidden neighbors.
- Host parity compares direct V2 and shared IR with the interpreter for complete CPU state and RAM, callback address/count, and retirement across the base/data/scale/width/direction matrix. The independent target oracle uses the old full-width base and RBP values with wrapping u64 arithmetic. `data=RBP` source/index alias cases use the old RBP value.
- Host regressions cover u64 address wrap and two fixed-register disp32 artifacts that differ only in byte 7 and target different addresses.
- Dispatcher cases cover actual-RIP budget continuation across the 4/5/8-byte forms without replay, entry STOP and zero budget, store+STOP commit, partial windows, invalid neighbors, noncanonical start/end #GP without callbacks, AddressOverflow separately, and backend no-commit.
