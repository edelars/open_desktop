# S3-20et: exact addr32 RCX-indexed no-base SIB disp32 Dword load

## Scope and semantics

This runtime slice admits only the exact eight-byte Dword-load singleton
with exactly the `67` address-size override prefix and no other prefixes:
`67 8B 04 0D disp32` (`MOV EAX,[ECX+disp32]`). The address-size-32 SIB has
no base, uses ECX as its scale-1 index, and carries a signed disp32.
The effective address is
`zero_extend((low32(RCX) + signed_disp32) mod 2^32)`. The checked read is one
contiguous four-byte access, including the recorded case crossing the 4-GiB
boundary. EAX zero-extends into RAX, and the guest instruction boundary is
`A+8`. Other prefixes, scales, SIB shapes, and encodings remain outside this
exact admission.

The exact JIT fixture is
`memory_load_v2::tests::ir_dword_addr32_rcx_index_no_base_sib_disp32_load_binds_all_source_bytes_to_its_site`.
The exact host fixture is
`tests::s3_20et_addr32_rcx_index_no_base_sib_disp32_dword_load_uses_wrapped_ecx`.
Harness S3-34ce pins both identities.
