# Stage 4 S4-22a: caller-driven virtual clock and bounded RDTSC

## Результат

Принят ограниченный S4-22a. `VirtualClock` starts at zero, uses a fixed
non-zero `tsc_hz`, advances only through explicit caller requests in Runnable,
and converts time with `floor(now_ns * tsc_hz / 1e9)` using a wide intermediate.
Time and TSC overflow failures are atomic.

`DiagnosticVcpuSession::new_with_tsc` supplies the clock to bare Long64 RDTSC
while preserving the existing TSD/CPL rules and `rflags_defined`. Execution,
budgets, polling and host delays do not advance time.
