# S3-20dl — exact address-size-32 no-displacement SIB dword loads

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `f326e9f` adds exactly four four-byte singleton forms:
`67 8B 04 0B`, `67 8B 04 4B`, `67 8B 04 8B`, and `67 8B 04 CB`
(`MOV EAX,[EBX+ECX*1/2/4/8]`). The decoder-owned address-size-32 effective
address adds low32 EBX to low32 ECX times the selected scale, wraps to 32 bits,
then zero-extends before canonical-address checking. Each checked operation is
one contiguous four-byte read; the fixtures include a four-byte read crossing the 4-GiB
boundary. Writing EAX zero-extends into RAX. Source/site identity includes
the exact prefix and SIB scale, and the PC-map guest boundary is `A+4`.
Fixtures also cover fault, STOP, and budget behavior.
