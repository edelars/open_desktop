# S4-12b: bounded CPU-side MOV CR3

## Scope

This slice adds an opt-in Long64 CPU entry point for exact bare `0F 22 D8`
(`MOV CR3,RAX`). It requires a modeled initial CR3, CR0=`0x80010033`,
CR4=`0x20`, EFER=`0xd00`, CPL0 for successful execution, and physical width
36. A successful instruction commits the full accepted source value, advances
RIP by three, retires once, and returns a typed `Cr3Write` translation-context
effect even when the old and new values match. The call stops before another
instruction can fetch.

CR3 source bits above bit 35 fault with #GP(0); ignored low bits and PWT/PCD
bits are preserved. LOCK raises #UD only within this profile; other forms stay
unsupported. Concrete RFLAGS are preserved and arithmetic-flag definedness is
cleared. Legacy execution remains opt-in and refuses CPU state containing CR3.
State adapters that cannot represent CR3 now reject it, and the diagnostic
translation snapshot bridge rejects disagreement between CPU-owned CR3 and its
explicit argument.

The machine does not yet apply the effect to its active translation snapshot.
S4-12c owns that integration, so parent S4-12 remains open.
