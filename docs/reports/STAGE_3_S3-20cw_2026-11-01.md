# S3-20cw — exact RIP-relative dword checked-memory store

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `7639d98` adds only the six-byte singleton `89 05 id`
(`MOV [RIP+disp32],EAX`) to the shared typed-IR dword-store path. The decoded
`NextRip` is `A+6`; the effective address uses this next-instruction address
and the signed disp32. Source bytes bind to the site and the PC map has one
guest instruction boundary at `A+6`.

The host fixture uses split code/data backing. Its `(ENTRY,-1)` write updates
only the BTreeMap data RAM; it does not alter the code backing. This fixture
therefore provides no self-modifying-code or backing-alias evidence. No SMC,
code/data alias, cache invalidation, production owner/MMU, broad dword family,
or performance behavior is claimed.
