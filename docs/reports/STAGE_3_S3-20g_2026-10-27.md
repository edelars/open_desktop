# S3-20g — address-size override with signed displacement

**Date:** 2026-10-27. **Status:** local implementation and independent review complete. Physical Mac mini testing remains deferred to the final S3-21 gate.

## Scope

The existing V2 qword MOV load/store profile now additionally admits only
`67 48 8B/89 /r disp8|disp32`: ModRM `mod=01/10`, data and base encodings
RAX..RBX, no SIB, and exact instruction lengths of five and eight bytes. The
existing `mod=00` form is unchanged. Runtime metadata validation uses the
decoded operand's address size, displacement, registers, and instruction
length. Raw-byte checks bind the `67 48 8B/89` encoding and ModRM shape to that
metadata; displacement bytes are interpreted only by `long_decode::decode`.
The helper still calls `MemoryOperand::access_address_48`; no independent
sign-extension, address mask, or effective-address calculation was added.
No `od-isa` or Stage 2 file was changed.

## Local evidence

- Compiler tests cover every data/base pair for both operations and disp8
  `-128/-1/0/1/127`, disp32 minimum/maximum and adjacent/zero values. They
  reject truncated and trailing encodings, SIB, unsupported registers, other
  ModRM modes, and extra/reordered prefixes.
- The ARM64 native/interpreter differential test compares full state and RAM
  for both operations across the same displacement boundary set. It verifies
  high base bits are ignored, positive disp32 can wrap the 32-bit effective
  address, and load destination/store source aliases the old base value.
- A sparse qword starting at `0xffff_fffc` reads/writes through
  `0x1_0000_0003` without wrapping later bytes. Removing the final byte produces
  matching native/interpreter faults and leaves CPU state and RAM unchanged
  for load and store.
- STOP, stop-RIP, and zero-budget cases preserve CPU/RAM state and write count
  for both operations. The emitter's guards-before-helper ordering was verified
  by code review; these cases do not separately count load helper calls.

## Review

Independent review: clean sign-off. The reviewer confirmed bounded admission,
decoder-derived displacement/address semantics, old-value alias behavior,
qword linear range and fault atomicity, and no Stage 2 changes. Independent
checks passed: `od-jit` 120/120, `od-host` 57/57, `cargo fmt --all -- --check`,
workspace all-targets offline check, Linux x86_64 `od-host` all-targets offline
check, and `git diff --check`. The Linux check emitted only existing dead-code
warnings for macOS-only paths. No blocker was found; direct counting of load
helper calls in STOP cases remains an evidence limitation.
