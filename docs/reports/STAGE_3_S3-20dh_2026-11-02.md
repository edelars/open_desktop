# S3-20dh — exact address64 SIB dword loads with signed disp8

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `a1f66b9` adds only the four exact four-byte singleton forms
`8B 44 0B ib`, `8B 44 4B ib`, `8B 44 8B ib`, and `8B 44 CB ib`
(`MOV EAX,[RBX+RCX*1/2/4/8+disp8]`) through shared typed IR. ModRM selects EAX
and a SIB address with full-width RBX base, full-width RCX index, and scale
1/2/4/8. Decoder-owned `access_address_48` supplies the signed-disp8 effective
address. Each checked read is four bytes and writes EAX, zero-extending into
RAX and clearing `RAX[63:32]`; the guest instruction boundary is `A+4`.

All four scales × all 256 signed-disp8 values bind source bytes to the exact
site. Recorded fixtures cover the PC-map boundary, atomic faults, STOP, and
budget behavior. Coverage limit: no separate canonical-end or range-overflow
fixtures were added for these SIB disp8 forms. Shared preflight is unchanged,
and no runtime defect is claimed.
