# S3-20ed — exact RSP disp32 dword load

## Scope

S3-20ed admits only the exact address64 seven-byte singleton `8B 84 24 id`
(`MOV EAX,[RSP+disp32]`) through the existing shared typed-IR checked-load
path. The SIB has scale 1 and no index; the decoder-owned effective address
adds sign-extended disp32 to full-width RSP with wrapping u64 arithmetic. One
contiguous checked width-four read zero-extends EAX into RAX and advances the
guest boundary to `A+7`.

The JIT fixture verifies exact source/site metadata for nine representative
signed disp32 values and mutations of each encoded displacement byte. It also
checks the one-instruction typed-IR PC-map boundary. The fixture is not an
exhaustive sweep of all 2^32 encodings and is not a separate published-map or
host PC-map recovery acceptance. The slice makes no production owner/MMU,
MMIO/SMC, physical-hardware, or performance claim.

## Evidence

- JIT gate `memory_load_v2::tests::ir_dword_rsp_sib_disp32_load_binds_all_source_bytes_to_its_site`: 1/1. It covers `i32::MIN`, `-129`, `-128`, `-1`, `0`, `1`, `127`, `128`, and `i32::MAX`; verifies each displacement byte mutation changes or invalidates the source/site binding, and checks `A+7`.
- Host gate `tests::s3_20ed_rsp_disp32_dword_load_preserves_ss_fault_and_checked_state`: 1/1. It checks nine signed representatives with interpreter parity and one width-four callback, negative and wrap-to-zero EA cases, RSP `#SS` versus RBX `#GP`, overflow and backend read-error atomicity, entry STOP/budget, callback STOP commit, and retry rejection at `A+7` without another read.
