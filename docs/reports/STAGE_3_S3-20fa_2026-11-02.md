# S3-20fa: scaled RAX-indexed no-base SIB Dword store

## Scope

This runtime slice adds one exact shared typed-IR checked Dword-store profile:
the seven-byte unprefixed forms `89 04 45/85/C5 disp32`
(`MOV [RAX*scale+signed disp32],EAX`) for scales 2, 4, and 8. The decoded
operand has no base, RAX as index, Qword address size, and Dword transfer
width. Its effective address is `(original full64 RAX * scale +
sign-extended disp32) mod 2^64`; the Dword payload is low32 of the same
pre-instruction RAX. The checked store advances RIP to `A+7` on commit.

The code change is integrated at `7479a1e`. It expands only the store matcher
for these scale fields and adds an IR source/site test plus a host native
fixture gate. The complete contract and supported boundaries are in the
[normative JIT contract](../specs/JIT_CONTRACT.md#s3-20fa-exact-address64-scaled-rax-indexed-no-base-sib-dword-store).

## Static review evidence

Independent Sol/high static review passed. Review covered exact source/site
binding for scales 2/4/8 and displacement bytes; rejection of partial windows,
trailing bytes, forged metadata and unsupported neighbors; wraparound in
scaled multiplication/addition; original-RAX address and payload semantics;
interpreter parity; entry guards; backend error atomicity and retry; guest
`#GP`; checked range overflow; committed callback STOP and no replay.

These are source-review observations, not executed results. No behavior tests,
builds, formatting, Cargo checks, Python harness, or machine smoke were run.
The exact JIT/host gates remain pending. S3-34cl pins those identities and its
independent harness review passed; the harness itself was not executed. See
the [S3-34cl report](STAGE_3_S3-34cl_2026-11-02.md) and
[JIT testing reference](../testing/JIT.md#s3-20fa-exact-address64-scaled-rax-indexed-no-base-sib-dword-store).
