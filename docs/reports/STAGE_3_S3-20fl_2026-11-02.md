# S3-20fl: exact address32 RAX-alias Dword load with signed disp8

## Scope and semantics

This bounded runtime slice admits only `67 8B 40 ib` (`MOV EAX,[EAX+sign_extend(ib)])`.
The effective address is computed from the original low32 RAX before EAX
writeback: `zero_extend((low32(RAX) + sign_extend(ib)) mod 2^32)`. The load is
one contiguous checked four-byte read. The value zero-extends into RAX; other
GPRs and RFLAGS remain unchanged; successful retirement advances RIP to
`A+4`. Only the starting EA wraps modulo 2^32. A transfer starting at the end
of the 32-bit address range continues contiguously above 4 GiB.

The exact-form admission covers compiler metadata, the `CheckedDwordLoad`
literal-byte gate, decoded address profiles, and runtime source/site matching.
Addr32 disp32, SIB, other destinations, and additional prefixes remain outside
this slice.
