# S3-20i / S3-26b — checked qword store through shared typed IR

**Date:** 2026-10-27. **Status:** bounded implementation and local native
ARM64 verification complete; independent review pending. The physical x86
Mac mini check remains reserved for final S3-21.

## Scope

The opt-in builder accepts only one `48 89 /r`, ModRM `mod=00`, with source
and base RAX..RBX and no SIB or displacement. It runs through the existing
BasicBlock, typed IR, allocator, and runtime emitter. `CheckedStore` carries
the decoded `MemoryOperand` and source GPR directly. The verifier requires one
store immediately followed by its instruction commit; no helper/effect/exit is
admitted between them. The artifact has a separate compile flavor and typed
host metadata/invocation entry. V1, IR/direct load, and direct-store invocation
APIs reject the foreign artifact before native entry.

The entry runs stop-RIP, STOP, then budget guards; invokes the checked helper
once; and immediately commits RIP, budget, and retirement. It observes STOP
only after commit, preserving a successful write when the write callback raises
STOP. The host entry has the same unsafe private synchronous ordinary-RAM
requirements as direct V2 store. The PC map marks the helper call and
return-to-commit interval `InadmissibleAfterEffect`; only the planned helper
error return is replay-admissible because error results guarantee no write.

## Local evidence

- `cargo test -p od-jit ir_checked_store_has_non_replayable_write_to_commit_map --offline` — passed. The compiled map contains no replay-admissible helper/write-to-commit range.
- `cargo test -p od-jit checked_store_is_unique_and_commits_immediately_after_write --offline` — passed. Negative cases cover duplicate store, missing/early commit, and an effect after store.
- `cargo test -p od-host ir_checked_store_matches_direct_and_interpreter_with_precise_commit --offline` — passed on local Apple Silicon. IR, direct V2, and interpreter agree on full CPU/RAM snapshots for `MOV [RAX], RAX`; exact source/address alias behavior and one write callback are checked. The same test covers STOP raised during write, architectural fault payload, backend error class, no callback for stop-RIP/STOP/zero budget, and rejection through V1, load, and direct-store entry APIs.

## Verification and limits

No `od-isa`, Stage 2 fixtures, or generators were changed. This remains one
instruction over private ordinary data RAM; it does not enable MMIO, DMA,
concurrent/shared RAM, atomics, executable aliases, active SMC, multiblock
ordering, or performance claims. Passed: `cargo fmt --all -- --check`;
`cargo check --workspace --all-targets --offline`; Linux `cargo check -p
od-host --target x86_64-unknown-linux-gnu --all-targets --offline`; all 126
`od-jit` tests; all 58 `od-host` tests; and `git diff --check`.

registered as ISSUE-025 and ISSUE-026; no Stage 2 source or report was changed.
`graphify update .` completed; it reported the existing parser warning for
`include/open_desktop/host_abi.h` and no-symbol warnings for crate manifests.
No physical Mac mini run or benchmark was performed. No additional unresolved
defect was observed in this store implementation.

## Follow-up after independent review

The metadata decoder/source validator is now shared by direct V2 compilation
and IR-store compilation; the latter no longer invokes the direct emitter to
produce metadata. The allocator explicitly declares and the store emitter
checks an empty-temp helper boundary. The unsafe host entry now documents the
private synchronous RAM, atomicity, non-aliasing, no-concurrency/re-entry,
no-delayed-effect, and no-unwind requirements. The duplicate plan status row
was removed. After these changes, the focused store allocator/map/compiler
tests and host native differential test passed; full suites passed at 126/126
for `od-jit` and 58/58 for `od-host`. Workspace check, Linux-target host check,
format check, and `git diff --check` passed again. Independent reviewer
follow-up remains pending.
