# S3-20cf: address32 RSI/RDI-base SIB with no index

**Status:** bounded partial slice implemented and independently reviewed. Mini and performance checks remain deferred until the end of Stage 3.

## Implemented profile

The JIT admits singleton `67 48 8B/89 /r sib [disp8|disp32]` instructions with ModRM `mod=00/01/10,r/m=100`, SIB exactly `0x26` or `0x27`, and data register RAX..RBP. Effective address size is Dword, transfer size is Qword, and lengths are 5/6/9. The decoder-owned address operation computes `(low32(old RSI/RDI)+signed displacement) mod 2^32` and zero-extends it. High base bits are ignored, the full base register is preserved, RSP is not an input, and a qword access remains contiguous when it crosses the 4 GiB boundary.

The admission path is bounded at checked block construction, typed IR verification, direct V2/shared IR metadata, immutable source matching, and fixture dispatcher matching. No scale aliases, extra prefixes, other data registers, pair or V3 support, or production owner/MMU integration were added. Address64 S3-20ce remains a separate Qword-address profile with its existing 4/5/8 lengths.

## Evidence added

- Descriptor matrix: both MOV directions, RSI/RDI bases, RAX..RBP, mod00/disp8/disp32 and signed displacement edges; direct-base addr32 operand comparison, exact next RIP, EA wrap, partial windows, and rejected neighbors.
- Host matrix: direct V2 and shared IR versus interpreter, including full CPU/RAM parity, full-width data, base preservation, callback address and width, and retirement. The equivalent direct-base encoding is interpreted separately and its RIP is normalized only after confirming its shorter encoded length.
- Dispatcher: actual-RIP continuation through 5/6/9-byte forms without replay, incomplete windows, entry guards, final disp32-byte target identity, store plus STOP as one qword write, and memory-error no-commit.
