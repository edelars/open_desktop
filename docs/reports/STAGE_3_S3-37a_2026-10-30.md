# S3-37a — bounded FIFO16 corpus churn observation

**Status:** three local release runs completed with 128 full-corpus sweeps on
one retained production FIFO16 runtime per process. The bounded cache reached
capacity and repeatedly evicted/recompiled under this workload. This is
partial S3-37 evidence only; it is not a leak-free stress or lifecycle result.

## Scope and method

The opt-in command `od-bench cache-churn` accepts only the frozen S3-17
case-list and trace hashes, admits the complete 1,010-case register-only
corpus, and runs exactly 128 complete sweeps in one production runtime/cache/
arena. Every sweep reuses the same ordered cases and checks the expected
interpreter result, dispatch exit, retirement count, and block count.

Timed dispatch-call intervals include FIFO lookup, compilation/publication on
miss, and native execution. Fixture parsing/admission, oracle preparation,
per-case state clone/reset and validation, runtime setup/teardown, and process
launch are excluded. Counter totals are cumulative for the process; resident
entry/code/logical-metadata fields are high-water values. The field
`arena_unoccupied_slots_at_resident_high_water` is derived as
`cache_capacity_entries - resident_entries_high_water`; it is not read from an
allocator availability counter.

## Results

| Measure | Run 1 | Run 2 | Run 3 |
|---|---:|---:|---:|
| Cumulative cache hits | 256 | 256 | 256 |
| Cumulative cache misses / successful compiles / publications | 168,960 each | 168,960 each | 168,960 each |
| Cumulative evictions | 168,944 | 168,944 | 168,944 |
| Resident entry high-water | 16 | 16 | 16 |
| Resident code bytes high-water | 21,640 | 21,640 | 21,640 |
| Resident logical metadata bytes high-water | 50,124 | 50,124 | 50,124 |
| Published arena reserved bytes | 65,536 | 65,536 | 65,536 |
| Derived unoccupied slots at resident high-water | 0 | 0 | 0 |
| Accumulated timed dispatch intervals (ms) | 2,362.063 | 2,310.972 | 2,239.969 |
| Mean timed dispatch interval per full sweep (ms) | 18.454 | 18.054 | 17.500 |

The identical counts show that the fixed workload and bounded FIFO behavior
were reproducible across these three processes. High-water values remained at
the cache's 16-entry capacity with the same code/metadata figures. This
supports only a bounded observation of capacity churn for this register-only
corpus. It does not demonstrate unbounded-growth prevention across other
workloads or correct release at runtime destruction.

## Verification and limits

`cargo fmt -p od-bench -- --check` and `cargo check -p od-bench --all-targets
--offline` passed for the implementation. Three release runs were collected.
Process RSS is null; runtime teardown/independent-instance lifecycle was not
measured. No Mini/physical x86 or Stage 2 checks were run. The experiment does
not cover SMC invalidation, unique-key growth beyond this fixture,
helper/memory workloads, or whole-VM resource budgets. Host power, thermal,
and background-load telemetry was not recorded. S3-37 remains open.
