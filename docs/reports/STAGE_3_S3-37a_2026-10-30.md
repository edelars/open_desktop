# S3-37a — bounded FIFO16 corpus churn observation path

**Status:** opt-in tooling implemented and compiles. No churn observation has
been run. This is partial S3-37 tooling evidence only, not a resource or
leak-free stress result.

## Scope and method

The command `od-bench cache-churn` accepts only the frozen S3-17 case-list and
trace hashes, admits the complete 1,010-case register-only corpus, and runs
exactly 128 complete sweeps on one retained production FIFO16 runtime/cache/
arena. Every sweep reuses the same ordered cases and checks the expected
interpreter result, dispatch exit, retirement count, and block count.

The report records per-sweep elapsed dispatch-call intervals, input calls,
native block executions, retired instructions, and cache counter deltas. It
also records cumulative hit/miss/compile/publication/eviction totals, resident
entry/code/logical-metadata high-water, and arena reserved bytes. The field
`arena_unoccupied_slots_at_resident_high_water` is derived as
`cache_capacity_entries - resident_entries_high_water`; it is not read from an
allocator availability counter. It requires the complete call count, at least
one eviction, equal misses/successful compiles/publications, and no
resident-entry high-water beyond FIFO16 capacity.

The total process is bounded by the existing 30-minute runner deadline. Timed
dispatch intervals exclude fixture parsing/admission, per-case state
clone/reset and correctness validation, runtime initialization/teardown, and
process launch. `process_rss_bytes` is null and
`teardown_or_independent_instance_lifecycle_measured` is false; the tool does
not claim to measure either.

## Reproduction

After independent review and commit, run on native Apple Silicon macOS:

```sh
cargo run --release -p od-bench --offline -- cache-churn \
  --case-list work/tmp/stage3/s3-17/cases.txt \
  --trace work/tmp/stage3/s3-17/dispatch-trace.json \
  --process-run 1 \
  --output work/tmp/stage3/s3-37/cache-churn-1.json
```

## Verification and limits

`cargo fmt -p od-bench` and `cargo check -p od-bench --all-targets --offline`
passed for this implementation. No benchmark, test suite, Mini/physical x86
check, or Stage 2 check was run.

The repeated frozen corpus can demonstrate bounded capacity eviction and
recompilation under this workload. It is not a long leak-free stress test. The
path does not measure RSS, teardown/release after STOP/fault/destroy, multiple
independent runtime instances, SMC invalidation, unique-key growth beyond this
fixture, helper/memory workloads, or whole-VM resource budgets. S3-37 remains
open until appropriate observations are collected and reviewed.
