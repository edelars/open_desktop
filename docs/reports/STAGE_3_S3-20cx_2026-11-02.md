# S3-20cx — exact address-size-32 dword checked-memory load

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `629e144` adds only the three-byte singleton `67 8B 03`
(`MOV EAX,[EBX]`) to the shared typed-IR dword-load path. The decoder-owned
address-size-32 access calculation zero-extends low32 RBX before checking the
canonical address. The JIT binds the exact source bytes to the site and
records one guest instruction boundary at `A+3`; the host path performs the
bounded four-byte load and EAX zero-extension.
