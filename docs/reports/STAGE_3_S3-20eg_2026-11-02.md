# S3-20eg — exact address-size-32 ESP-base dword store

## Scope

S3-20eg admits only the exact four-byte singleton `67 89 04 24`
(`MOV [ESP],EAX`) through the shared typed-IR checked-store path. The
address-size-32 SIB uses ESP as its base, no index, scale 1, and zero
displacement. Effective address is `u64(RSP as u32)`: high RSP bits are
ignored and ESP is zero-extended. The checked store writes low32 RAX in one
contiguous four-byte operation and advances RIP to `A+4`.

When ESP is `0xffff_fffe`, the store touches `0xffff_fffe`, `0xffff_ffff`,
`0x1_0000_0000`, and `0x1_0000_0001`; the four-byte span does not wrap at
4 GiB. Host coverage compares interpreter CPU state and memory for ordinary
and poisoned-high32 RSP patterns. This bounded fixture does not establish
production owner/MMU, MMIO/SMC, physical-hardware, or performance behavior.
