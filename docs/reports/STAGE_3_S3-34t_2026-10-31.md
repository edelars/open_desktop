# Stage 3 S3-34t: Register dispatch event gates

## Result

Added five existing `od-jit` register-dispatch event tests to the Stage 3
local acceptance harness as exact Rust gates. The harness now includes each
identity once in `RUST_TEST_GATES`, local step routing, the input manifest, and
required evidence validation. Each invocation is pinned to
`cargo test --offline -p od-jit --lib <identity> -- --exact
--test-threads=1`.

The source manifest already pins `crates/od-jit/src/dispatch.rs`; it remains in
the pinned source list, so the new gate evidence is bound to the exact tested
source. Gate count increased from 92 to 97. Existing event, ABI, memory,
register, and lifecycle gates remain in the manifest.

## Added gates

- Event request survives native cache miss and hit until cleared.
- Event raised during publication prevents native entry.
- Multi-cache event behavior respects hit/miss and capacity.
- Event after Jcc yields before NOP and resumes without replaying the prefix.
- Stop, code-end, budget, and error priorities are preserved with an event.
