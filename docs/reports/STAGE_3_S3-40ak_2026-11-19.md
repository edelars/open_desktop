# S3-40ak Historical interpreter RUN residual after S3-40aj

The two arms use the unmodified interpreter and decoder from
`d24865d` and `d48eef9`. The current revision includes the HLT,
INT3, CLI and STI predicate change adopted in S3-40aj. The
shared driver and workload match S3-40ai. The
separate untimed checks verified the 2,400 S3-34a MOV inputs at
budgets 0, 1 and 2 and an unmapped instruction at budget zero.
Both builds passed CPU state, defined flags, RAM, ordered data
callback, retirement and budget-exit checks on M1 Pro.
[Previous historical comparison](STAGE_3_S3-40ai_2026-11-19.md)

## Results

Six paired rounds alternated the two builds and the two instruction
sequences. Each process ran all budget permutations and used fixed
counts of 4,374,000 and 4,339,200 RUN calls per interval. The series
retained 432 intervals and 1,882,051,200 RUN calls. The shortest
interval was 80.577 ms against a 45 ms floor.

The absolute columns show pooled medians [min, max] in nanoseconds
per RUN call. The last column shows the median [min, max] of six
current/historical ratios of process medians.

## Environment and reproduction

MacBookPro18,3, Apple M1 Pro, eight logical CPUs, macOS 14.6.1 (23G93),
Xcode 15.4, Rust and Cargo 1.99.0, and Python 3.12.5. The native ARM64
release builds use minimum macOS 14.0. Both passed strict signature checks
with Hardened Runtime and `allow-jit`. The machine was on AC power.
All twelve timing processes recorded UID 501, nice −5 and QoS `0x21`.
The 24 preflight probes measured 95.5–99.3% idle CPU (median 98.6%).
The 29 in-run probes measured 82.9–86.8% (median 86.2%).

The first preflight reached a low of 72.2% idle CPU and ended
before starting any timed process. The accepted series used the
same signed builds after a fresh preflight with a 95.5% minimum.
