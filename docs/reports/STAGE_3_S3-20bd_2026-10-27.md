# Stage 3 S3-20bd: address32 SIB with RSP base and RBP index

## Scope

Added one bounded singleton profile: `67 48 8B/89 /r sib [disp8|disp32]`, ModRM `mod=00/01/10,r/m=100`, SIB base=RSP and index=RBP, scale 1/2/4/8, data RAX..RBP. Instruction lengths are exactly 5/6/9 bytes; the effective address is Dword while data transfer remains Qword. The decoder's `MemoryOperand` and `access_address_48` remain the sole effective-address implementation. Existing address32 no-index, low-base/RBP-index, RSP-base/low-index, and address64 stack-index profiles remain distinct. No `od-isa`, Stage 2, owner/MMU, pair/V3, Mini, or performance changes were made.

## Evidence

- The JIT descriptor matrix compares direct V2 and shared IR for load/store, all six data registers, all four scales, and no-displacement/disp8/disp32 cases including signed bounds. It checks decoded base/index/scale/displacement/width/length, exact source admission, and `access_address_48` against the independent oracle `(low32(RSP) + low32(RBP)*scale + signed displacement) mod 2^32`.
- The host matrix compares direct V2, shared IR, and the interpreter for both operations across all six data registers, four scales, and all three instruction widths. It checks full CPU/RAM state, callback address and count, and one retirement; data aliasing uses pre-instruction values and qword store payload remains full width.
- A qword load starting at `0xffff_fffc` crosses the 4 GiB boundary in one eight-byte callback. Two immutable nine-byte instruction artifacts differing only in source byte nine produce independently asserted distinct callback addresses.
- Architectural read/write faults preserve exact guest fault payload and leave state/RAM uncommitted, with the attempted callback recorded. Backend read/write failures remain host errors with unchanged state and exact callback identity. A successful store followed by callback STOP commits the write and one retirement.
- Bounded dispatch splits after the new singleton at budget 1, then resumes from actual RIP through the opt-in NOP and existing two-instruction pair without repeating the first read. Partial windows 1..8 return fixture `BoundaryReached` with no CPU or memory effects. Unsupported SIB/prefix neighbors are rejected.
