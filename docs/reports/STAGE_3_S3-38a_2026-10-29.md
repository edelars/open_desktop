# S3-38a — V0 C ABI through the register block dispatcher

**Статус:** bounded partial slice implemented; independent review clean. Full
S3-38 and Stage 3 remain open.

## Реализованная граница

`od_fragment_execute` now executes its immutable v0 fragment through the eager
S0-09 block dispatcher. Each synchronous call creates one bounded
`PublishedArenaBackend` and multi-entry cache, uses a full decoded
`AdmittedInstructionBoundaries` witness and a run-local immutable code identity,
then drops the cache and arena before returning. The cache is never shared
between C handles or stored in `FragmentInstance`; this keeps its `!Send`/`!Sync`
MAP_JIT ownership on the executing thread. ABI v0 layouts, status codes,
byte-offset RIP, four-register state, output-on-success behavior, and handle
STOP/destroy synchronization are unchanged.

The state adapter copies all four guest GPRs, RIP and raw RFLAGS into
`LongModeState`, leaving the other GPRs at zero; it copies only the four v0 GPRs
back. It does not normalize caller flags. `CodeView` is based at RIP 0 because
v0 RIP is an offset into the fragment. An explicit entry-boundary check retains
the existing `INVALID_STATE` response for an invalid RIP even when STOP or a
zero budget is pending. Arena acquisition remains before that check to preserve
the legacy `BUSY` status when another MAP_JIT mapping is live. Tests verify
both statuses leave an output sentinel untouched, and a later valid call
succeeds after the temporary arena lease is released.

At `RIP == code_end`, a pending pre-run STOP now returns `STOP_REQUESTED` and is
cleared once, as required by the v0 contract. The legacy fragment JIT returned
`CODE_END` at that boundary before checking STOP. This bounded slice follows
the documented v0 pre-run STOP contract; it does not claim equivalence with the
legacy path for that precedence edge.

No memory forms, interpreter fallback, persistent cache, Swift changes, ABI
changes, Stage 2 files, or owner-backed `od-machine` work are included. Mini and
performance gates were not run.
