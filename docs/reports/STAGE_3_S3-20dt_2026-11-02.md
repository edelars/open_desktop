# S3-20dt — exact RBP-base dword checked-memory load with disp32

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `add3166` adds only the six-byte singleton `8B 85 id`
(`MOV EAX,[RBP+disp32]`) to the shared typed-IR Dword-load path. The decoded
memory operand supplies full-width RBP plus signed disp32 with wrapping. The
JIT descriptor test covers twelve representative signed displacement values
and binds each of the four encoded displacement bytes to its site; it does not
enumerate all 2^32 possible displacement patterns. A successful checked read
transfers exactly four bytes, writes EAX and zero-extends it into RAX. The
single checked guest boundary is `A+6`.

The bounded host fixture compares published execution with the interpreter,
checks the exact width-four callback and preserves unrelated state. RBP
noncanonical-start and range-end failures produce `#SS`; the retained RBX
disp32 S3-20cs host case is the `#GP` control. Effective-address addition
wraps from `u64::MAX+1` to zero and performs a checked four-byte read. A
four-byte access whose computed start is `u64::MAX-1` reports
`AddressOverflow` before a read callback or architectural commit. Read faults
leave state uncommitted. Budget and entry STOP guards perform no read; STOP
raised by a successful callback is reported after the completed load. These
fixtures do not establish other bases or encodings, MMIO, SMC, owner/MMU, or
hardware behavior.
