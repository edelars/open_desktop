## Scope and behavior

Added the exact singleton qword MOV profile `48 8B/89 /r sib disp8|disp32`, ModRM `mod=01/10,r/m=100`, SIB base=RBP and index=RBP, scale 1/2/4/8, data RAX..RBP. Encoded lengths are five and eight bytes. ModRM `mod=00` with SIB base `101` remains no-base and is not admitted by this profile. The generic index whitelist remains unchanged; no pair, V3, address32, or executable-frame/ABI profile was added. The decoder `MemoryOperand` and `access_address_48` remain the sole effective-address implementation.

The direct V2 compiler, shared IR, host source validation, and bounded dispatcher recognize the same exact form. Descriptor coverage compares both directions and all six data registers, four scales, and signed disp8/disp32 boundaries. Host direct V2/shared IR/interpreter coverage compares CPU and RAM state, exact callback addresses/counts, and retirement against `RBP + RBP*scale + signed displacement` modulo 64 bits. `data=base=index=RBP` verifies pre-instruction alias values.

Fault coverage checks exact #SS payload for noncanonical qword start and last-byte crossing on both load and store, with no callback or commit; a low-base/RBP-index control yields #GP. A canonical high RBP plus `disp8=+1` produces an endpoint `AddressOverflow` before callbacks. Backend read and write failures retain host classification, attempted `(0x200, 8)` callback identity, and no CPU/RAM commit. A successful store followed by STOP commits exactly once. Bounded dispatch splits after the new singleton, resumes from actual RIP through the opt-in NOP and existing pair without replay, and rejects out-of-profile neighbors and partial windows 1..4/1..7 before publication or memory effects.

Older negative fixtures that encoded the newly admitted SIB were changed to genuinely excluded neighbors, such as RBP base with RSI index or address32 forms. Stage 2 and `od-isa` were not changed.
