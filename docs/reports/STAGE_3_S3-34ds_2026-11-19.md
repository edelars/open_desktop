# S3-34ds Generated mixed-register coverage on the ARM64 arena

The new integration test exercises the opt-in S3-55 dispatcher using
`MixedRegisterV1Admission` and `PublishedArenaBackend`. It derives a
register MOV immediate and an ADD, SUB or CMP from the S0-09 testkit
generator. When present, the generator's JZ or JNZ and fallthrough MOV
retain their encoding. The fixture places bare CLD, STD and NOP at
instruction boundaries and ends with INC. The test checks that mixed
admission accepts the inputs and strict admission refuses them.

Three fixed seeds generated 400 cases each. The 1,200 unique inputs
contained 1,196 distinct byte sequences. The corpus SHA-256 is
`410e2edbeacab8a2f16f507ce588c21df619831e2400639274935173c978cbd5`.

- 1,011 inputs retired both direction helpers and reached code end.
- 63 exited on budget, 105 on a STOP address and 21 on a STOP request.
- The interpreter recorded 361 fallthroughs, 366 taken branches and DF
  changing in each direction. It rejected all non-fetch accesses.
- Each input ran twice in the interpreter and twice on the retained
  arena in each flags mode. Eager and demand runs matched full state,
  DF, RIP, exit, budget and native/helper retirement. The repeats
  recorded 6,556 warm block hits across the two modes.

The exact integration test passed on local ARM64 macOS 26.7.1 (25G241),
Xcode 27.1 and Rust 1.99.0. The executable targets macOS 14.0 and
verified with Hardened Runtime and `allow-jit`. The fixture used base
`4995612`. A mismatch reports its seed, index and instruction bytes.
This covers the bounded S3-55 mixed family under S3-34.5. Stage-wide
S3-34 acceptance and the physical x86 comparison remain open.

## Reproduce

Run within the repository on macOS ARM64.

```sh
export MACOSX_DEPLOYMENT_TARGET=14.0
target_dir=$(mktemp -d)
cargo test -p od-host --offline --locked --release --target aarch64-apple-darwin \
  --test mixed_register_v1_corpus --no-run --target-dir "$target_dir" \
  --message-format=json > "$target_dir/build.jsonl"
test_bin=$(python3 - "$target_dir/build.jsonl" <<'PY'
import json
from pathlib import Path
import sys

records = [json.loads(line) for line in Path(sys.argv[1]).read_text().splitlines()]
path, = (row["executable"] for row in records
         if row["reason"] == "compiler-artifact"
         and row["target"]["name"] == "mixed_register_v1_corpus"
         and row["executable"])
print(path)
PY
)
codesign --force --sign - --options runtime \
  --entitlements apps/vmhost/Configuration/vmhost-smoke.entitlements "$test_bin"
codesign --verify --strict "$test_bin"
"$test_bin" --exact generated_mixed_register_v1_corpus_runs_twice_on_published_arena --nocapture
```
