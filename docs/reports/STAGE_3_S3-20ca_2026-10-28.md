# Stage 3 S3-20ca: address64 low-base SIB with no index

## Scope and implementation

Added only the singleton Qword MOV forms `48 8B/89 /r sib`, ModRM `mod=00/01/10,r/m=100`, SIB exactly `0x20..=0x23`, data RAX..RBP, lengths 4/5/8. SIB scale is one; index field `100` with extension clear is the no-index sentinel, not guest RSP; the base is RAX..RBX. No address32, other SIB/base/index form, extra prefix, pair, V3, owner/MMU, or Stage 2/ISA change is included.

The decoded `MemoryOperand::access_address_48` remains the effective-address implementation. It uses the old base register and signed displacement with the existing 64-bit address semantics. Admission is aligned across checked block construction, direct V2 and shared-IR site validation, immutable runtime source matching, and bounded dispatcher compilation. The separate direct-base encoding is used as a semantic interpreter comparison, not admitted as this SIB profile.

## Evidence

The JIT descriptor test covers both opcodes, all four bases, all six data registers, no displacement/disp8/disp32 lengths, signed displacement boundaries, exact source/operand metadata, partial windows, final disp32-byte identity, and invalid neighboring encodings.

The host matrix executes direct V2, shared IR and interpreter for both load and store across all four bases, all six data registers, and ten no-displacement/signed disp8/disp32 cases. It compares complete CPU and RAM state, an independent `old_base + signed displacement` target, callback address/width/count and retirement. Each case is also compared with the equivalent direct-base interpreter encoding.

Additional exact-profile checks verify noncanonical-start and canonical-start/noncanonical-end #GP payloads for loads and stores without callbacks or commit; high-half qword-range overflow remains `AddressOverflow` before a callback; architectural faults and backend read/write errors preserve CPU/RAM; successful store+STOP commits the full qword once; STOP, stop-RIP and zero-budget entry guards suppress access. Bounded dispatch continues from actual RIP across 4/5/8-byte singleton forms into the existing pair without repeating the first load. Separate immutable artifacts that differ in the final disp32 byte produce independently expected targets.
