# Stage 4 S4-25c: xAPIC Fixed self-IPI

S4-25c adds xAPIC ICR low/high register access to the standalone `LocalApic`.
`ICR_HIGH` at offset `0x310` stores only the destination byte; writing it does
not send an IPI. An aligned Dword write to `ICR_LOW` at `0x300` supports only
Fixed delivery, Self destination shorthand, edge trigger, asserted level and
vectors `16..=255`. Destination mode is ignored for Self shorthand. The
read-only Delivery Status bit is ignored on write and reads Idle after the
synchronous internal send.

A valid ICR low write stores its writable fields and sets the vector in IRR
under one device-state lock. This internal one-CPU self-delivery is distinct
from CPU interrupt acceptance or handler execution. Repeated commands are
issued again; multiple pending requests for the same vector coalesce in IRR.
Software disable allows an IPI to enter IRR but leaves it ineligible for
acknowledge. Global disable blocks ICR MMIO and reset/global-disable clear both
ICR halves.

The behavior is based on Intel's [64 and IA-32 Software Developer's Manual release 093, Volume 3A](https://cdrdv2.intel.com/v1/dl/getContent/671190), §§13.6.1–13.6.2.3, Table 13-3 and §§13.8.3–13.8.5. Self shorthand permits Fixed edge delivery and ignores destination mode; ICR low write starts sending; Delivery Status is read-only.

## Limits

Only the Fixed Self profile is implemented. Other delivery modes and
destinations, level delivery, APIC bus messaging, ESR, CPU interrupt
acceptance, handler/IDT/IF semantics, HLT wakeup, IOAPIC, default board wiring
and Linux discovery remain outside this slice. Unsupported or reserved writes
fail through local `DeviceError` without mutation; they do not model guest
exception delivery. Parent S4-25 and Stage 4 remain open.
