# Stage 3 S3-16o: mixed Store→Store / NOT RCX corpus

Status: partial; bounded host corpus and exact fail-closed gate are implemented
and independently reviewed. Local ARM64 bounded acceptance passed; full
harness, Mini, and M1 acceptance remain pending.

## Scope

The host test
`tests::s3_16o_s3_34_store_store_not_rcx_store_store_fixed_seed_boundaries`
uses fixed seed `0x5333_3136_6f34_636f` for eight cases. Each input composes
exact native Store→Store (`48 89 03 48 89 02`), the existing opt-in interpreter
fallback `NOT RCX` (`48 F7 D1`), and another native Store→Store pair.

Six budgets (0 through 5), two stop-RIP boundaries, and callback-triggered STOP
compare full CPU state, RAM, ordered write ledger, RIP, per-backend retirement,
and remaining budget against interpreter execution. Continuation checks that
committed stores are not replayed. This adds no instruction forms, production
fallback mode, or performance claim.

fail-closed self-test
`test_s3_16o_store_store_not_rcx_mixed_corpus_gate_is_pinned_once_and_fail_closed`

and the S3-34bh store gate. The current fail-closed self-check pins all 149

The implementation-time snapshot contained 321 Rust gates (303 acceptance +
18 lifecycle), 339 local steps, 321 distinct step IDs, and 146 self-test
