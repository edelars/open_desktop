# S3-20as report: address32 indexed SIB with RSP base

## Scope

Added only singleton `67 48 8B/89 /r sib [disp8|disp32]` forms with ModRM
`mod=00/01/10,r/m=100`, SIB base RSP, index RAX..RBX, scale 1/2/4/8, data
RAX..RBP, Dword effective address and Qword transfer. Instruction lengths are
5/6/9 bytes. The exact no-index SIB `0x24` remains a distinct existing profile;
no-base and RSP/RBP index encodings, extra prefixes, pairs and V3 remain
unsupported. The decoder's `MemoryOperand` and `access_address_48` remain the
sole address-semantics source.

## Evidence

The JIT descriptor matrix covers both operations with RSP/RBP data registers,
all scales, and signed disp8/disp32 boundary values. The host direct V2, shared
IR and interpreter matrix covers all six data registers and compares full
CPU/RAM state, callback addresses/counts and retirement. Host cases include
RSP base and index high halves, data=RSP and data=index aliasing,
modulo-2^32 target formulas, and a contiguous qword starting at `0xffff_fffc`.
A ninth-byte disp32 case distinguishes addresses with a fixed RSP and index.

Architectural memory-fault and backend-error paths preserve the expected
guest/RAM/budget/retirement state; errors remain classified as guest faults or
host errors. A successful store of the old, full-width noncanonical RSP value
commits one qword before callback STOP and returns at the instruction's next
RIP. Bounded dispatch executes an RSP-base indexed disp32 load, the explicit
NOP bridge and the existing native pair; budget/stop-RIP continuation resumes
from actual RIP without repeating the first callback. Partial windows 1..8 and
forbidden SIB fields have no effects. Existing address32 no-index SIB coverage
still passes.

This remains borrowed-fixture evidence; production memory-owner/MMU
integration, physical x86 validation, Mini and performance measurement remain
open and are not claimed here.
