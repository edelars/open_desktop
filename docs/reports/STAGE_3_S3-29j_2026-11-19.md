# S3-29j split flags windows on M1 Pro

The signed ARM64 split-window driver passed untimed preflight on M1 Pro,
macOS 14.6.1, with Rust 1.99.0. It rechecked 1,200 stored interpreter
observations, passed 2,400 full-state comparisons and matched the
stock per-case cache baselines. The source was `8cdac54` with the
dedicated benchmark overlay. The signed driver SHA-256 was
`43344c73ce035b85a5a65e953e728e79628f28d5193abc2e31bae2df317c3a34`.

The whole-process controller ran cold first and allowed four attempts
per round. The first two stopped in the host-load preflight before
launching the timed driver. The second attempt crossed a recorded
system wake. With AC power confirmed, a temporary `caffeinate -s -w`
sleep assertion was started for the controller PID. The third and
fourth attempts each completed 20 cold pairs at 200 ms or more per
side. The driver PID in each ran as UID 501 with effective nice −5.

The split repeat series remains pending. S3-29 remains open for
accepted latency measurements and a flags strategy decision.

UTF-8 receipts, timing reports, build and signature records, and
both replay harnesses. The `file_sha256` map binds the restored files.
