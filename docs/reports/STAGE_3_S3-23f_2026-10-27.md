# S3-23f — bounded cross-mapping qword write

## Scope

The fixed-RAM `TrackedCodeFixture` now resolves ranges through either one guest
mapping or exactly two adjacent mappings. A split access requires equal
`BackingId` and contiguous backing offsets. It validates checked guest/backing
ranges and both mappings' write/required execute permissions before producing
one backing-relative write plan. The commit uses one all-or-nothing slice copy,
one backing version increment, and one content notification. Decoder input can
be read as one contiguous backing slice, while cache dependency spans retain
each guest mapping's separate identity and version.

## Native case

The fixture maps B's `48 BA imm64` instruction across two adjacent 4096-byte
guest mappings of one backing. B starts at page-end−6 and the immediate starts
at page-end−4. The test warms B, an alias of B, and unrelated C, then uses the
production checked V2 qword store to replace all eight immediate bytes across
the mapping boundary.

It verifies exact little-endian bytes, one write, one version increment and
notification, eviction of B plus its alias, retention of C as a cache hit, and
fresh native B/alias execution returning the replacement immediate. The native
store's CPU/RAM/version result matches the committed interpreter step on an
independent fixture owner.

Failure cases cover a missing, read-only, or non-executable second mapping,
version exhaustion, backend write failure, a different backing, a noncontiguous
backing offset, and checked endpoint overflow. They preserve CPU state, RAM
bytes on both sides of the boundary, versions, cache residents, and notification
count. Writes that end exactly at or start exactly on a boundary remain valid
single-mapping ranges.

## Limits

This is a single-vCPU fixed-RAM fixture capped at two guest-adjacent mappings
with one contiguous backing. It does not support arbitrarily segmented ranges,
production MMU behavior, MMIO, DMA, or concurrent writers. No Stage 2 source was
changed. Physical Mac Mini tests and long benchmarks remain deferred to the
final S3-21 gate.
