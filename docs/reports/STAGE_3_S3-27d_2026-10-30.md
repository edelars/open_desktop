# S3-27d — direct singleton V2 host-PC attribution

**Status:** bounded implementation complete; S3-27 and Stage 3 remain open.

## Implemented

- Direct V2 load/store wrappers own a validated `PcMap`. The shared memory
  artifact and its typed-IR consumers remain unchanged.
- The direct V2 emitter returns code and map together. It captures byte
  offsets from checked `Encoder::position() * 4` values and maps the full
  emitted range contiguously, with a single committed next-RIP boundary.
- Entry guards, helper, commit, normal return, and each out-of-line exit stub
  have explicit attribution. A load helper range reports `ReplayCurrentInstruction`
  as generated-state attribution only. Replay also requires the caller to
  establish synchronous ordinary RAM; the map does not classify arbitrary
  `GuestMemory`, MMIO, or unknown classes. Store helper/failure code is
  non-replayable after a possible write. No host-fault recovery was added.
- Standalone `PublishedCode` retains an owned map after compiler artifact drop.
  Arena V2 store slots retain an owned map through notification/cache
  invalidation, and generation checks reject stale handles after slot reuse.
- `MemoryOperationMetadataV2` remains `Copy`; direct metadata is separate from
  shared-IR and V3 metadata. No ABI or generated-instruction emission changes
  were made.

## Evidence

- `memory_load_v2::tests::ir_checked_load_uses_distinct_v2_artifact_and_pc_map`
  checks map coverage, alignment, contiguity, the single boundary, distinct
  exit stubs, replay classification, and the non-replayable store helper.
- `tests::direct_memory_v2_pc_map_survives_artifact_drop_and_arena_slot_reuse`
  checks standalone/artifact lifetime and arena slot generation reuse.
- `tests::tracked_v2_store_invalidates_alias_after_return_and_preserves_late_stop_commit`
  checks the arena map before and after notification-driven cache invalidation.
- `tests::address32_low_base_rsi_rdi_index_sib_matches_all_execution_paths`
  retains direct V2 regression coverage that distinguishes guest faults from
  backend failures.
- Focused JIT and host tests passed. `cargo check -p od-jit -p od-host
  --all-targets --offline` passed; formatting was applied.

The emitter's instruction calls, arguments, ordering, and labels are unchanged;
map offsets are captured around them. The compiler test confirms emitted code
length and map length agree. The local Stage 3 harness, independent review,
and final commit remain pending. Mini, Stage2, performance, physical/MMU, and
full S3-27 validation were deliberately deferred/out of scope.
