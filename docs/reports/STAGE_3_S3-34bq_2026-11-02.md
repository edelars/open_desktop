# S3-34bq — exact harness gates for S3-20ef

## Scope

S3-34bq pins only the two exact Rust regression identities for the bounded
S3-20ef address-size-32 ESP-base dword load:

- JIT source/site gate: `memory_load_v2::tests::ir_dword_addr32_rsp_sib_load_binds_exact_source_and_site`.
- Host checked-state gate: `tests::s3_20ef_addr32_rsp_dword_load_uses_zero_extended_esp`.

This report records harness gate identity and fail-closed validation. Runtime
semantics—including zero-extension of ESP, the contiguous span across 4 GiB,
and callback retry behavior—are documented in the [S3-20ef runtime report](STAGE_3_S3-20ef_2026-11-02.md). This harness slice adds no separate PC-map gate and does not claim full `od-host` acceptance.
