# S3-20dk — exact address64 SIB dword stores with signed disp32

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `0165d64` adds exactly four seven-byte singleton forms:
`89 84 0B id`, `89 84 4B id`, `89 84 8B id`, and `89 84 CB id`
(`MOV [RBX+RCX*1/2/4/8+signed disp32],EAX`). The decoder-owned
`access_address_48` calculation uses full-width RBX and RCX, the encoded SIB
scale, and signed disp32. Each store performs one contiguous checked
four-byte write of low32 RAX. The guest instruction boundary is `A+7`.

JIT source/site binding covers each of the four scales and all four encoded
disp32 bytes, with PC-map coverage at `A+7`. Host fixtures cover ordinary
checked semantics, canonical-end `#GP`, u64 range overflow, fault atomicity,
no replay, STOP, and budget. The exact host test comment was corrected to
describe the seven-byte boundary as `A+7`.
