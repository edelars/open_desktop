# Stage 3 S3-20bw: address64 indexed no-base SIB with RSI/RDI index

Implemented the exact singleton qword MOV profile `48 8B/89 /r sib disp32`: ModRM `mod=00/rm=100`, SIB base field `101` (no base), index RSI or RDI, scale 1/2/4/8, data RAX..RBP, length 8. Effective address remains decoder-owned: full-width old index multiplied by scale plus signed disp32, wrapping u64. There is no base or RIP contribution; RSI/RDI are index-only and preserved. Address32 and no-index absolute forms remain distinct.

The exact profile is admitted consistently by the checked block builder, direct V2 artifact, shared IR verifier, runtime source matcher, and bounded memory dispatcher. The matcher uses the immutable decoder-built displacement metadata and does not re-decode the raw disp32.

## Evidence

- JIT descriptor matrix covers load/store, all six data registers, RSI/RDI, all four scales, and signed disp32 values `MIN, -1, 0, 1, MAX`. It validates decoded base/index/scale/displacement/width/length, direct V2 and shared IR metadata, source identity, and truncated/invalid neighbors.
- Host direct V2/shared IR/interpreter matrix checks full CPU and RAM parity, independent `index*scale+signed_disp32` EA, callback address/width/count, and retirement. It covers high index bits and modulo-u64 wrap, exact-payload noncanonical-start and canonical-end #GP without callback, end-of-u64 overflow, architectural/backend no-commit, committed store+STOP, and disp32 final-byte target identity.
- Bounded dispatcher checks stop-RIP, STOP, zero budget, partial windows 1..7 with no effects, and resumption from actual RIP across an 8-byte native singleton, interpreter NOP, and another native singleton without repeating the first memory access.
- Stale unsupported fixtures for the newly admitted addr64 RSI-index no-base form were changed to invalid non-unit-scale no-index neighbors. Address32 no-base RSI/RDI remains rejected by this profile.
