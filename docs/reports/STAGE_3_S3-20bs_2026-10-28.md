# Stage 3 S3-20bs: address64 indexed SIB with RSP base and RSI/RDI index

## Implemented profile

Added the exact singleton `48 8B/89 /r sib [disp8|disp32]` profile: ModRM `mod=00/01/10,r/m=100`, SIB base RSP, index RSI or RDI, scale 1/2/4/8, data RAX..RBP, and instruction lengths 4/5/8. Effective-address calculation remains owned by the decoded `MemoryOperand::access_address_48`: old full RSP + old full RSI/RDI×scale + signed displacement with u64 wrapping. `data=RSP` uses the pre-instruction stack value for the address and store payload; loads commit RSP only after successful reads. RSI/RDI are index-only and are preserved.

Exact admission was added consistently to the checked block builder, shared IR verifier, direct V2 metadata/source validator, runtime site validator, and bounded dispatcher. The dispatcher continues from the committed guest RIP and compiles one singleton at a time. Existing generic register whitelists, pairs, V3, address32, and owner/MMU integration were not expanded.

## Evidence

- The JIT descriptor test covers both opcodes, all six data registers, RSI/RDI, four scales, and no-displacement/disp8/disp32 signed boundaries. It verifies the decoded operand, next RIP, independent address formula, direct V2/shared IR descriptor agreement, and rejects unsupported neighboring shapes and partial disp32 windows.
- The host matrix runs direct V2, shared IR, and interpreter from independent state/RAM snapshots across the profile matrix. It checks CPU/RAM parity, callback addresses and counts, retirement, high index bits, full-width wrapping, and `data=RSP` pre-state behavior.
- A focused full-width wrap case uses `RSP=0x1000`, `RSI=0x2000_0000_0000_0001`, scale 8, and disp8 -1; the independent oracle is `0x1007`. Direct V2 and shared IR stores match the interpreter, each with one 8-byte callback at that address.
- Exact fault checks prove RSP-base #SS at noncanonical start and end before callbacks, a low-base #GP control, and a separate canonical-range `AddressOverflow`. Architectural and backend load/store failures preserve CPU/RAM and retirement; backend callbacks retain exact addresses. Successful store+STOP commits the old RSP payload once.
- Two immutable disp32 sources differing in byte 8 produce different expected and observed callback targets.
- The borrowed dispatcher test continues across 4-, 5-, and 8-byte singleton forms using actual RIP, with one read per invocation and no replay. Entry stop-RIP, cooperative STOP, and zero budget prevent access.
- Older negative fixtures that used the now-supported RSP-base/RSI-index encoding were updated to genuinely unsupported forms; the full suites pass afterward.
