# S3-20dc — exact address-size-32 disp32 dword checked-memory store

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `28d837d` adds only the exact seven-byte singleton `67 89 83 id`
(`MOV [EBX+signed disp32],EAX`) through the shared typed-IR checked-memory
store path. Effective-address calculation remains decoder-owned: the signed
disp32 addition wraps in address-size-32 arithmetic, then the result is
zero-extended. The operation writes low32 RAX in one contiguous checked
four-byte access. The guest instruction boundary is `A+7`.

The recorded contract covers exact source/site binding and PC-map boundary,
STOP and budget behavior, checked faults, and no-replay behavior. This slice
does not admit other addr32 store forms or establish production owner/MMU,
SMC, broad workload, or performance behavior.
