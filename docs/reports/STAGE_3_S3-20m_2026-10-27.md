# S3-20m — signed direct-base disp8/disp32 shared-memory singleton

## Scope

This slice extends only the existing single-instruction qword MOV profile with
`48 8B/89 /r disp8` at ModRM `mod=01` (four bytes) and `48 8B/89 /r disp32`
at ModRM `mod=10` (seven bytes). Data/source and direct base registers are
RAX..RBX. SIB, `67`, additional prefixes, register form, trailing bytes, new
pairs, or wider blocks remain rejected. The pair sequences and unsafe
private synchronous ordinary-RAM contract are unchanged.

EA semantics remain solely in the decoder's `MemoryOperand` and existing
`access_address_48` / checked helper. Compiler raw-byte admission verifies that
ModRM mode and exact length match the decoded displacement; it performs no
address arithmetic.

## Evidence

- Shared-IR compiler tests compare direct V2 sites for all RAX..RBX aliases,
  disp8 `-128/-1/0/127`, and disp32 `MIN/-1/0/1/MAX` for load and store.
- Native direct V2 and shared IR are compared with the interpreter for those
  displacement boundaries. Each load writes its destination register that is
  also the base; each store reads its source register that is also the base.
  The disp32 min/max cases exercise signed wraparound to canonical addresses.
- Shared-IR load/store tests cover noncanonical start and noncanonical final
  byte as architectural #GP, with unchanged CPU/RAM/budget and no callback.
  They also cover backend failures as host errors and a successful store whose
  callback raises STOP; the committed bytes, next RIP and retirement remain.
- Bounded dispatch composes a disp8 singleton → bare NOP fallback → existing
  pair at budgets 0..4. It checks pre-entry STOP and continuation from the
  singleton's actual returned RIP with no repeated memory callback. Truncated
  direct windows of lengths 1..3 (disp8) and 1..6 (disp32) return
  `BoundaryReached` without effects.
- Negative compiler cases reject SIB, `67`, register form and trailing bytes.
