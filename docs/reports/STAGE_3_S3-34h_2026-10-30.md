# S3-34h — LoadThenLoad в локальном memory corpus

**Статус:** bounded partial slice реализован и прошёл независимое ревью. В corpus
добавлена только уже принятая последовательность `48 8B 03; 48 8B 0B`
(`LoadThenLoad`). Новый runtime/backend, ISA форма, ABI, Stage 2, owner path и
измерения производительности не добавлялись. Полный S3-34 и Stage 3 остаются
открытыми.

## Изменения и проверяемые контракты

Три фиксированных seed дают 3,600 уникальных входов: три последовательности,
400 случаев на последовательность и seed. Каждый случай выполняется дважды и
сравнивает полное CPU state, RAM, exit status, остаток budget, retirement,
число и порядок memory callbacks. Access trace также содержит адрес каждого
read/write. Для нового `LoadThenLoad` обе инструкции обязаны прочитать один и тот
же qword по RBX; generated offsets включают `0`, `1`, `7`, `111`, `112` и `120`,
покрывая unaligned access и оба края 128-byte fixture RAM.

Сохранённый envelope остаётся version 1 и использует прежний profile. Старые
варианты и их source bytes не менялись. Уже существующее поле `fault.site_index`
принимает site 0 и 1, а operation и architectural fault address проверяются для
выбранного site. Для новых saved observations сериализуется `memory_accesses`;
старые observations без этого optional-поля декодируются с пустой трассой.
Тесты покрывают replay original и continuation snapshot без повторного первого
чтения, site-0/site-1 fault, STOP, budget, отказ от недопустимого site и reducer,
который удерживает `LoadThenLoad`, site-1 fault, address 120 и класс mismatch
`gpr[10]`. Negative self-check удаляет второй read callback при неизменном
итоговом GPR; comparator обязан вернуть класс `callbacks`. Отдельная подмена
адреса второго чтения даёт `memory_accesses`.

Stage 3 local harness фиксирует count 3,600 и запускает отдельную точную команду
для `reducer_preserves_load_pair_site_fault_boundary_and_mismatch_class`.
Manifest, итоговый summary, argv, единственная строка `... ok` и digest лога
связаны fail-closed проверкой. В summary сохраняются два ожидаемых ignored
environment-only tests для replay/reducer из файла.
