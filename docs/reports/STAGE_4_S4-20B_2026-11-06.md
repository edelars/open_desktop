# Этап 4 — S4-20b: machine IRETQ и одна CPL3 load

**Дата:** 2026-11-06  
**Объём:** ограниченный machine path из S4-20a с одной CPL3 инструкцией;
родительский S4-20 и Stage 4 остаются открытыми.

## Реализация

`step_paged_iretq_and_user_load` выполняет synthetic paged IRETQ CPL0→CPL3,
затем при успешном commit проверяет committed CS selector/cache и запускает
ровно `48 8B 03` (`MOV RAX,[RBX]`). Machine wrapper берёт CR3 из CPU state и
сам строит explicit Ring3 `AccessContext`; caller не может передать privilege
context или альтернативный CR3. Результаты IRETQ и MOV разделены. Ошибка
следующей инструкции сохраняет уже завершённый переход в CPL3; ошибка IRETQ
не запускает MOV.

ISA allowlist принимает только точные байты `48 8B 03`, включая RAX, RBX,
qword width, zero displacement и отсутствие дополнительных префиксов.
Bounded predecode читает не более трёх байтов и прекращает чтение на первом
несовпадении; fetch faults на ожидаемых байтах сохраняются. Все три байта
должны помещаться в одной guest page; offset `0xffd` поддержан. Cross-page
instruction fetch остаётся вне профиля.

Системный путь использует tracked четырёхуровневый page walker. Успешное чтение
user page проверяет возвращённое значение и retirement. Supervisor-only fetch
даёт PFEC `0x15`, data read — `0x05`; проверяются CR2, saved RIP и U/S права на
каждом уровне. Успешный, faulting и backend-abort walks сверяют точные A-bit
updates с PTE значениями после операции; load не устанавливает D и не пишет
operand. Физическая дыра возвращается как backend abort, отдельно от guest
`#PF`. Late #PF при чтении SS descriptor подтверждает, что wrapper не
коммитит частичное IRETQ состояние и не запускает MOV. В начале MOV profile
RF очищается до operand data access; это определённое изменение RFLAGS
остаётся видимым при последующем data-access abort.

## Границы

Этот срез не реализует user stores, cross-page instruction fetch, exception
delivery из CPL3, syscall roundtrip или Linux boot. Он не меняет ограниченный
S4-20a профиль IRETQ и не заявляет поддержку произвольных user descriptors.
