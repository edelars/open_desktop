# S3-20dr — exact RBP-base dword checked-memory load with disp8

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `989b634` adds exactly the three-byte singleton `8B 45 ib`
(`MOV EAX,[RBP+disp8]`) to the shared typed-IR dword-load path. The decoded
memory operand is authoritative for full-width RBP plus signed disp8 with
wrapping. A successful checked read transfers exactly four bytes, writes EAX,
and zero-extends RAX. The JIT descriptor binds every one of the 256 disp8 byte
values to a distinct source/site identity; the instruction boundary is `A+3`.

The host fixture compares published native execution with the interpreter and
checks complete state and RAM parity, callback address and width, retirement,
and preservation of unrelated registers and flags. Address addition wraps from
`u64::MAX + 1` to zero and performs one checked four-byte read. A four-byte
range beginning at `u64::MAX - 1` reports `AddressOverflow` before a memory
callback or architectural commit. RBP noncanonical-start and canonical-start
whose range crosses the canonical boundary produce `#SS` without callback or
commit; the preserved RBX-based S3-20cr host regression supplies the `#GP`
control. Fault, zero-budget, entry STOP, and STOP raised by a successful
callback are also covered. The fixture is
bounded private synchronous RAM; it does not establish MMIO, SMC, owner
notification, MMU integration, or hardware behavior.
