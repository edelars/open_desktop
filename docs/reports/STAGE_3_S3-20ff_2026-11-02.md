# S3-20ff: address64 RAX-base Dword load with signed disp8

## Scope

This runtime slice admits only the three-byte unprefixed form
`8B 40 ib` (`MOV EAX,[RAX+sign-extended disp8]`) with Qword address size and
Dword transfer width. Effective address is the pre-instruction full-width
RAX plus signed disp8 with wrapping u64 semantics. A contiguous checked
four-byte read writes EAX and zero-extends it into RAX; other GPRs and RFLAGS
are preserved, and successful retirement commits `A+3`.

## Static review evidence

Runtime source `45aca5c` passed independent Sol review. The host fixture
source exercises all 256 disp8 encodings with an unaligned address above
4 GiB, where RAX is also the EAX destination; it compares native and
interpreter state. The fixture also contains entry guards with retry,
backend-error atomicity and retry, canonical-address faults, access-range
overflow, and callback STOP after the committed load with no replay.

These are source-review observations, not executed results. No behavior
tests, builds, formatting, Cargo checks, or Python harness were run. Exact JIT
and host gates remain pending. Harness S3-34cq pins both test identities and
passed separate Sol review; its gates were not run. See the
[normative JIT contract](../specs/JIT_CONTRACT.md#s3-20ff-exact-address64-rax-base-dword-load-with-signed-disp8),
[JIT testing reference](../testing/JIT.md#s3-20ff-exact-address64-rax-base-dword-load-with-signed-disp8),
and [S3-34cq report](STAGE_3_S3-34cq_2026-11-02.md).
