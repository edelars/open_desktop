# Этап 4 — S4-20a: CPU IRETQ outer return CPL0→CPL3

**Дата:** 2026-11-06  
**Объём:** CPU-only профиль exact paged `IRETQ`; S4-20 и Stage 4 остаются открытыми.

## Реализация

В `od-isa::iretq` добавлен отдельный `PagedCpl0ToCpl3V1`. Профиль принимает
только synthetic four-level Long64 состояние: `CpuidProfile::DiagnosticV1`
(максимальный basic leaf 1, leaf 7 нулевой), `CR0=0x80010033`, `CR4=0x20`
(`LA57=0`), ограниченный 36-bit CR3 и `EFER=0xd00`. Исходный CS cache должен
быть flat CPL0 code descriptor; видимые DS/ES/FS/GS selectors — нулевые.
Live RF должен быть очищен перед исполнением.

Гостевой CPU исполняет ровно `48 CF`, читает пятисловный outer-return frame и
GDT-only user CS/SS descriptors. Допускаются только плоские уже Accessed
дескрипторы: CS `access=0xfb, flags=0xa`; writable SS `access=0xf3, flags=0xc`.
Чтения следуют проверенному порядку: RIP/CS/RFLAGS, CS descriptor, RSP/SS,
canonicality сохранённого RIP, SS descriptor. CPU registers, RIP/RSP, flags и
CS/SS caches публикуются только после успешной валидации всех разрешённых
чтений. CPU-профиль не откатывает побочные эффекты, уже выполненные переданным
memory backend. Unit tests используют guest-memory test double и не проверяют
tracked page walker или A/D updates.

Unsupported формы frame/selector/descriptor/address/flags завершаются
`Unsupported` этого ограниченного профиля. Guest page faults из tracked memory
возвращаются как `Fault`, backend ошибки остаются `ReadAborted`. Эта задача не
добавляет архитектурную #GP/#SS-классификацию invalid return state. Machine CPL
derivation и исполнение user MOV выделены в S4-20b.

## Границы

Профиль не доказывает Linux loader handoff или запуск Ubuntu. Он не реализует
машинный CPL-aware `AccessContext`, user instruction fetch/data access,
SYSCALL/SYSRET, TSS stack switch, exception delivery из CPL3, general-purpose
IRETQ либо точную #GP/#SS priority вне заявленного профиля. Для IRETQ
read/fault ordering использованы Intel SDM revision 090 Vol. 2A (операция
IRET/IRETD/IRETQ) и Vol. 3A §§7.14.2–7.14.3:
[официальный combined manual](https://cdrdv2-public.intel.com/874240/325462-090-sdm-vol-1-2abcd-3abcd-4.pdf).
