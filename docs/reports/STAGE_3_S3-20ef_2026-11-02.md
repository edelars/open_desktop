# S3-20ef — exact address-size-32 ESP-base dword load

## Scope

S3-20ef admits only the exact four-byte singleton `67 8B 04 24`
(`MOV EAX,[ESP]`) through the shared typed-IR checked-load path. The address
size is 32 bits, the SIB base is ESP, there is no index, scale is 1, and the
displacement is zero. Effective address is `u64(RSP as u32)`: high RSP bits
are ignored and ESP is zero-extended. The checked load reads four contiguous
guest-memory bytes, zero-extends EAX into RAX, and advances RIP to `A+4`.

For ESP `0xffff_fffe`, the read touches `0xffff_fffe`, `0xffff_ffff`,
`0x1_0000_0000`, and `0x1_0000_0001`; the four-byte span does not wrap at
4 GiB. Host fixtures demonstrate successful reads with several poisoned high
RSP patterns. This is not an address-derived RSP `#SS` case; no such fault
claim is made. The slice does not establish production owner/MMU, MMIO/SMC,
physical-hardware, or performance behavior.

## Evidence

- JIT gate `memory_load_v2::tests::ir_dword_addr32_rsp_sib_load_binds_exact_source_and_site`: 1/1. It pins the exact source, address-size/base/index/scale/displacement metadata, and `A+4` boundary; neighboring indexed SIB and other encodings remain rejected.
- Host gate `tests::s3_20ef_addr32_rsp_dword_load_uses_zero_extended_esp`: 1/1. It compares interpreter state and memory for ordinary and poisoned high32 RSP values, verifies one width-four read and the span crossing 4 GiB, injected architectural/unmapped read-error atomicity, STOP/budget, and callback STOP followed by retry rejection without a second read.
- The pre-existing negative JIT gate `memory_load_v2::tests::ir_dword_rsp_sib_load_binds_exact_source_and_site` and adjacent host gates `tests::s3_20cx_addr32_dword_load_uses_zero_extended_ebx` and `tests::s3_20cz_addr32_disp8_dword_load_uses_wrapped_ebx` passed 1/1.
- On runtime author commit `392886b`, `od-jit` passed 344/344; the new exact JIT/host, old negative JIT, and S3-20cx/S3-20cz adjacent host gates passed 1/1. Formatting, affected-crate `cargo check`, diff-check, Graphify, and independent runtime Sol review passed. The review fix restored the existing indexed-base guard; callback STOP retry is rejected without a second read.
- After root integration (`a0ce871` runtime, `1ba352a` harness), exact S3-20ef JIT/host gates passed 1/1 and the full Python Stage 3 harness passed 91/91. Root Graphify refresh reported 12,048 nodes.
