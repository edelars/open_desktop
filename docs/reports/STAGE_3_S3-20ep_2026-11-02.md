# S3-20ep: exact RCX-indexed no-base SIB disp32 Dword load

## Scope and semantics

This runtime slice admits only the exact unprefixed seven-byte singleton
`8B 04 0D disp32` (`MOV EAX,[RCX+disp32]`): address64, SIB with no base,
RCX as the index at scale 1, and a Dword transfer. Effective address
calculation uses the full RCX value plus sign-extended disp32 with wrapping
u64 arithmetic. The checked read is one contiguous four-byte access; writing
EAX zero-extends into RAX, and the guest instruction boundary is `A+7`.
Other prefixes and neighboring SIB encodings remain outside this exact
admission.

The exact JIT fixture is
`memory_load_v2::tests::ir_dword_rcx_index_no_base_sib_disp32_load_binds_all_source_bytes_to_its_site`.
The exact host fixture is
`tests::s3_20ep_rcx_index_no_base_sib_disp32_dword_load_uses_signed_displacement`.
Their exact gates are pinned by harness S3-34ca. The runtime tests were not
executed for this slice, so the fixture names and intended scope are not
runtime test evidence.
