# Stage 3 S3-11 implementation report — 2026-10-26

## Scope and result

This implementation adds a pure W64 ADD/SUB/CMP flag helper in `od-isa`, a
small scalar helper ABI adapter in `od-jit`, and staged eager flags plus JZ/JNZ
RIP selection in the production data-effect emitter. It intentionally does
not commit guest architectural state: helper errors return a host-contract
sentinel, and successful generated entries return
`DATA_EFFECTS_UNCOMMITTED_V1` with zero retired guest instructions. Commit and
state recovery remain S3-12 work. No decoder, Stage 2, or runtime dispatch
changes are included.

The arithmetic flag mask is `0x8d5` (CF/PF/AF/ZF/SF/OF). The helper preserves
every other incoming RFLAGS bit. `od-host` tests execute published ARM64 code
from the full decoder → block → IR → allocator → emitter path for allocator
budgets 0..=4. Tests cover distinct arithmetic operands, wrapping/borrow,
aliasing, CMP's scratch-only result, MOV flag preservation, taken and not-taken
JZ/JNZ, helper register clobbers, and nonzero helper statuses without current
instruction output or terminal selection.
