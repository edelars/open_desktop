# Stage 3 S3-20au: absolute qword MOV through no-base/no-index SIB

## Scope and result

Added the exact singleton profile `48 8B/89 /r 25 disp32`: ModRM `mod=00,r/m=100`, SIB exactly `0x25`, data register RAX..RBP, and instruction length eight. The decoder's `MemoryOperand` and `access_address_48` remain the sole effective-address implementation. The disp32 is sign-extended in 64-bit address mode; the absolute address does not depend on guest GPRs or RIP.

The whitelist does not include indexed no-base SIB, address32, other SIB values, moffs, pairs, or V3. No owner/MMU integration, Stage2/od-isa changes, Mini run, or performance measurement is claimed.

## Evidence

- The JIT descriptor test covers load/store, all six data registers, and displacements `i32::MIN`, `-8`, `-1`, `0`, and `i32::MAX`. It checks direct V2 and shared IR site equality, immutable artifact source snapshots, decoded base/index/scale and widths, signed displacement, and next RIP. The runtime source-profile matcher checks the fixed opcode/ModRM/SIB shape and uses the displacement already stored in the decoder-built artifact; it does not re-decode or compare raw disp32 bytes. Partial source windows 1..7 do not compile. Existing invalid-form tests now use indexed no-base SIB as the unsupported neighbor, because the exact no-base/no-index profile is admitted by this slice.
- Host parity covers direct V2, shared IR, and interpreter for both operations and all six data registers, comparing full CPU state, full RAM, callbacks, and retirement. Expected targets use the independent sign-extended-displacement formula even after guest GPRs and RIP are changed. A qword at `-8` is observed as one contiguous callback from `u64::MAX - 7` through `u64::MAX`; `-1` returns AddressOverflow before any callback.
- Architectural faults preserve exact guest-fault payload and leave CPU/RAM/budget/retirement uncommitted. Backend read/write failures remain host errors and preserve CPU and RAM. Successful store+STOP commits the complete qword once and returns at RIP+8.
- Two immutable decoder-built artifacts whose source differs only in byte eight execute distinct expected targets (`0` and `0x0100_0000`), confirming that displacement metadata is carried through compilation to execution. This is not a raw-displacement-byte comparison in the runtime matcher. A same-displacement comparison confirms this absolute form resolves to `0x20`, while `mod=00,r/m=101` RIP-relative resolves to `ENTRY + 7 + 0x20`.
- The borrowed dispatcher runs the absolute singleton, NOP, and existing pair continuously; budget 0..4 matches interpreter state and RAM. Budget-split continuation resumes from actual RIP without replaying the first read. Partial windows 1..7 return `BoundaryReached` with zero blocks/effects; the complete address32 neighbor and other forbidden forms return `Unsupported` without effects.
