# S3-20dv — exact address-size-32 RBP-base dword checked-memory load with disp8

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `8e8f1a3` adds only the four-byte singleton `67 8B 45 ib`
(`MOV EAX,[EBP+disp8]`) to the shared typed-IR Dword-load path. The decoded
operand uses low32 RBP plus signed disp8, wraps that sum modulo 2^32, and
zero-extends the effective address. A successful read transfers exactly four
contiguous bytes, writes EAX and zero-extends it into RAX. The guest boundary
is `A+4`.

The JIT descriptor test binds all 256 encoded disp8 bytes to distinct
source/site identities and checks the `A+4` boundary. The bounded host fixture
does not repeat all 256 cases: it checks the two signed edges (`-128` and
`+127`), each with low and high full-width RBP values. Native execution is
compared with the interpreter for CPU/RAM state and read callbacks. One case
reads four contiguous bytes starting at `0xffffffff`, crossing the 4-GiB
boundary into the next address range; the address-size wrap applies to the
starting effective address, not to each byte of the memory transfer. The
result is zero-extended into RAX. Read errors leave state and RAM uncommitted;
budget, stop-address, entry STOP, and successful callback STOP behavior are
covered. This address-size-32 EBP form makes no address-size-64 RBP `#SS`
claim, and it does not add other bases/forms, prefixes, SIB, or displacement
widths.
