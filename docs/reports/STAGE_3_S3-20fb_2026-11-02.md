# S3-20fb: address32 RAX-indexed no-base SIB Dword load

## Scope

This runtime slice adds one exact shared typed-IR Dword-load profile: the
eight-byte form `67 8B 04 05 disp32` (`MOV EAX,[low32(RAX)+signed disp32]`).
The `67` prefix selects Dword address size; SIB has no base, RAX index, and
scale 1. The effective address is
`zero_extend_64((low32(original RAX) + sign-extended disp32) mod 2^32)`. The
checked four-byte load writes EAX, zero-extends the result into RAX, preserves
other GPRs and RFLAGS, and commits the guest boundary `A+8` on success.

The code change is integrated at `bf8dae1`. It expands the bounded shared
typed-IR load matcher for this exact form and adds JIT source/site and host
fixture gates. The
[normative contract](../specs/JIT_CONTRACT.md#s3-20fb-exact-address32-rax-indexed-no-base-sib-dword-load)
records the profile and exclusions.

## Static review evidence

Independent Sol/high static review passed. The review examined the exact
prefix/opcode/SIB form, decoder-owned addr32 effective-address behavior,
pre-instruction RAX use, source/site and displacement-byte identity, EAX
zero-extension, and the `A+8` boundary. The added host fixture source compares
the native path with the interpreter for representative signed displacements
and low32 wrap cases, and includes entry guard, budget, backend-error retry,
and callback STOP/no-replay cases.

These are source-review observations, not executed results. No behavior tests,
builds, formatting, Cargo checks, Python harness, or machine smoke were run.
