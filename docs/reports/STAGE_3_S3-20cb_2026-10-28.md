# Stage 3 S3-20cb: address32 low-base SIB with no index

## Scope and implementation

Added only singleton qword MOV forms `67 48 8B/89 /r sib [disp8|disp32]`: ModRM `mod=00/01/10,r/m=100`, SIB exactly `0x20..=0x23`, base RAX..RBX, data RAX..RBP, and lengths 5/6/9. The SIB index field `100` with extension clear is the absent-index sentinel, not guest RSP; scale is one. No other SIB shape, prefix, base/index/data register, pair, V3, production owner/MMU, Stage 2, or ISA profile was added.

The decoder-owned `MemoryOperand::access_address_48` remains the effective-address implementation. It truncates the old base and adds the signed displacement modulo 2^32, then zero-extends the result for the contiguous qword transfer. The base GPR remains unchanged unless it is the load destination; when data=base, the old base supplies the EA (and store payload), and a successful load commits the full qword to that destination. Admission is aligned across checked block construction, direct V2 and shared IR sites, immutable source matching, and bounded dispatcher compilation.

## Evidence

The JIT descriptor matrix covers both opcodes, all four bases, all six data registers, mod00/disp8/disp32 forms, signed displacement edges, exact operand/source metadata, partial windows, and invalid neighbors. Separate disp32 artifacts differing in the ninth source byte resolve to distinct decoder-derived targets.

The host matrix executes direct V2, shared IR, and interpreter across 480 combinations: load/store × four bases × six data registers × ten displacement cases. It compares full CPU and RAM, independent low32 EA, callback address/width/count, and retirement. Each result is also compared with the equivalent address32 direct-base interpreter encoding, normalizing RIP for its shorter source form.

Additional checks exercise a qword callback starting at `0xffff_fffc`, backend and architectural read/write errors with no CPU/RAM commit, exact callbacks, store+STOP with the full qword committed once, entry STOP/stop-RIP/zero-budget guards, and bounded dispatcher continuation from actual RIP through 5/6/9-byte singletons into the frozen pair without repeating the first access. Partial execution windows return at the entry RIP with zero publication, retirement, or memory callbacks.
