# S3-29a: bounded demand-driven flags correctness candidate

**Status:** Bounded candidate implemented; eager remains the reference/default.
This report does not close S3-29, choose a production strategy, or claim a
performance improvement.

## Implemented contract

Added `compile_block_demand_flags_candidate` and
`emit_runtime_block_demand_flags_candidate` as an explicit opt-in path. The
path is separate from eager compilation and is not called by the shared block
cache. It requires a 192-byte reserved frame prefix; the eager 176-byte layout
and eager code path remain unchanged.

For each existing W64 full arithmetic writer, the candidate saves the original
lhs/rhs to dedicated stack slots and replaces a compile-time pending descriptor
with `{operation, width, saved operand slots}`. MOV preserves it. A later
ADD/SUB/CMP overwrites it without calculating flags for the earlier writer.
The helper receives the saved pair and the last staged pre-write RFLAGS, using
the existing `od_isa::integer_flags` semantics. The candidate materializes at
JZ/JNZ observation or on a taken guard/terminal return. Fast guards do not call
the helper. Successful materialization writes staged and canonical RFLAGS;
pending commit boundaries and PC ranges are marked
`InadmissiblePendingFlags`. Helper failure returns the existing mapped host
contract error.

The candidate remains limited to the existing W64 register-only ADD/SUB/CMP,
flag-preserving MOV and JZ/JNZ profile. No ADC/SBB, partial writer, memory
helper, new instruction, shared-cache publication or default change was added.

## Correctness coverage

Native host cases compare candidate with eager state/exit/accounting and one
arithmetic chain with `od_isa::execute::step`. They cover ADD→SUB, CMP→ADD,
ADD RAX,RAX alias/equal inputs, ADD→MOV immediate that overwrites RAX,
arithmetic→MOV→JZ/JNZ with both taken/not-taken outcomes, register homes 0..4,
budget exits between writers, zero budget, stop-RIP, unsupported tail,
deferred-decode exit and mapped helper failure. An instrumented helper proves
that two uninterrupted full writers call it once with the final writer's
operation/operands; an exit between writers materializes the earlier pair; a
zero-budget return makes no call. The opt-in fallback compiler and native host
test also verify canonical state at the `NeedInterpreter` boundary before the
existing bare-NOP fallback. JIT map tests verify pending boundaries are not
labelled canonical and reject the eager frame prefix for candidate mode.
