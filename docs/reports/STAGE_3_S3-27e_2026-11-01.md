# S3-27e — two-site V2 memory PC-map attribution

**Status:** bounded test slice complete; S3-27 and Stage 3 remain open.

## Scope

Commit `6493f940cdf51504182896dec8050e1084f05270` adds test coverage only in
`crates/od-jit/src/memory_load_v2.rs` and
`crates/od-host/tests/memory_corpus.rs`. It does not change generated runtime
behavior.

The compiler regression covers the exact two-site store→load, load→store, and
load→load sequences. It checks that the map partitions all emitted code into
checked, contiguous ranges; attributes both instructions and the shared
Service epilogue; preserves expected guest RIP and snapshot admissibility; and
places the two canonical committed retirement boundaries correctly. Negative
mutations verify rejection of wrong instruction/site attribution, incorrect
shared-Service attribution, a wrong guest RIP, incorrect committed count, and
an invalid replay classification after a helper.

The host regression checks the published map against its compiler artifact,
then republishes at a distinct RIP and sequence. It checks distinct maps for
different publications and compares each publication with its own artifact
map; it also checks map persistence after the artifact lifetime ends.

## Evidence

On the local Mac, both focused tests passed (1/1 each):

- `cargo test -p od-jit ir_two_site_pc_maps_attribute_all_checked_ranges_and_boundaries --offline`
- `cargo test -p od-host --test memory_corpus published_two_site_pc_map_matches_artifact_and_outlives_artifact --offline`

Independent Sol review passed after corrections to shared Service epilogue
attribution and republication assertions. The implementation commit contains
only the two test-file additions listed above.

## Limits

This evidence establishes the two-site PC-map contract and publication/map
lifetime behavior for the tested fixture. It does not establish arbitrary host
fault recovery, guest architectural fault delivery, production owner/MMU
integration, or full S3-27 acceptance. This test-only slice includes no
performance measurement; Mini checks remain deferred until the end of Stage 3.
