# Stage 3 S3-20bp: address64 no-displacement SIB with RSI/RDI index

## Scope

This slice admits only singleton `48 8B/89 /r sib`: ModRM `mod=00/rm=100`, SIB base RAX..RBX, index exactly RSI or RDI, scale 1/2/4/8, data RAX..RBP, instruction length 4. EA semantics remain decoder-owned through `MemoryOperand::access_address_48`: old full base plus old full index times scale, with wrapping u64. When data=base, the pre-instruction base value supplies both the EA and store payload; a load to the base commits only after the read succeeds. RSI/RDI are address-only index registers here and remain unchanged. No generic index/data whitelist was widened; address32, displacement, no-index/no-base, other bases/indices, extra prefixes, pairs and V3 remain outside this profile.

## Evidence

- `od-jit` descriptor coverage tests loads and stores across 4 low bases × 2 indices × 4 scales × 6 data registers. Direct V2 and shared IR descriptors verify exact bytes, decoded operand metadata and consumed length. Unsupported neighboring forms and byte windows 1–3 are rejected.
- Host direct V2/shared IR/interpreter parity covers the same complete matrix, compares full CPU and RAM snapshots, independently computes `base.wrapping_add(index.wrapping_mul(scale))`, and asserts exact callback direction, address, length, and one retirement. Store cases verify the full pre-state data value.
- The bounded dispatcher test continues from actual RIP through this singleton, an explicit NOP fallback, and the existing native pair without replay. It verifies noncanonical start/end #GP before callbacks, separate u64 AddressOverflow, architectural and backend failures without state/RAM commit, store+STOP commit, stop-RIP/STOP/zero-budget guards, partial source windows, and an unsupported neighboring RSI-base/RSI-index form.
