# Stage 3 S3-20bl: address64 indexed SIB with RSI/RDI base and displacement

## Scope

Adds one exact singleton qword memory profile: `48 8B/89 /r sib disp8|disp32`, ModRM `mod=01/10,r/m=100`, SIB base RSI/RDI, index RAX..RBX, scale 1/2/4/8, data RAX..RBP, instruction length 5/8. Effective-address semantics remain in decoder-owned `MemoryOperand::access_address_48`: old full base + old full index × scale + signed displacement, wrapping in u64.

No address32, no-index/no-base, other base/index, extra prefixes, pair/V3 profile, owner/MMU integration, Stage 2/ISA, Mini or physical/performance work is included. The existing no-displacement 20bk profile remains covered.

## Evidence

- JIT descriptor tests cover load/store, RSI/RDI, all four low index registers, all four scales, all six data registers, and signed disp8/disp32 boundaries. Negative neighbors include RBP index, RBP base, address32, and truncated displacements.
- The runtime source matcher validates opcode/ModRM/SIB shape, consumed length, and decoded displacement width. It does not re-decode raw displacement bytes; source bytes and decoder operand come from the same immutable compile-time snapshot.
- Host tests compare direct V2 and shared IR native execution against the interpreter for full state and RAM, exact callback address/count, retirement and pre-state alias behavior. The target oracle independently computes `old_base.wrapping_add(old_index.wrapping_mul(scale)).wrapping_add_signed(displacement)`.
- Two immutable disp32 artifacts differing only in the final displacement byte independently target `0x1000` and `0x0100_1000`. A displaced high-index pre-state alias case checks scale-8 u64 wrapping and signed disp8 `-1`, yielding target `0x1ff7`.
- Dispatcher coverage checks actual-RIP continuation from both disp8 and disp32 singleton forms through interpreter NOP fallback and the existing two-instruction pair without repeating the first memory read; it also checks STOP/budget entry guards, partial byte windows, #GP start/end with no callback, AddressOverflow, backend error without commit, and successful store+STOP commit.
