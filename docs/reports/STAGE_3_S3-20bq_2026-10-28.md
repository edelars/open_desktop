# Stage 3 S3-20bq: address64 indexed SIB with RSI/RDI index and displacement

## Scope

This slice admits only singleton `48 8B/89 /r sib disp8|disp32`: ModRM `mod=01/10,r/m=100`, SIB base RAX..RBX, index RSI or RDI, scale 1/2/4/8, data RAX..RBP, and instruction length 5 or 8. `MemoryOperand::access_address_48` remains the sole effective-address implementation: old full-width base + old full-width index × scale + signed displacement, wrapping u64. A load to the base uses its pre-instruction value for EA and commits only after a successful read; RSI/RDI are address-only index registers and stay unchanged. Generic register whitelists are unchanged. Address32, stack/no-base, other indices/bases, extra prefixes, pair profiles and V3 remain outside this profile.

## Evidence

- The JIT descriptor matrix covers load/store × four low bases × RSI/RDI × four scales × six data registers at signed disp8 and disp32 boundaries. Direct V2 and shared IR descriptors retain exact source bytes and decoded operand metadata; invalid neighbors and every partial source window are rejected.
- Host direct V2/shared IR/interpreter parity compares full CPU and RAM state, exact callback address/count, and retirement across the same matrix. Targets are independently calculated from pre-state full-width base/index and signed displacement. Dedicated cases prove that high index bits participate and base/index addition wraps u64. The tests check data=base pre-state behavior and preserved RSI/RDI values.
- Two fixed-register disp32 artifacts differ only in the final displacement byte and access distinct independently calculated targets. The dispatcher resumes from actual RIP after both the 5-byte disp8 and 8-byte disp32 singleton, then runs explicit NOP fallback and the frozen pair without repeating the first access.
- Exact-profile cases check #GP at noncanonical start/end before callbacks, separate qword endpoint AddressOverflow, guest architectural and backend failures without commit, committed store+STOP, stop-RIP/STOP/budget-zero entry guards, partial windows, and an unsupported neighboring stack-base/index form.
