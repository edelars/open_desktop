# S3-20do — exact address-size-32 SIB dword stores with signed disp8

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `6db2dff` adds exactly four five-byte singleton forms:
`67 89 44 0B ib`, `67 89 44 4B ib`, `67 89 44 8B ib`, and `67 89 44 CB ib`
(`MOV [EBX+ECX*1/2/4/8+disp8],EAX`). The decoder-owned address-size-32
effective address adds low32 EBX, low32 ECX multiplied by the selected SIB
scale, and signed disp8; it wraps to 32 bits and zero-extends before canonical
checking. Each store commits low32 RAX through one contiguous checked
four-byte write. Source/site binding covers all four scales × all 256 signed
disp8 values; the PC-map boundary is `A+5`. Fixtures cover atomic faults,
STOP, and budget behavior.
