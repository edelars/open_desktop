# Stage 3 S3-20ci: address64 direct low-base MOV with RSI/RDI data and displacement

Implemented the exact singleton qword forms `48 8B/89 /r disp8|disp32`: ModRM `mod=01/10`, data RSI/RDI (`reg=6|7`), base RAX/RCX/RDX/RBX (`r/m=0..3`), lengths 4/7. SIB, `67`, added prefixes, other base/data registers, pair and V3 forms remain unsupported. Effective-address calculation remains decoder-owned: full old base plus signed displacement with wrapping u64.

Scoped IR source/write permissions now cover only the matching checked store/load form; arbitrary RSI/RDI reads and generic GPR validation are unchanged. Direct V2, shared IR, runtime metadata and source-byte checks use the same operation-specific bounds. The source matcher compares signed disp8/disp32 bytes to the decoded displacement, including the final disp32 byte. Bounded dispatch routes only the exact 4/7-byte low-base forms.

Coverage added:

- JIT descriptor matrix covers all 32 opcode/data/base/displacement-width combinations, signed displacement boundaries, partial windows 1..3/1..6, exact next RIP, source identity and forbidden neighbors.
- Host direct V2/shared IR/interpreter matrix compares full CPU and RAM, one qword callback at the independently computed target, and one retirement. Successful full-u64 wrap to address zero is compared across all three paths.
- Noncanonical start/end fault before callback, canonical upper-half qword endpoint overflow, backend read/write failure atomicity, zero-budget guards, and one full qword store followed by STOP are covered.
- Bounded dispatch continues from actual RIP through 4/7-byte load/store forms to a NOP without replay; a forbidden RBP-base neighbor is rejected before execution.
- Existing 176-byte runtime frame, 4096-byte emitted block cap and the 10×MOV size regression at 3868 bytes remain covered.
