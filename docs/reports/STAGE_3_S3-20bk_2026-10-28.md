# Stage 3 S3-20bk: address64 indexed SIB with RSI/RDI base

## Scope and implementation

Added the exact four-byte singleton profile `48 8B/89 /r sib`: ModRM `mod=00/rm=100`, SIB base RSI or RDI, index RAX..RBX, scale 1/2/4/8, and data RAX..RBP. Address and transfer sizes are Qword. The profile excludes address-size override, displacement, no-index/no-base forms, RBP/RSI/RDI indexes, extra prefixes, pair admission changes, and V3 changes.

The decoded `MemoryOperand::access_address_48` remains the effective-address implementation. The target is the full pre-instruction base plus the full pre-instruction index multiplied by scale, with u64 wrapping. Direct V2, shared IR, host metadata/source validation, and borrowed dispatch accept the same exact form.

## Acceptance evidence

- JIT descriptor coverage: both load/store opcodes, RSI/RDI bases, four low-GPR indexes, all four scales, and all six data registers. It checks decoded operand/site fields and source bytes, and rejects partial 1..3 byte windows, no-index/no-base, displacement, address32, RBP-index, and missing-SIB neighbors.
- Host direct V2/shared IR/interpreter parity: all load/store × base × index × scale × data combinations. It checks full CPU state, RAM, exact callback address/length/count, retirement, and pre-state `data=index` alias behavior; RSI/RDI bases are outside the RAX..RBP data-register set and remain preserved. The independent oracle is `old_base.wrapping_add(old_index.wrapping_mul(scale))`; high-half base and index values exercise full 64-bit contributions and wrapping while keeping targets canonical.
- Dispatcher continuation: budget-split SIB singleton → explicit NOP interpreter fallback → existing native pair; each continuation starts at actual RIP and does not repeat the first memory access.
- Fault and commit behavior: noncanonical start and noncanonical end of the qword range raise #GP with unchanged CPU state, zero callback count and zero retirement. A canonical high-half start with a range overflowing u64 remains AddressOverflow without a callback. Entry STOP and zero budget execute no block and make no callback. A successful exact-profile store triggers STOP from the callback after one committed qword write at the next RIP.
