# S3-20ee — exact RSP disp32 dword store

## Scope

S3-20ee admits only the exact address64 seven-byte singleton `89 84 24 id`
(`MOV [RSP+disp32],EAX`) through the shared typed-IR checked-store path. The
SIB uses scale 1 and no index; the decoder-owned effective address adds
sign-extended disp32 to full-width RSP with wrapping u64 arithmetic. A
successful checked store writes low32 RAX in one contiguous width-four
operation and advances guest RIP to `A+7`.

The JIT fixture covers nine representative signed disp32 values, mutations of
each encoded displacement byte, source/site binding, and the typed-IR
single-instruction PC-map boundary. It is not exhaustive across all 2^32
disp32 values and is not a separate published-map integration gate. The slice
makes no production owner/MMU, MMIO/SMC, physical-hardware, or performance
claim.

## Evidence

- JIT gate `memory_load_v2::tests::ir_dword_rsp_sib_disp32_store_binds_all_source_bytes_to_its_site`: 1/1. It binds nine signed representatives, verifies four-byte source mutations and exact site metadata, and checks the `A+7` boundary.
- Host gate `tests::s3_20ee_rsp_disp32_dword_store_preserves_ss_fault_and_checked_state`: 1/1. It checks signed representatives with interpreter parity, one width-four write, wrap-to-zero, RSP `#SS` versus RBX `#GP`, overflow/backend-write-error atomicity, entry STOP/budget, callback STOP commit, and no-replay at `A+7`.
- On author runtime commit `7a07588`, the full `od-jit` library passed 343/343; the exact S3-20ee JIT/host gates and adjacent S3-20ec JIT/host gates passed 1/1. Runtime Sol review, formatting, and affected-crate `cargo check` passed.
