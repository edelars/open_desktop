# S3-40w. Оставшийся разрыв интерпретатора на двух MOV

Проверка ISSUE-521 сравнивает `d9ecaa2` с исторической сборкой
`d24865d` на тех же 2 400 входах S3-34a, по 1 200 на порядок
операций. После изменений декодера и обычного RUN отдельное
декодирование быстрее исторического варианта в каждом парном раунде.
Оставшееся отставание воспроизводится на полных вызовах RUN и STEP.

## Методика

Одинаковый драйвер на Apple M3 Max (Mac15,11), macOS 26.7.1 (25G241)
и rustc 1.99.0 собран для двух ревизий в ARM64 Release.
Оба бинарника подписаны с Hardened Runtime и `allow-jit`.
Перед таймерами каждый процесс подтвердил обычный UID, `nice -5`
и QoS `USER_INTERACTIVE`. Шесть предварительных проб дали
87,5–93,6% простоя CPU. Во время зачётной серии 25 проб дали
77,8–89,3% с медианой 82,9%.

Сравниваются три отдельные границы вызова. RUN выполняет пару MOV
одним публичным вызовом с бюджетом 2. STEP исполняет те же инструкции
двумя публичными вызовами. Decode делает два вызова long-mode декодера
по адресам инструкций и проверяет отсутствие data callbacks.
Вне таймеров драйвер сбрасывает состояние и RAM, проверяет результат
и порядок обращений. Эталон состояния для STEP формируется через RUN
в той же сборке. RUN также проверяется по выходу на бюджете, числу
завершённых инструкций, определённым флагам и ожидаемым обращениям.

Пилоты задали общие числа проходов 2 417 и 2 365, то есть
2 900 400 и 2 838 000 пар инструкций на интервал соответственно для
store→load и load→store. Порядок двух процессов чередуется между
шестью парными раундами. В каждом процессе шесть троек покрывают
все перестановки RUN, STEP и decode. Порядок задан детерминированно.
Аудит подтвердил все 432 интервала и 1 239 494 400 измеренных пар
инструкций или декодирований. Кратчайший интервал составил
87,028 мс при пороге 45 мс.

## Результат

Отношение current/historical получено из медиан в каждом
парном раунде. В скобках указаны крайние значения шести раундов.

| Поток | RUN | Два STEP | Два decode |
| --- | ---: | ---: | ---: |
| Store → load | 2.073 [2.038, 2.105] | 2.794 [2.774, 2.884] | 0.740 [0.726, 0.746] |
| Load → store | 2.107 [2.047, 2.164] | 2.872 [2.803, 2.926] | 0.730 [0.724, 0.735] |

| Поток | RUN, historical → current | Два STEP, historical → current | Два decode, historical → current |
| --- | ---: | ---: | ---: |
| Store → load | 125.6 → 260.0 | 122.4 → 342.9 | 42.3 → 31.3 |
| Load → store | 124.3 → 261.2 | 120.4 → 342.9 | 43.1 → 31.3 |

Во второй таблице указаны медианы по всем интервалам сборки в нс
на пару. Время включает накладные расходы вызовов и таймеров.
У трёх контролей разные границы публичных вызовов и отдельный
машинный код. Данные сравнивают эти границы целиком. Для атрибуции
стоимости внутри RUN или STEP нужны отдельные измерения этого пути.

На обеих последовательностях современный STEP занимает больше
времени, чем полный RUN. Следующий проверяемый вариант переносит
специализацию с пустыми профилями из RUN в обычный STEP.
ISSUE-521 остаётся открытой.

поля `files`, сверьте их `file_sha256` и запустите

Для нового измерения используйте команды из сохранённого `README.md`.
