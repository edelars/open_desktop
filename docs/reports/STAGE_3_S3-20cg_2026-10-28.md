# S3-20cg: Address64 qword store from RSI/RDI

**Статус:** реализация и локальные проверки завершены; ожидается независимое ревью. Mini/performance и `od-machine` отложены до конца Stage 3 и остаются вне scope.

## Реализовано

- Принимается только `48 89 /r` длины 3 с ModRM `mod=00`, source RSI/RDI и base RAX/RCX/RDX/RBX.
- Admission добавлен только для `CheckedStore` в block admission, lowering, IR verifier и MemorySite V2 runtime profile/source-byte matching. Общий `validate_gpr`, frame layout и GPR staging не расширялись.
- Store helper получает полное 64-битное значение source из canonical guest state; успешная операция меняет только RIP/retirement по существующему контракту.
- Симметричные `48 8B` в RSI/RDI, addr32, displacement/SIB, REX.R/B и R8 source остаются отклонёнными.
- Добавлены тесты восьми разрешённых кодировок для direct и IR compiler admission, отрицательные формы, а также host direct/IR execution против interpreter с высокими source bits, полным состоянием CPU/RAM и ровно одной записью/retirement. Дополнительные проверки для RSI и RDI покрывают неуспешную запись и budget-zero entry guard в direct и IR путях; ошибки не меняют CPU/RAM и не фиксируют retirement, guard не вызывает запись.

## Ревью и ограничения

Первое независимое ревью обнаружило две проблемы тестового покрытия: отсутствие явной проверки ожидаемого IR RIP и отсутствие новых fault/guard кейсов для RSI/RDI. Оба замечания исправлены. Повторное ревью `gpt-6.1-sol/high` подтвердило исправления и выдало signoff без блокирующих замечаний. Коммит не создавался.
