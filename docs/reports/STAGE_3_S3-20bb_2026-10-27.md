## Scope and behavior

Added one exact singleton qword MOV profile: `48 8B/89 /r sib`, ModRM
`mod=00/01/10,r/m=100`, SIB base RSP and index RBP, scale 1/2/4/8, and data
register RAX..RBP. Encoded lengths are 4, 5, and 8 bytes. Admission is a
scoped exception; the general index whitelist remains RAX..RBX. The decoder's
`MemoryOperand` and `access_address_48` provide all effective-address
semantics, including wrapping 64-bit arithmetic and canonical/range checks.
No pair/V3 profile or executable-memory frame/ABI change was made.

Direct V2, shared IR, and bounded dispatcher recognize the same exact profile.
The descriptor test covers both directions, all six data registers, four
scales, and all three ModRM widths. The host test checks direct V2/shared
IR/interpreter parity for full CPU and RAM state, exact callback addresses and
counts, retirement, pre-state aliases where data is RSP or RBP, and a wrapping
effective address. Fault evidence checks RSP-base #SS at noncanonical start and
qword end without backend callbacks, a low-GPR-base #GP control, distinct
AddressOverflow classification, and backend failures with exact callback
identity and no architectural commit. A successful store followed by STOP
commits once. Dispatcher coverage checks budget split and resume at the actual
RIP through the explicit NOP bridge and existing pair without replay; partial
byte windows return fixture `BoundaryReached` with no effects.

Previously supported forms remain covered. Three legacy negative fixtures
that used to encode RSP-base/RBP-index shapes were changed to genuinely
out-of-profile no-base or RBP-base/RBP-index forms; those fixtures now match
the expanded admission contract.
