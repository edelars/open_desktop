# Stage 3 S3-20ay report

## Scope and implementation

Added one exact qword singleton profile: `48 8B/89 /r sib`, ModRM `mod=00,r/m=100`, data RAX..RBP, base RAX..RBX, index RBP, scale 1/2/4/8, and exactly four instruction bytes. The branch is explicit; the generic index whitelist remains RAX..RBX, so SIB index field `100` with `REX.X=0` continues to mean no index. No displacement, address-size override, other base/index, pair/V3, owner/MMU, Stage 2, or ISA behavior was added.

Direct V2, shared IR, host metadata/runtime validation, and the borrowed dispatcher share the exact profile. Effective-address semantics remain in the decoder's `MemoryOperand` and `access_address_48`; the guest target is `base + RBP * scale` with wrapping 64-bit arithmetic. The runtime matcher uses immutable decoder-built artifact metadata and does not independently re-decode instruction bytes.

## Evidence

- JIT descriptor coverage compares direct V2 and shared IR for load/store, all six data registers, all four permitted base registers, and all four scales. It checks exact instruction/site metadata and pre-state alias forms (`data=base` and `data=RBP`); no-index `SIB=0x24` stays separately validated.
- Host differential coverage compares direct V2, shared IR, and interpreter CPU/RAM state, exact memory callback address/count/width, and retirement. The EA oracle independently computes `base.wrapping_add(rbp.wrapping_mul(scale))`; RBP has nonzero high bits, and changing unrelated RIP/RSP does not affect the target.
- Coverage includes wrap to zero, noncanonical start and end #GP with no callback or guest commit, qword endpoint `AddressOverflow`, and backend load/store failures without state/RAM commit. A successful store whose callback raises STOP remains committed once.
- Bounded dispatch covers a budget split after the indexed singleton and continuation from its returned RIP through the existing pair without replaying the first memory access. Unsupported SIB neighbors and partial instruction windows are checked before effects/publication.
