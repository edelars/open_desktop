# S3-20o — address32 direct-base qword MOV in shared IR and dispatch

## Scope

The shared checked-memory singleton profile adds only exact four-byte
`67 48 8B/89 /r` with ModRM `mod=00`, data/base RAX..RBX, qword operand size,
and dword address size. It is a separate byte/descriptor branch from the
four-byte 64-bit-address SIB and direct disp8 forms. SIB, displacement,
extended registers, reordered/extra prefixes and trailing bytes remain
rejected. The decoder-provided `MemoryOperand` and existing
`access_address_48` remain the only effective-address semantics; no new emitter
or address arithmetic was added. Pair profiles and the private synchronous
RAM contract are unchanged.

## Evidence

- `od-jit` descriptor tests compare shared IR with direct V2 for both MOV
  directions across all 16 data/base register pairs. They assert qword data,
  dword EA, zero displacement, no index, scale 1 and exact source/next-RIP
  metadata. Truncation, ModRM register mode, SIB, disp8/disp32, REX extension,
  wrong prefix order and trailing bytes are rejected.
- Native shared IR, direct V2 and interpreter are compared for both
  operations and every data/base pair. This covers destination/base and
  source/base aliasing and full qword data. A noncanonical full-u64 base value
  is truncated according to the decoder's dword EA; the `0xffff_fffc` case
  accesses the contiguous qword through `0x1_0000_0003` in one callback.
- Load and store architectural fault cases preserve full CPU/RAM state and
  budget/retirement with exact #PF payload. Backend store failure remains a
  host error without commit. Budget, stop-RIP and STOP guards skip access. A
  successful store callback raises STOP after commit; bytes, next RIP and
  retirement remain committed.
- Bounded dispatch composes address32 singleton → bare NOP interpreter fallback
  → existing pair at budgets 0..4, stops after the singleton before NOP, then
  resumes from actual RIP without repeating the first callback. Partial source
  windows before the ModRM byte return `BoundaryReached` without retirement or
  data access.
