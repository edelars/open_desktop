# Stage 3 S3-20cd: address32 RBP-base SIB with no index and displacement

## Scope and implementation

Added only singleton `67 48 8B/89 /r sib disp8|disp32`: ModRM `mod=01/10,r/m=100`, SIB exactly `0x25` (scale one, no index, RBP base), data RAX..RBP, Dword effective address/Qword transfer, exact lengths 6/9. The existing `mod=00` form with the same SIB remains the separate absolute/no-base S3-20av profile. Decoder-owned `MemoryOperand::access_address_48` remains the only EA implementation: `(low32(old RBP)+signed displacement) mod 2^32`. RBP data uses its pre-instruction value for addressing and store payload; successful loads commit the full qword after the memory read.

The exact source, typed IR, runtime metadata, and dispatcher admission are scoped to this profile. Generic index admission, pair/V3 profiles, Stage 2/ISA, and owner/MMU integration were not changed.

## Evidence

The JIT descriptor test covers load/store × six data registers × signed disp8/disp32 boundaries; checks decoded operand and next-RIP metadata against direct V2/shared IR, independently computes low32(RBP)+signed displacement, compares an equivalent address32 direct-base encoding, and rejects invalid neighboring shapes. Every partial window before the 6- or 9-byte instruction is rejected.

The host test compares direct V2 and shared IR native execution against the interpreter using independent CPU/RAM fixtures. It checks full CPU and RAM state, exact callback address/width/count, payload and retirement; includes qword access across 4 GiB as one contiguous callback, final disp32-byte target identity, architectural and backend failures without commit, entry STOP and zero-budget guards, successful store+STOP, dispatcher continuation from actual RIP through both instruction lengths without replay, and unsupported-neighbor/partial-window no-effect behavior.
