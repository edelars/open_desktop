# Stage 3 S3-20br: address32 indexed SIB with low base and RSI/RDI index

## Implemented profile

Added the exact singleton `67 48 8B/89 /r sib [disp8|disp32]` profile: ModRM `mod=00/01/10,r/m=100`, SIB base RAX..RBX, index RSI or RDI, scale 1/2/4/8, data RAX..RBP, and instruction lengths 5/6/9. Address calculation remains decoder-owned through `MemoryOperand::access_address_48`: `(low32(old_base)+low32(old_index)*scale+signed displacement) mod 2^32`, then zero-extension. Data and memory transfer remain full qwords. RSI/RDI are index-only in this profile and preserve their full register values. A load whose data register aliases the base uses the pre-instruction base for the address and commits only after a successful read.

The exact admission was added to the checked block builder, direct V2 and shared IR validators, host publication metadata and borrowed dispatcher. Generic register whitelists were not widened. No pair/V3 form, extra prefix, stack/no-base base, other index, Stage 2/ISA, or production owner/MMU integration was added.

## Evidence

- JIT descriptor test covers both opcodes, four low bases, RSI/RDI, four scales, all six data registers, and no-displacement/disp8/disp32 boundary encodings. It checks source/site fields and rejects malformed fields, unsupported neighboring forms, and partial source windows.
- Host direct V2/shared IR/interpreter parity checks full CPU and RAM state, exact memory callback address/width/count, retirement, data=base pre-state behavior, and preservation of full RSI/RDI values. The oracle independently truncates the old base/index to 32 bits and performs wrapping scale/add/displacement arithmetic.
- Focused cases cover scale/product and address wrap, a qword callback crossing 4 GiB, and two immutable disp32 sources whose ninth byte changes the target. Host architectural faults preserve their exact guest payload and retire zero instructions; Unmapped/backend helper errors remain host errors. Load and store cases both assert unchanged state/RAM and precise callback address/count. Successful store+STOP remains committed once.
- Entry STOP, stop-RIP and zero-budget avoid callbacks. Partial windows 1..8 return the fixture boundary result without publication/effects. The borrowed dispatcher resumes at actual RIP across 5/6/9-byte forms without repeating the first read, then runs the NOP fallback and existing pair.
