# Stage 3 S3-20bf: address64 indexed no-base SIB with RBP index

## Scope

Added one exact singleton profile: `48 8B/89 /r sib disp32`, ModRM `mod=00/rm=100`, SIB base field `101` (no base), index RBP, scale 1/2/4/8, data RAX..RBP, qword address/data, exact length eight. The decoded `MemoryOperand` and `access_address_48` remain the only effective-address semantics. The address is `RBP*scale + signed disp32` modulo 2^64; no base or RIP value contributes. Address32 no-base/RBP-index, mod01/10, extra prefixes, pairs, V3, owner/MMU integration, Stage 2, Mini, and performance work remain out of scope.

## Evidence

- JIT descriptor tests cover load/store, all six data registers, four scales, signed disp32 boundaries, decoded metadata and direct/shared-IR admission. A complete address32 no-base/RBP-index neighbor remains rejected.
- Host parity covers direct V2, shared IR and interpreter full state/RAM, callback address/count and retirement for both directions × six data registers × four scales × five signed displacement edges. The target is independently computed as wrapping `RBP*scale + signed disp32`; data=RBP uses the pre-instruction value.
- Two immutable eight-byte sources differing only in byte eight produce independently asserted callback targets `0x101` and `0x0100_0101`.
- A noncanonical no-base start and a qword crossing the canonical boundary fault #GP without callback; a separate canonical start whose qword range crosses `u64::MAX` remains `AddressOverflow` without callback. Backend read/write failures retain host-error classification, exact attempted target/width/count, and no CPU/RAM commit. Exact-profile store+STOP commits and retires once.
- Bounded dispatch executes the no-base/RBP-index load, stops at budget one at its actual next RIP, then executes the existing two-instruction pair without replay. Partial byte windows 1..7 return `BoundaryReached` without effects.
- Full JIT validation initially exposed stale negative fixtures that now described the admitted RBP-index no-base form. Those negatives were changed to unsupported RSI-index forms; address32 negatives were retained.
