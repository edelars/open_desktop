# S3-20f — bounded address-size override MOV sites

**Date:** 2026-10-27. **Status:** local implementation complete; independent review pending. Mac mini testing remains deferred to the final S3-21 gate.

## Scope

The V2 compiler admits a separate exact profile: `67 48 8B/89 /r`, ModRM `mod=00`, data/base register fields RAX..RBX, qword data width, dword address size, register base, no index, scale 1, zero displacement, and exactly four instruction bytes. The source bytes are bound to the decoded `MemoryOperand`; `next_rip` is decoder-derived and equals entry RIP plus four. The compiler/emitter does not mask addresses or zero-extend registers. Runtime uses the existing `MemoryOperand::access_address_48` semantics. No `od-isa` files were changed.

## Local evidence

- Compiler tests cover all 16 data/base pairs for both load and store and validate exact bytes, lengths, decoded widths/base, no-index, scale, displacement, and next RIP.
- Negative admission tests cover truncation, trailing bytes, extra/reordered prefixes, extended registers, ModRM mod01/mod10/mod11, SIB, and base-less disp32 for both operations.
- Native/interpreter differential tests cover all 16 data/base pairs per direction (32 cases), full qword values, base registers with nonzero high 32 bits, and `MOV RAX,[EAX]` where destination aliases the old base. Full CPU state and RAM are compared on independent copies; stores are checked against exact little-endian bytes and one committed write.
- A sparse-memory differential case maps byte `0xffffffff` and the next seven bytes at `0x100000000..=0x100000006`, while low addresses `0..=6` hold distinct sentinels. Load succeeds with the eight high-address bytes as one qword; store writes its exact qword across the same boundary. Native/interpreter state and sparse RAM snapshots match, and all low sentinels remain unchanged. This demonstrates that address-size truncation applies to the starting effective address only; subsequent qword byte addresses advance linearly without 32-bit wrap. The code snapshot is separate from the private data backing.
- A separate unmapped qword case fails at start address `0xffffffff` and preserves CPU state/RAM. It checks fault atomicity only; the successful sparse case is the evidence for non-wrapping operand bytes.

## Checks and limits

Final local checks passed: targeted compiler admission and host differential cases; `cargo test -p od-jit --offline` (111 tests); `cargo test -p od-host --offline` (42 tests); `cargo check --workspace --all-targets --offline`; `cargo fmt --all -- --check`; `git diff --check`; and `graphify update .`. Changed paths are limited to `crates/od-jit/src/runtime.rs`, `crates/od-jit/src/memory_load_v2.rs`, `crates/od-host/src/lib.rs`, and Stage 3 docs/report; no Stage 2 paths were edited. No physical Mac mini test was run. The local ARM64 result does not close S3-21.

Unsupported: other prefixes/orderings, address-size override with SIB/displacement or ModRM modes other than mod00, registers outside RAX..RBX, and any generalized 32-bit effective-address lowering. Independent reviewer status: pending.
