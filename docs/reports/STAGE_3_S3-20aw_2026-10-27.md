# Stage 3 S3-20aw report

## Scope and implementation

Added one bounded qword singleton profile: `48 8B/89 /r sib disp32`, with ModRM `mod=00,r/m=100`, SIB base field `101` (no base), index RAX..RBX, scale 1/2/4/8, and data RAX..RBP. The exact instruction length is eight bytes. The new profile is distinct from the existing no-base/no-index absolute SIB form `SIB=0x25`; no prefix, pair, V3, owner/MMU, or Stage 2 behavior was added.

Compiler admission, IR descriptor validation, host publication validation, runtime metadata validation, and the bounded dispatcher recognize the same profile. Effective-address semantics continue to come from the decoded `MemoryOperand` and `access_address_48`; runtime matching binds the fixed opcode/ModRM/SIB shape to immutable decoder-built metadata and does not independently decode displacement bytes.

## Evidence

- JIT descriptor test covers both load/store directions, six data registers, four low index registers, scales 1/2/4/8, and signed disp32 MIN/-1/0/1/MAX. It checks exact metadata and rejects unsupported index/base/prefix shapes and partial byte windows 1..7.
- Host matrix compares direct V2, shared IR, and interpreter for full CPU/RAM state, callback address/count, and retired instructions. It checks an independent wrapping-u64 target formula, data=index pre-state behavior, eighth-byte displacement identity, canonicality, guest/backend faults and no commit, AddressOverflow diagnostics, and successful store+STOP.
- A dedicated wrap case verifies `index*scale + signed displacement` wraps in 64-bit address arithmetic. The no-base/no-index `SIB=0x25` regression remains covered.
- Bounded dispatch runs the new singleton before NOP and the existing pair; budgets 0..4 and split continuation resume at the actual RIP without replay. Partial windows and unsupported SIB neighbors return the expected boundary/unsupported outcomes without publication or data effects.
- Legacy negative fixtures in earlier profile tests used `SIB=0x05/0x0d`, which are valid new low-index no-base forms. They now use `SIB=0x2d` (unsupported RBP index), preserving their negative intent.
