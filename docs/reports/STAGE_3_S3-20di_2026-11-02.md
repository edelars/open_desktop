# S3-20di — exact address64 SIB dword stores with signed disp8

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `18bfbf6` adds exactly four four-byte singleton forms:
`89 44 0B ib`, `89 44 4B ib`, `89 44 8B ib`, and `89 44 CB ib`
(`MOV [RBX+RCX*1/2/4/8+disp8],EAX`). The effective address uses full-width
RBX and RCX, the encoded SIB scale, and signed disp8 through the decoder-owned
address48 path. Each store writes low32 RAX with one contiguous checked
four-byte access; the guest instruction boundary is `A+4`.

Recorded fixtures bind every source byte to its exact site across all four
scales and all 256 disp8 values. They cover the `A+4` PC-map boundary, atomic
fault behavior, STOP, and budget handling. The host fixture distinguishes a
four-byte noncanonical-end crossing (`#GP`) from u64 range overflow
(`AddressOverflow { address, length: 4 }`); both produce no write callback,
guest-state commit, or retirement. It also confirms a valid adjacent write
ending at the canonical boundary succeeds. Other SIB shapes, wider blocks,
production owner/MMU integration, and performance conclusions are outside
this slice.
