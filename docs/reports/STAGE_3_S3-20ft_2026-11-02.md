# S3-20ft: RCX-base Dword load signed disp32 `8B 81 id`

## Implemented scope and semantics

This slice admits only the six-byte form `8B 81 id`:
`MOV EAX,[RCX+disp32]`, with a Dword operand, Qword address size, RCX base,
no index, and no prefix or SIB. The displacement is a signed little-endian
`i32`, sign-extended into site metadata. The effective address is computed
from the full original RCX as `original_RCX.wrapping_add_signed(displacement)`
modulo 2⁶⁴.

Execution uses one contiguous checked four-byte read. The result
zero-extends into RAX; RCX, other GPRs, RFLAGS, and RAM remain unchanged; the
successful next RIP is `A+6`. Canonicality and range preflight apply to the
computed EA and full read range. Existing guest/backend faults, entry guards,
retry, and callback STOP without replay remain in scope. Address32 forms,
other bases or destinations, prefixes, and SIB are excluded.

## Identities and acceptance coverage

Rust test identities:

- JIT: `memory_load_v2::tests::ir_dword_rcx_disp32_load_binds_all_source_bytes_to_its_site`
- Host: `tests::s3_20ft_rcx_disp32_dword_load_uses_full_rcx_and_signed_displacement`

Harness identities:

- `s3_34de_ir_rcx_disp32_dword_load_source_binding`
- `s3_34de_host_rcx_disp32_dword_load_full_rcx_and_signed_displacement`
- Fail-closed self-test: `test_s3_34de_rcx_disp32_dword_load_gates_are_pinned_and_fail_closed`

The JIT fixture binds each of the four displacement bytes to
its source/site, checks signed metadata and the `A+6` PC-map boundary, and rejects
forged fields. The host fixture distinguishes full RCX from a
low32 decoy; covers signed displacement and 64-bit wrap; exercises zero and
unaligned EAs, canonical upper-half and maximum valid ranges; and verifies
noncanonical/range failures before the read callback. Guest/backend faults
and each entry guard have successful retries; callback STOP does not replay
the read. Fetch errors for any displacement byte must propagate without a
fallback value.

Three existing JIT compile-negative fixtures that use the new byte form became
successful compilation plus bidirectional source/site
mismatch checks: `8B 81 00000000` in the RCX singleton fixture,
`8B 81 80000000` in the RCX disp8 fixture (disp32 value +128), and
`8B 81 00000000` in the RAX disp32 fixture. Other malformed and unsupported
forms remain rejected.

The previous harness baseline was 286 Rust gates (276 acceptance and 10
lifecycle), 304 local steps, and 127 self-test names. Actual totals after this
slice are 288 gates (278 acceptance and 10 lifecycle), 306 steps, and 128
self-test names; identities and argv were verified against the integrated
harness. The JIT neighbor fixture was corrected to use the exact supported
form `[8B,01]`.

integrated and passed independent Sol/high review. The focused S3-20ft Rust
