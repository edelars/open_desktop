# S3-20fn: exact address32 RAX-alias Dword load with signed disp32

## Scope and semantics

This runtime slice admits only the seven-byte form `67 8B 80 id`
(`MOV EAX,[EAX+disp32]`). The displacement is decoded as signed little-endian
`i32` and retained sign-extended in metadata. The effective address uses the
original low32 RAX before EAX writeback:
`zero_extend((low32(RAX) + signed_disp32) mod 2^32)`. The operation is one
contiguous checked four-byte read. The loaded value zero-extends to full RAX;
other GPRs, RFLAGS, and RAM remain unchanged; successful retirement advances
RIP to `A+7`. Only the starting address wraps modulo 2^32. A transfer that
crosses 4 GiB continues contiguously above that boundary.

## Implementation and coverage

Runtime commit `d2eb210` adds the exact source/metadata, `CheckedDwordLoad`
byte gate, decoded/IR/runtime profile, and source/site binding. It changes four
stale compile-negative fixtures to verify successful compilation with a
distinct source/site mismatch: the singleton alias form, the disp8 alias form,
the RSP SIB disp32 form, and the addr64 RAX disp32 form. The neighboring
unsupported forms remain outside this admission.

JIT identity:
`memory_load_v2::tests::ir_dword_addr32_alias_disp32_load_binds_all_source_bytes_to_its_site`.
Host identity:
`tests::s3_20fn_addr32_alias_disp32_dword_load_uses_wrapped_original_eax`.
The JIT fixture covers signed displacement representatives and binds each
disp32 source byte to its site; the host fixture covers original-EAX address
wrapping, full-RAX preservation, contiguous reads across 4 GiB, guard/fault
retry, and callback STOP without replay.

Harness commits `632e83f` and `c46a00a` add exact gates
`s3_34cy_ir_addr32_alias_disp32_dword_load_source_binding` and
`s3_34cy_host_addr32_alias_disp32_dword_load_wrapped_original_eax`, plus the
fail-closed self-test
`test_s3_34cy_addr32_alias_disp32_dword_load_gates_are_pinned_and_fail_closed`.
The self-test list has 276 Rust gates (266 acceptance and 10 lifecycle), 294
local steps, and 122 names. Independent Sol/high review of the harness passed,
including confirmation of both Rust test identities, argv, and counts.
