# S3-20ao report: address32 no-index SIB stack-data MOV

## Scope and implementation

Added one bounded singleton profile for `67 48 8B/89 /r 24 [disp8|disp32]`.
The accepted ModRM modes are 00, 01, and 10 with `r/m=100`; the SIB byte is
exactly `0x24`, so the old guest RSP is the only base and there is no index.
Data registers are RAX through RBP. Instruction lengths are 5, 6, and 9 bytes;
the effective-address size is Dword and the transferred value remains Qword.
Other SIB values, extra prefixes, pair forms, and V3 remain outside this
profile.

The existing decoder `MemoryOperand` and `access_address_48` continue to
provide address semantics. The implementation adds the exact SIB case to
bounded source admission, V2 metadata, shared IR validation, and dispatch
compile-at matching. It does not add another effective-address calculation.

## Evidence

`address32_rsp_sib_base_has_exact_qword_profile_for_all_data_registers`
checks load/store across all six data registers, all three ModRM modes, and
signed displacement boundaries. It compares direct V2 and shared IR sites and
retains exact source bytes. Forbidden no-base/index/scale/prefix variants and
truncated encodings are rejected.

`address32_rsp_sib_base_data_matrix_and_dispatch_continuation` compares direct
V2, shared IR, and interpreter results for 108 operation/register/displacement
combinations. It checks full state and RAM parity, exact callback address and
count, single retirement, signed low-32-bit wrap, and full 64-bit data. A
qword access at `0xffff_fffc` reaches through `0x1_0000_0003` in one callback.
With RSP in the data field, the target comes from old RSP low bits while a
successful load commits the full loaded qword. A store preserves all 64 bits
of old RSP as its payload.

The same host test dispatches the singleton, the explicit interpreter NOP,
and the existing native pair. Budget exhaustion returns at the singleton's
actual next RIP; continuation does not repeat its access. Entry budget zero
and pre-entry STOP perform no access. A successful stack-data store commits
once before callback STOP. Fixture byte windows 1 through 8 stop before
publication, retirement, or memory access.

Backend failures on both exact load and store forms preserve guest state and
RAM commit state. A loaded noncanonical full RSP value commits after the
address32 access; the subsequent 64-bit `[RSP]` use raises #SS after the first
retirement and without a second backend callback.
