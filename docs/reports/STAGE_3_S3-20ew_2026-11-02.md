# S3-20ew: exact addr32 scaled RCX-indexed no-base SIB disp32 Dword stores

## Scope and semantics

This runtime slice admits only the exact eight-byte Dword-store singletons
with exactly the `67` address-size override prefix and no other prefixes:
`67 89 04 4D disp32`, `67 89 04 8D disp32`, and
`67 89 04 CD disp32` (`MOV [ECX*2|4|8+disp32],EAX`). The address-size-32
SIB has no base and uses ECX as its index at scale 2, 4, or 8. The effective
address is `zero_extend((low32(RCX)*scale + signed disp32) mod 2^32)`. Each
checked write is one contiguous four-byte access storing low32 RAX, including
the recorded crossing of the 4-GiB boundary. GPRs and RFLAGS are preserved,
and the guest instruction boundary is `A+8`. Other prefixes, scales, SIB
shapes, and encodings remain outside this exact admission.

The exact JIT fixture is
`memory_load_v2::tests::ir_dword_addr32_rcx_index_no_base_sib_scaled_disp32_store_binds_all_source_bytes_to_its_site`.
The exact host fixture is
`tests::s3_20ew_addr32_rcx_index_no_base_sib_disp32_dword_store_uses_wrapped_scaled_ecx`.
Harness S3-34ch pins both identities.
