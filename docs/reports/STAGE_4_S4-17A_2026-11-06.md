# S4-17a: paged qword load differential

**Status:** accepted after independent code and documentation review. Parent
S4-17 and Stage 4 remain open.

## Scope

One exact Long64/CPL0 `48 8B 03` (`MOV RAX,[RBX]`) case through the uncached
interpreter and the published V2 JIT memory-load path. Each backend receives a
fresh `MachineBus` built from the same deterministic case descriptor. The
scenario has a successful nonidentity RAM load and a second run with an absent
data leaf PTE that raises a genuine #PF.
The integration target is compiled only on Apple Silicon macOS, where
`PublishedCode` supports executable-memory publication.

The code and data use separate PML4 branches. Code-path Accessed bits are set
before either run so the interpreter's code fetch does not add A-bit writes
that the JIT path, which executes an already-published artifact, cannot
observe. The data PDE starts with A=0; the success case observes PDE/PTE A
updates, while the missing-PTE case observes the committed PDE A update before
the fault.

## Normalized result and comparison

Added `od_testkit::memory_fault` schema v1 for all 16 GPRs, RIP, RFLAGS and its
definedness mask, retired count, completion/page-fault outcome, intended CR2
value, architectural CR2 availability, changed physical RAM ranges, ordered
committed-write ranges, and device-event availability. It validates required
observations and compares the same case ID and input digest. Undefined RFLAGS
bits are masked only by the shared explicit definedness mask.

The page-walk API returns a `PageFaultRecord::cr2_value()` but does not commit
architectural CR2. The normalized result records the intended fault address in
the #PF outcome and marks actual architectural CR2 unavailable. The bus has
only a RAM region in this case, so device events are explicitly observed as an
empty list.

The test injects a result-only reporting mismatch by clearing the data PDE A
bit in a clone of one completed normalized result. The comparator identifies
the exact physical qword and differing bit. Testkit unit tests also cover
masked-out and defined RFLAGS differences, missing required observations,
strict JSON round-trip, and explicitly unsupported cached-interpreter status.
The existing pure translation-probe cache is not a cached instruction
interpreter and is not presented as one.

## Limitations

This local differential compares two paths that share the page walker; literal
PFEC, CR2 value, destination/RIP/retirement and A-bit assertions are retained
so pairwise equality is not the sole oracle. It is not hardware evidence.
Cached interpreter execution, mismatch reduction, other memory instructions,
stores, MMIO/device effects, cross-page accesses, fetch faults, remapping, and
exception delivery remain outside S4-17a. Hardware evidence remains separate in
S4-34. No performance claim is made.
