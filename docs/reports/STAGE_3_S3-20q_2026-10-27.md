# S3-20q — 64-bit SIB displacement in shared IR and bounded dispatch

## Scope

The shared checked-memory singleton now admits only exact
`48 8B/89 /r sib disp8|disp32` encodings: ModRM `mod=01/10,r/m=100`,
RAX..RBX data/base/index registers, SIB scale 1/2/4/8, qword data and 64-bit
address size, exact lengths five/eight. SIB index 4 and the mod00 base-5
no-base special are excluded; base 5 in mod01/mod10 denotes RBP and is rejected
by the RAX..RBX limit. Extended registers, `67`, extra prefixes, and unreviewed
forms remain outside the profile. The compiler and host bind exact source bytes to decoder-derived
metadata; the decoder's `MemoryOperand` and `access_address_48` remain the only
effective-address and access-range semantics. No emitter, decoder, pair
profile, Stage2, or production owner changes were made.

## Evidence

- `od-jit` descriptor checks cover both MOV directions, all four SIB scales,
  all allowed disp8/disp32 boundary values, and combinations with data/base,
  data/index, and base/index aliases. They reject invalid ModRM/SIB fields,
  truncation, extra bytes, wrong prefixes, and extended registers.
- Native direct V2, shared IR, and interpreter are compared for both
  operations across scales and signed boundary cases. The host RAM logs
  callback address and width, proving one eight-byte callback at the decoded
  target. Arithmetic wraps into canonical memory; separate cases verify
  noncanonical starts and qword end ranges fault before any memory callback.
- Injected architectural faults preserve the exact payload and CPU/RAM/budget/
  retirement across direct V2, shared IR, and interpreter. Backend errors
  remain host errors. A successful SIB store followed by STOP keeps its
  committed bytes and retirement.
- Bounded dispatch composes a SIB disp8 singleton → bare NOP fallback →
  existing pair across budgets 0..4. STOP after the SIB load returns at its
  actual RIP; clearing STOP resumes without repeating the access. Partial
  disp8/disp32 windows and invalid no-index SIB return without publication or
  data callbacks.
