# S3-29d: arithmetic-to-checked-load handoff

**Status:** bounded uncached integration evidence passed on macOS ARM64.
Eager flags remain the default; S3-29 remains open. This fixture does not add a
production owner path or make a performance claim.

## Scope

The host test composes existing eager and demand-flags native compilation,
`run_controlled`, `PublishedMemoryBlockExecutor`, and the existing checked-load
V2 helper over one immutable source view. Its exact instruction sequences are
one or two W64 register arithmetic operations (`48 03 C3`, `48 2B C3`, or
`48 3B C3`),
`48 8B 03` (`MOV RAX,[RBX]`), JZ or JNZ, and a native `ADD RAX,RBX` on the
fallthrough path. A shared remaining budget carries work across the native
prefix, checked helper, and native suffix. Candidate entry rechecks STOP-RIP,
STOP, budget, and event immediately before artifact entry; the memory mapping
is dropped before suffix compilation/execution.

The test is intentionally fixture-scoped. It does not broaden the general
S0-09 builder/admission or shared cache and does not add a reusable public
dispatcher, Stage 2, owner/MMU, raw ABI, or ISA form.

## Evidence

- Candidate and eager native execution match the interpreter's complete CPU
  state and RAM for ADD/SUB/CMP with JZ/JNZ, each taken and fallthrough, plus
  two-writer ADD→SUB and ADD→CMP prefixes.
- The candidate PC map has pending-flags ranges before handoff. Immediately
  before the V2 helper, the candidate state matches interpretation of the
  arithmetic prefix, including canonical RFLAGS.
- The successful qword load invokes one callback and retires once. Native,
  checked-helper, and interpreter counts are asserted separately.
- #PF and noncanonical #GP preserve the completed prefix and exact load RIP,
  do not commit RAX, and do not enter the suffix. Noncanonical #GP is raised
  before a data callback. A host backend error remains an executor error.
- After repairing guest memory or the host callback, retry executes the load
  and suffix without replaying the arithmetic prefix. Fault/retry injection is
  covered on the demand-flags candidate path; eager/interpreter fault parity
  remains outside this slice.
- An event set by a successful memory callback yields after committing the
  load and before entering the native suffix. A simultaneous #PF and event
  returns the guest fault. STOP-RIP, STOP, exhausted budget, and event priority
  are checked at the memory handoff; a shared budget can stop at the suffix and
  resume there.
- The fixture boundary decoder rejects a branch target inside the three-byte
  load. The candidate compiler rejects neighboring `48 01 D8` rather than
  broadening its accepted S0-09 profile.
- Native report budget conservation, retirement bounds, and zero-progress
  continuation are asserted in the fixture coordinator. This fixture does not
  inject malformed native reports; existing `od-jit::memory_dispatch` contract
  tests continue to cover invalid executor accounting and zero-progress reports
  for the checked-memory dispatcher.
