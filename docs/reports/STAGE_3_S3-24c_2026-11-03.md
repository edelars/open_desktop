# S3-24c — exact V3 tail immediate across adjacent mappings

## Scope and outcome

Extends only the existing fixture admission for the exact 23-byte V3 program
`MOV RDX,imm64; MOV [RBX],RAX; MOV RCX,imm64`. Its committed qword store may
replace the complete eight-byte immediate at artifact offsets `[15,23)` when
the destination resolves to either one segment or two adjacent guest mappings
of the same backing with contiguous backing offsets. The split plan must cover
the complete immediate with contiguous source offsets; opcode bytes, shifted
or partial qwords, and more than two segments remain rejected.

The complete artifact source lease remains in one mapping and is still checked
before entry; the split is exercised through a destination alias. The fixture
marks the admitted store dirty before commit. After a split write succeeds, the
V3 entry exits with `CodeInvalidated` before executing the old tail, commits one
write and one backing version increment, and sends one backing notification.
The test prewarms the old tail, confirms invalidation drops that cached entry,
then fresh dispatch executes the new immediate without replaying the store.
STOP raised by the successful write does not suppress the dirty exit.

This is a fixture-owner extension of S3-24b using the existing S3-23f
write-plan semantics. It does not add production MMU ownership, general active
SMC, a physical-x86 oracle, or complete S3-24/25 behavior.

## Validation

- Exact gate:
  `cargo test -p od-host --lib active_code_v3_invalidates_exact_not_yet_executed_tail_immediate --offline`
  passed 1/1 on the local macOS ARM64 host.
- `cargo fmt -p od-host -- --check` remains blocked by extensive pre-existing
  formatting differences throughout the crate; no mass formatting was applied.
- Noncontiguous backing offsets and a split crossing into another backing were
  rejected before mutation or notification.
- Mini, M1, Stage 2, full `od-host`, and the full Stage 3 harness were not run.
- Independent `gpt-6.1-sol/high` review passed with no findings; the reviewer
  did not edit files or run tests.
