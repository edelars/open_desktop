# S3-20ch: Address64 qword load into RSI/RDI

**Статус:** реализация и локальные проверки завершены; независимое ревью `gpt-6.1-sol/high` выдало signoff без оставшихся замечаний. Mini/performance отложены до конца Stage 3; owner-backed `od-machine` и Stage 2 не входят в срез.

## Реализовано

- Прямой qword load принимает ровно восемь singleton-кодировок `48 8B /r`, ModRM `mod=00`, destination RSI/RDI (`reg=6|7`), base RAX/RCX/RDX/RBX (`r/m=0..3`), длина 3. Addr32, displacement, SIB, дополнительные prefixes/REX, R8+ и другие widths отклоняются.
- Shared block admission, direct V2 metadata/source matching, shared-IR lowering/emission и MemorySite V2 согласованы по одному профилю. RSI/RDI `WriteGpr` допускается только непосредственно после `CheckedLoad` с тем же temporary и точным qword low-base direct operand длины 3. `ReadGpr` и общий `validate_gpr` не расширялись; непроверенная или несмежная запись в RSI/RDI отвергается.
- Staged frame согласован во всех runtime emitter/compiler путях: staged GPR offsets `[56,120)`, flags `120`, RIP `128`, X19/X20 `144`, X21/X22 `160`, reserved prefix `176`, frame aligned to 16. Setup и commit копируют восемь GPR. Spill homes остаются после reserved prefix. `MAX_EMITTED_BLOCK_BYTES` оставлен равным 4096.
- Host direct V2 и shared IR сравниваются с interpreter для всех восьми форм с high-bit qword, полным состоянием CPU/flags и RAM, одним qword read и одной retirement. Для обоих destination и обоих execution paths fault и budget-zero не меняют state; budget-zero не вызывает read. Сохранены отрицательные checks для invalid encodings и произвольных RSI/RDI read/write.
- Добавлена явная layout regression для всех frame offsets и проверка spill offsets после 176; старые host runtime fixtures переведены на новый обязательный prefix. Предыдущие arithmetic/store/two-memory проверки сохранены.
- Проверена регрессия размера runtime-блока на 10 последовательных `MOV RAX,imm64`: baseline `911263f` выдавал 3884 bytes, первая версия 8-GPR frame — 4148 bytes и правильно отвергал блок по cap 4096. В `emit_commit` hoisted один стабильный canonical-state pointer load из каждого GPR-loop; итоговый размер fixture — 3868 bytes, блок снова компилируется, cap остался 4096. Это устраняет лишний код без изменения guest semantics; выводов о скорости нет.

## Проверки

- `cargo fmt --all -- --check`: passed.
- `cargo test -p od-jit --offline`: 207 passed, включая 10-MOV code-size regression.
- `cargo test -p od-host --offline`: 84 unit tests passed; memory corpus: 12 passed, 2 ignored.
- Focused host S3-20ch matrix: direct V2/shared IR/interpreter parity прошла для 8 кодировок; последующий targeted rerun также прошёл.
- `cargo check --workspace --all-targets --offline`: passed.
- `cargo check --workspace --all-targets --offline --target x86_64-unknown-linux-gnu`: passed; предупреждения dead-code/unreachable остаются в platform-specific od-host/runner/bench code.
- `graphify update .`: прошёл и обновил граф; сообщил о существующей неполной AST-экстракции `include/open_desktop/host_abi.h` и файлах без извлекаемых символов.
- `git diff --check`: passed.
- `python3 tools/check_layout.py`: failed из-за unmapped корневого `.git` и двух отсутствующих Stage 1/2 manifests, на которые ссылается параллельный `STAGE_2_REPORT.md`. Ссылки на S3-20ch report добавлены и файл уже создан. Артефакты Stage 2 не изменялись.
- Mac mini execution и performance measurements не запускались по просьбе отложить их до конца Stage 3.

## Ревью и границы

Повторное независимое ревью проверило size fix: X16 остаётся стабильным между LDR/STR в commit loop, 10-MOV блок занимает 3868 bytes при прежнем cap 4096, scoped IR и frame layout согласованы; замечаний не осталось. Доказательства относятся к локальному borrowed-memory host fixture и не заявляют production owner/MMU integration, завершение Stage 2, физический x86 oracle, Mini или performance.
