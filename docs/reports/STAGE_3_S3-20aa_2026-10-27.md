# S3-20aa — guest RBP as qword MOV data register

## Scope

Admit only singleton `48 8B/89 /r`, ModRM `mod=00`, data register RBP
(`reg=5`), direct base RAX..RBX (`r/m=0..3`), qword data and 64-bit EA,
exactly three bytes. No SIB, displacement, prefix, other base, pair or V3
extension is admitted. Generic GPR validation remains narrow; checked memory
load/store lowering carries the sole RBP-data exception. `MemoryOperand` and
`access_address_48` remain the effective-address authority.

Both direct V2 and shared-IR runtime use the existing canonical state field and
checked helper. RBP load commits only after a successful read. Store payload
`0x0000_8000_0000_0000` is intentionally noncanonical and its exact eight bytes
are asserted in RAM; canonicality is checked for the memory address, not data.

## Private frame layout

To avoid register-slot aliasing, the private emitter frame uniformly stages six
GPRs RAX..RBP at `SP+56..103`, flags at `SP+104`, RIP at `SP+112`, padding at
`SP+120..127`, and saves X19/X20 and X21/X22 at `SP+128` and `SP+144`. The
required prefix is 160 bytes and allocator spills start beyond it. The Runtime
Context and public C ABI remain unchanged. All six emitter prologue/epilogue
save/restore paths, runtime compiler prefix, checked-load/store prefixes and
host fixture allocations were scanned and updated.

## Evidence

- Descriptor checks both opcodes for all direct bases, decoded metadata, direct
  V2/shared-IR compile admission, and rejects SIB, displacement, address-size
  override and out-of-profile data register variants. An RBP-data pair sequence
  remains rejected.
- Direct V2, shared IR and interpreter compare full state/RAM, callback address
  and count, and exact one-instruction retirement for load/store. A fault leaves
  old RBP/RIP/budget/RAM untouched; the full-width noncanonical store payload
  commits intact.
- An x19 ABI canary runs RSP and RBP load artifacts repeatedly across normal,
  budget-guard and architectural-fault exits. Entry STOP and zero budget make no
  memory callback. A forced-spill emitter regression checks spill offset
  `>=160` and emits a one-instruction PC map.
- Dispatcher splits after the RBP load both at budget one and at callback STOP.
  Continuation executes `MOV RCX,[RBP+0]` from the actual RIP. Since the first
  load supplies a noncanonical RBP, the second instruction returns #SS while
  retaining the first state commit and does not repeat its read.
