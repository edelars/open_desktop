# S3-37e — native cached-memory fault/error lifecycle

**Status:** bounded local lifecycle acceptance completed. S3-37 and Stage 3 remain open.

## Result

The local Stage 3 harness now requires an exact native integration gate for
`capacity_one_memory_cache_republishes_after_fault_and_backend_error`. It
exercises the existing capacity-one `MemoryPairCache` and native published
memory backend; no production API or runtime behavior changed.

Before keeping a native mapping resident, the test creates uncached and
interpreter references. It then checks a cold publication and same-key hit
with distinct invocation-local CPU/RAM, STOP after the first committed store,
and an architectural fault at the second helper site. STOP and guest fault
retain the resident entry. Next, a dependency-version change under the same
profile and context generation replaces that resident entry without an
explicit clear. The `replacements` counter changes from 0 to 1 on this path,
and the replacement artifact is published and executed successfully. Clear,
profile switch, backend error, recovery publication and fresh-cache creation
do not increment the replacement count; a newly created cache starts at zero.

The second-site backend-error path checks the injected
`MemoryError::Backend("S3-37e second-site write failure")` from the fixture
before result normalization. The raw cached and uncached native results both
carry the typed `MEMORY_ERROR_BACKEND` payload with address and length zero.
The message is fixture-level evidence and is not claimed to cross the native
ABI. The suspect entry is removed after the error. Immediate successful
publication and execution proves the previous MAP_JIT mapping was released.
The test then drops that cache and publishes/executes through a fresh cache
using different invocation state.

Each dispatch compares full interpreter-visible state, RAM, flags, RIP,
retirement, callback order and memory accesses against the references. This is
a bounded lifecycle regression, not leak-free stress, concurrent arena/SMP
reclamation evidence, or completion of S3-37.
