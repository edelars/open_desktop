# S3-20cr — exact dword checked-memory load with disp8

**Status:** bounded implementation slice committed; S3-20 and Stage 3 remain
open.

Commit `11fbe79` adds exactly the three-byte singleton `8B 43 ib`
(`MOV EAX,[RBX+disp8]`) to the shared typed-IR dword-load path. The decoder's
memory operand supplies the signed disp8 effective address from the full-width
RBX value. A successful checked read transfers exactly four bytes and
zero-extends EAX into RAX. All 256 disp8 byte values have distinct source/site
identity, with the single committed guest boundary at `A+3`.

The fixture covers atomic no-commit behavior on read faults and the bounded
STOP/retirement path. Admission remains exact: this does not enable arbitrary
dword MOVs, other bases/addressing modes, qword forms, or a general dword
family.
