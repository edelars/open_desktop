# S3-34o: bounded NativeRegisterV1 value-only reducer

## Scope

This slice adds a standalone reducer for an existing saved `NativeRegisterV1`
v1 mismatch envelope. It changes no production JIT, ISA, admission, interpreter,
Stage 2, owner/MMU, or runtime behavior. The reducer does not generate a new
case from seed metadata. It loads the saved bytes and state from the exact path
provided by `OD_JIT_NATIVE_REGISTER_V1_REDUCE_CASE`.

The original is re-executed first. Reduction proceeds only if the saved
nonempty signature reproduces exactly and denotes a stable semantic mismatch:
all two-repeat interpreter/eager/candidate observations must exist and be
repeat-stable, with no errors or repeat-instability entries. Each candidate is
re-digested, revalidated against the exact profile/admission, and run twice
through all three backends. A candidate is accepted only if its complete
signature equals the original and its explicit value-complexity metric
strictly decreases.

The reducer changes only initial GPR values, arithmetic flags and DF
(`RFLAGS & 0x0cd5`, leaving other and mandatory bits unchanged), and existing
immediate/displacement value bytes in decoded `ADD/CMP/SUB RAX,imm8`,
`MOV RAX,imm32`, `LEA RAX,[RBX+disp8]`, and `LEA RAX,[RIP+disp32]` encodings.
It never changes guest base/entry RIP, auxiliary state, STOP/budget, opcodes,
instruction ordering/lengths, or branch displacement/targets. Instructions are
not deleted and no relocation is performed. The metric is the sum of
population counts of initial GPRs, mutable arithmetic flags/DF, and eligible
encoded values. Candidate order is fixed and exact canonical input bytes are
deduplicated. At most 256 candidates are evaluated. `evaluation_limit` means
the bounded search stopped; it does not imply global minimality.

## Artifacts and self-checks

The harness run directory retains a create-only copy of the source envelope,
the complete report with source/candidate backend observations for both
repeats, source and reduced signatures, counts, before/after metric, stop reason,
and replay commands. A reduced saved case and separate input digest are only
written after at least one accepted candidate. When the ordinary corpus sample
has no saved mismatch, the exact reducer gate records `not_reproduced` with no
reduced envelope.

The positive mechanics check uses a fixed local exact-profile fixture and a
deliberately injected observation mismatch. Its source and artifacts are
explicitly labelled `LOCAL-FAULT-INJECTION SELF-CHECK ONLY`; it is neither
ordinary replay evidence nor evidence of a JIT defect. The check replays the
reduced input through the same injected predicate and verifies signature
preservation. A separate injected run exercises the evaluation-limit stop.
Negative coverage includes malformed digest/profile, source non-reproduction,
source repeat instability/errors/missing results, changed semantic signature,
candidate backend error/timeout, and branch-displacement mutation.

Two exact local acceptance gates extend the manifest from 72 to 74 Rust test
identities while preserving all 42 S3-33 identities and the three S3-34n
gates. The final summary records the path and SHA-256 of each reducer artifact,
including source replay, positive injected reduction, replay commands,
complete repeat observations, reduced digest, and evaluation-limit evidence.
