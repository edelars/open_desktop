# Stage 3 S3-20cl: Address64 RSP-base SIB qword MOV with RSI/RDI data

## Scope

Implemented the bounded singleton profile `48 8B/89 /r 24 [disp8|disp32]` with ModRM `mod=00/01/10`, `r/m=100`, RSI/RDI data (`reg=6|7`), and SIB exactly `0x24`. The three forms have lengths 4/5/8 and cover 12 opcode/data/mode classes. No address32, extra prefix, alternate SIB, extended register, pair, or V3 form was added.

Effective address calculation remains decoder-owned through `MemoryOperand::access_address_48`, using the complete old guest RSP and signed displacement. RSI/RDI load writes stay restricted to the immediately preceding matching `CheckedLoad`; checked stores accept RSI/RDI only for the scoped RSP-base profile. Generic `ReadGpr` and arithmetic validation were not broadened. Runtime source binding checks the exact signed displacement bytes, including the final disp32 byte.

Successful cases use a canonical guest RSP above 32 bits.
