# S3-35i Cold FIFO first execution on M1 Pro

The stock FIFO and interpreter ran the full recovered S3-17 corpus on an
Apple M1 Pro with macOS 14.6.1 and Rust 1.99.0. The ARM64 release binary
from clean `2e9b601` targeted macOS 14.0 and used Hardened Runtime and
`allow-jit`. The exact historical trace and all 1,010 ordered fixture
files were verified. The recovered pathname list has its own SHA-256.
[Recovered inputs and provenance](STAGE_3_S3-17-lookup-measurements-2026-10-26.md#exact-input-recovery-2026-11-19)

Each JIT sweep starts with fresh FIFO cache and arena initialization and
includes the native dispatch intervals for the entire corpus. The
interpreter uses the same input order. Input preparation, state cloning,
validation and teardown occur outside the measured intervals. Each sweep
checks 1,010 calls, 2,990 guest retirements and 1,322 trace visits. FIFO
records two hits, 1,320 compilations and publications, and 1,304 evictions.
Its high-water counts are 16 entries, 21,640 code bytes, 50,124 logical
metadata bytes and 65,536 reserved arena bytes.

Three separate processes contributed 20 paired intervals each. Each pair
uses the same sweep count on both sides. All 120 intervals met the
200 ms floor, with a minimum of 200.054 ms. The actual benchmark PIDs
ran under UID 501 at nice −5.

| Round | Sweeps per side | FIFO median per sweep | Interpreter median per sweep | Paired FIFO/interpreter median (range) |
| --- | ---: | ---: | ---: | ---: |
| 1 | 306 | 8.318 ms | 0.659 ms | 12.626 (12.482–12.701) |
| 2 | 306 | 8.317 ms | 0.659 ms | 12.624 (12.536–12.672) |
| 3 | 305 | 8.301 ms | 0.659 ms | 12.597 (12.557–12.683) |

The interpreter was faster in every scored pair for this corpus.

## Load control and reproduction

Each round had its own 24 two-second preflight probes. The minimum idle
values were 82.3%, 81.7% and 80.5%, with medians of 98.4%, 99.0% and 97.4%.
During accepted rounds, 25 probes recorded 85.4–87.2% CPU idle. The
first individual round attempt was rejected at 71.7% idle. Two earlier
complete stock series were rejected at 73.4% and 73.7% idle. During one
of those trials `mediaanalysisd` and the benchmark
each occupied nearly a full CPU core. The archive preserves both earlier
series and the phase trial rejected for the same load criterion.
[Earlier rejected load records](data/stage3/s3-35i-m1pro-20261119/rejected-load.json.gz)

The measurement uses `cold-first-run --relocated-s3-17-paths` with the
default FIFO dispatcher. Restore the archive's `files` into a scratch
directory and run `python3 -B kit/run.py combine attempts-v3`. The result
matches `audit.json`. The collection wrapper missed its final exit marker.
A separate replay of the saved receipts matched both existing audits.
The archive includes the runner, the exact inputs
manifest, the signed build checksum and all attempts from the final series.
Its SHA-256 is `211811b4fd8f4fb79e0cc19f741516cda563e72ce3419fa47c030c2a1f426a53`.
