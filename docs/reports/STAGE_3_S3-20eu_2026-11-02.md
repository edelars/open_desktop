# S3-20eu: exact addr32 RCX-indexed no-base SIB disp32 Dword store

## Scope and semantics

This runtime slice admits only the exact eight-byte Dword-store singleton
with exactly the `67` address-size override prefix and no other prefixes:
`67 89 04 0D disp32` (`MOV [ECX+disp32],EAX`). The address-size-32 SIB has
no base and uses ECX as its scale-1 index. The effective address is
`zero_extend((low32(RCX) + sign-extended disp32) mod 2^32)`. One contiguous
checked four-byte write stores low32 RAX, including the recorded case that
crosses the 4-GiB boundary. GPRs and RFLAGS are preserved, and the guest
instruction boundary is `A+8`. Other prefixes, scales, SIB shapes, and
encodings remain outside this exact admission.

The exact JIT fixture is
`memory_load_v2::tests::ir_dword_addr32_rcx_index_no_base_sib_disp32_store_binds_all_source_bytes_to_its_site`.
The exact host fixture is
`tests::s3_20eu_addr32_rcx_index_no_base_sib_disp32_dword_store_uses_wrapped_ecx`.
Harness S3-34cf pins both identities.
