# Stage 4 S4-32b: freestanding store/load/UART probe

## Result

S4-32b is a bounded candidate slice that extends the accepted S4-32a real
artifact path with a guest-committed RAM write and a subsequent guest read.
`Stage4StoreLoadProbeV1` uses the existing paged quantum and executes exactly
`MOV [RBX],RCX`, `MOV RAX,[RBX]`, `OUT DX,AL`, `HLT`. The runner has an explicit
profile subcommand and never synthesizes the store, expected RAX or serial
output.

The raw image keeps the S4-32a `0x9000`-byte layout at GPA `0x1000`. Its data
page contains an initial qword at GPA `0x9000` and a distinct store-value qword
at GPA `0x9008`. The loader copies the artifact's store-value into `RCX` as
documented handoff state, validates the exact image/code/table layout and
rejects equal data qwords. It does not modify the target data before guest
execution.

## Acceptance contract

- Code bytes: `48 89 0b 48 8b 03 ee f4` at GPA `0x7000`.
- Handoff: S4-32a Long64/CPL0 state, `RBX=0x800000`, `RCX=store-value`,
  `RDX=0x3f8`, `RIP=0x400000`, `RFLAGS` definedness `0x0cd7`.
- Success: four retired instructions, data qword and `RAX` equal to
  store-value, UART byte equal to its low byte, `Halted`, `RIP=0x400008`.
- Prefixes: budget 1 commits only the store, budget 2 adds the load result,
  budget 3 adds the UART byte; none is guest completion.
