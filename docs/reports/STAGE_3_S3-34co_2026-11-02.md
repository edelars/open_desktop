# S3-34co: exact harness gates for S3-20fd addr32 scaled RAX-indexed Dword load

## Scope

This harness slice pins the JIT source/site and host acceptance identities for
the eight-byte addr32 no-base scaled-SIB Dword-load forms
`67 8B 04 45/85/C5 disp32` (scales 2, 4, and 8). The exact JIT identity is
`memory_load_v2::tests::ir_dword_addr32_rax_index_no_base_sib_scaled_disp32_load_binds_all_source_bytes_to_its_site`;
the host identity is
`tests::s3_20fd_addr32_rax_index_no_base_sib_scaled_disp32_dword_load_uses_original_wrapped_scaled_eax`.
Their harness gate IDs are
`s3_34co_ir_addr32_rax_index_no_base_sib_scaled_disp32_dword_load_source_binding`
and
`s3_34co_host_addr32_rax_index_no_base_sib_scaled_disp32_dword_load_original_eax`.

Each self-check pins its own exact IDs and test identities in the gate
registries, manifest, invocation, and required-evidence validation. The
distinct S3-34cn and S3-34co fail-closed tails reject absent gate declarations
and missing, ignored, failed, zero-match, or wrong-identity evidence.
