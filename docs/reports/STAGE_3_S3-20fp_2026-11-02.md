# S3-20fp: exact RCX-base Dword load `8B 01`

## Scope and semantics

This runtime slice admits only the two-byte encoding `8B 01`
(`MOV EAX,[RCX]`): Dword operand, Qword address size, no prefix, displacement,
or SIB. The effective address is the full original RCX, without truncation to
ECX. The operation is one contiguous checked four-byte read. The result
zero-extends to full RAX; RCX, other GPRs, RFLAGS, and RAM remain unchanged;
successful retirement advances RIP to `A+2`. Existing canonical48/range
preflight, guest/backend faults, entry guards, retry, and callback STOP without
replay remain in force.

## Implementation and coverage

Runtime commit `a99abbb` adds the exact compiler metadata and
`CheckedDwordLoad` byte gate, address64 decoded/IR/runtime profile, and exact
source/site binding for `[8B,01]`. The neighboring `[8B,00]` and `[8B,03]`
forms remain separate supported sites. The JIT test binds the exact source and
site, checks the `A+2` boundary and rejects forged profile fields. The host
fixture checks a full RCX address above 4 GiB against a distinct low32 decoy,
valid canonical upper and maximum-range addresses, plus existing read-fault,
guard/retry, range-preflight, and callback STOP behavior.
