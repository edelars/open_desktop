# Stage 4 S4-25d: bounded CR8 ↔ xAPIC TPR

S4-25d adds an opt-in exact-encoding Long64 profile for `MOV RAX, CR8` and
`MOV CR8, RAX`, connected to the standalone Local APIC's TPR. It returns the
zero-extended TPR priority class on reads and maps a valid CR8 low nibble to
`TPR[7:4]` on writes, clearing `TPR[3:0]`. The machine helper applies a
successful write effect before returning. TPR remains owned by `LocalApic`.

The machine scenario uses self-IPI vector `0x51`: TPR class 5 blocks it, class
4 makes it eligible, acknowledge moves it to ISR and EOI releases priority.
The pending lower vector and in-service state remain observable through the
existing APIC model. Instruction fetch checks canonical48 before each backend
read, including an instruction crossing into a noncanonical address.

## Limits

Only the exact byte encodings are admitted in the selected profile. General
MOV CR8 execution, CPU interrupt acceptance and handler delivery, IDT/IF, HLT
wakeup, JIT and paged-session integration, and default board wiring are not
implemented. APIC operations must be serialized by the caller across the
complete helper call, including instruction fetch and effect application; no
architectural serialization guarantee is claimed. Unsupported machine states
remain closed. Parent S4-25 and Stage 4 remain open.
