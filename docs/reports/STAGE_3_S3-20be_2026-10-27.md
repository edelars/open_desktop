# Stage 3 S3-20be: address32 SIB with RBP base and RBP index

## Scope

Added one exact singleton profile: `67 48 8B/89 /r sib disp8|disp32`, ModRM `mod=01/10,r/m=100`, SIB base=index=RBP, scale 1/2/4/8, data RAX..RBP. Address size is Dword, transfer size is Qword, and instruction lengths are exactly 6 and 9 bytes. The `mod=00,SIB.base=101` no-base form remains excluded. The generic index whitelist, pair profiles, V3, `od-isa`, Stage 2, owner/MMU integration, Mini, and performance scope are unchanged. Decoder `MemoryOperand` and `access_address_48` remain the sole source of address semantics.

## Evidence

- The JIT descriptor matrix covers both operations, all six data registers, four scales, and signed disp8/disp32 edges. It checks direct V2/shared IR descriptor agreement, exact source/profile admission, decoded widths/base/index/scale/displacement/length, and the independent target `(low32(RBP) + low32(RBP)*scale + signed displacement) mod 2^32`.
- The host matrix compares direct V2 and shared IR against interpreter full CPU/RAM state for both directions, all six data registers, four scales, and signed disp8/disp32 boundaries. Callback address/length/count and retirement are checked. `data=base=index=RBP` uses the pre-instruction value; loads commit the full destination after the read and stores send the full old qword.
- High RBP halves are ignored by Dword EA. A qword at `0xffff_fffc` is one contiguous eight-byte callback crossing 4 GiB. Two immutable 9-byte artifacts differing only in source byte 9 produce separately asserted targets `0x500` and `0x0100_0500`.
- Guest read/write callback faults preserve the exact guest fault payload and leave CPU/RAM uncommitted; backend failures remain host errors with exact attempted callback and no commit. The dispatcher test also covers pre-entry zero-budget/STOP, partial byte windows 1..5 and 1..8, and a complete rejected `mod=00,SIB.base=101` neighbor.
- An exact-profile store callback requests STOP after a successful write; the store remains committed and retires once. Budget 1 stops after the singleton at its actual next RIP; continuation executes the explicit NOP and existing two-instruction pair without replaying the first memory effect.
- Full-suite validation exposed stale negative fixtures using the now-supported base=index=RBP encoding. Those invalid cases were changed to use unsupported RSI-index encodings; subsequent JIT/host tests pass.
