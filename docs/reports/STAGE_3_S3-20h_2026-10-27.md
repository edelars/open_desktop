# S3-20h / S3-26a — checked qword load through shared typed IR

**Date:** 2026-10-27. **Status:** bounded implementation and local native
ARM64 verification complete; independent review is pending. The physical x86
Mac mini check remains reserved for the final S3-21 gate.

## Scope

This slice admits exactly one `48 8B /r` instruction with ModRM `mod=00`, data
and base GPR RAX..RBX, no SIB, and no displacement. It uses the shared
BasicBlock, typed IR, allocator, and runtime emitter path. The existing direct
V2 compiler remains a separate baseline. No `od-isa`, Stage 2 fixture, or
generator file was changed.

`CheckedLoad` defines a W64 temporary only on successful helper completion.
The verifier requires one current instruction, a qword canonical48 direct
base descriptor, a write of the returned temporary, and commit after that
write. The builder performs exact raw encoding checks while the lowerer uses
the decoder's `MemoryOperand`. Allocation marks the actual helper call
boundary. The V2 emitter saves/restores helper-crossing values, calls the
existing checked helper with site index 0, stages the qword, and applies the
common GPR/RIP/budget/retirement commit with a PC map covering helper and
commit ranges.

The compiled artifact uses a distinct flavor, compiler-issued type, publication
metadata, and `RuntimeContextV2` entry. Both the V1 executor and direct V2 load
executor reject this artifact before native entry.

## Local evidence

- `cargo test -p od-jit --offline checked_load_requires_valid_descriptor_result_write_and_commit_order -- --nocapture` — passed. Negative cases cover malformed descriptor, undefined result temporary, missing write, and commit before write.
- `cargo test -p od-jit --offline ir_checked_load_uses_distinct_v2_artifact_and_pc_map -- --nocapture` — passed. Checks distinct code/flavor, helper range, and committed guest boundary.
- `cargo test -p od-host --offline v2_mov_load_matches_interpreter_on_independent_state_and_ram_snapshots -- --nocapture` — passed on local Apple Silicon. The alias form `[RAX] → RAX` matches direct V2 and interpreter full state/RAM on success. IR success explicitly reports one retired instruction; architectural fault reports zero. The backend error assertion checks exact unmapped kind, address 8, and length 0 (the checked-memory outcome does not attach a span to `Unmapped`). Architectural and backend failures preserve full CPU state. STOP, stop-RIP, and zero budget perform no read. V1 and direct V2 executors reject the IR artifact before entry.
