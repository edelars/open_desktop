# S3-40ag Historical residual in public interpreter RUN on M1 Pro

The comparison uses the unmodified interpreter and decoder from
`d24865d` and `5bc5ec6`. The current build includes both x87 guard
changes adopted in S3-40ae and S3-40af. The benchmark driver,
workload attachment and priority check are byte-identical to S3-40z.
Both builds use the same 2,400 S3-34a inputs and budgets 0, 1 and 2.
[Previous historical comparison](STAGE_3_S3-40z_2026-11-19.md)

Separate untimed checks on the M1 Pro covered both instruction
sequences at all three budgets and an unmapped-code case at budget
zero. They verified the full CPU state, defined flags, RAM, ordered
data callbacks, retirement count and budget exit. The archived
receipts bind the two signed ARM64 binaries to their exact revisions.

## Results

Six rounds alternated build and sequence order. Each process
ran all six permutations of budgets 0, 1 and 2 and used the fixed
S3-40z counts of 4,374,000 and 4,339,200 calls per interval.
The series retained 432 intervals and 1,882,051,200 RUN calls.
The shortest interval was 80.509 ms, above the 45 ms floor.

The current build took longer in every paired round at every budget.
The pooled difference was 5.3 ns at budget 0, 67.8–69.4 ns at
budget 1 and 134.2–134.7 ns at budget 2. These are complete RUN
paths from two pinned revision builds. ISSUE-521 remains open
for the remaining gap on the nonzero-budget paths.
[Interpreter performance issue](../KNOWN_ISSUES.md#issue-521)

## Environment and reproduction

MacBookPro18,3, Apple M1 Pro, eight logical CPUs, macOS 14.6.1
(23G93), Xcode 15.4 (15F31d), Rust and Cargo 1.99.0, and Python 3.12.5.
The native ARM64 release builds target macOS 14.0. Both passed strict
signature checks with Hardened Runtime and `allow-jit`. The machine
was on AC power. All twelve scored processes recorded UID 501,
nice −5 and QoS `0x21`.

The 24 preflight probes ranged from 93.7% to 99.1% idle CPU,
with a median of 98.6%. The 31 in-run probes ranged from
80.9% to 92.1%, with a median of 86.3%.

Extract the harness files to `work/tmp/s3-40-run-residual/` in a
checkout with the two pinned commits and the S3-40m, S3-40w and S3-40z
archives. The archived `README.md` provides the native builds,
untimed checks and monitor commands. `python3 offline_audit.py
/path/to/evidence.json.gz` reproduced the saved audit on M1 Pro
and after transfer. The archive contains 67 files and has SHA-256
`911c38b6ea8a5a339f060a27711e0bbe412453192ac5b2dd753d2077d54b6dbc`.
