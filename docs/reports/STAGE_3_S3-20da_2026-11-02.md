# S3-20da — exact address-size-32 disp32 dword checked-memory load

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `10b0f08` adds only the seven-byte singleton `67 8B 83 id`
(`MOV EAX,[EBX+disp32]`) to the shared typed-IR dword-load path. Its signed
disp32 effective address follows the decoder-owned address-size-32 semantics,
including 32-bit wrapping and zero-extension. The host fixture performs one
checked four-byte load; the JIT test binds every source byte to the site and
checks the `A+7` instruction boundary.

This is one exact addr32 disp32 load profile. It does not admit other addr32
bases or displacement forms, and it does not establish production owner/MMU
integration, broader memory coverage, physical-x86 behavior, or performance.
