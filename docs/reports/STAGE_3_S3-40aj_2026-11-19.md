# S3-40aj HLT and interrupt guards in interpreter RUN on M1 Pro

Four 7-second samples used the exact signed S3-40ai images. In the
current `de1f446` STEP, the HLT, INT3 and CLI predicates account for
13, 17 and 12 matched stacks. Together they account for 42 of 148
directly mapped `Operation::eq` stacks. A further 366 equality
stacks lacked a direct call-site mapping. The outer STI guard is
present on the false-CLI branch. The fresh samples have no direct
match for it. One match was observed in the earlier S3-40ah samples.
The historical STEP has no direct literal equality calls for
these four variants. The samples locate calls, while the paired
benchmark measures the whole RUN path.
[Historical RUN comparison](STAGE_3_S3-40ai_2026-11-19.md)

The candidate uses `matches!` for the four fieldless outer predicates.
The Rust source keeps the CLI/STI short-circuit order, the profile-only
HLT condition and the body-only STI expression. The linked STEP loses
the four outer calls. LLVM also folds the body-only STI comparison,
bringing the total static call count from 86 to 81. The profile-only HLT
comparison remains in the binary.
Both build variants passed the seven targeted HLT, INT3, CLI and STI
behavior checks and 2,400 MOV inputs at each budget. The MOV tests
also cover unmapped code at budget zero and verify state, defined
flags, RAM, ordered data callbacks, retirement and budget exit.

## Results

Six paired rounds alternated build and workload order. Each process
ran all six budget permutations. The two workloads used a fixed
4,374,000 and 4,339,200 calls per interval.
The run retained 432 intervals and 1,882,051,200 RUN calls.
The shortest interval was 103.471 ms against a 45 ms floor.

Adopt the four predicate changes. Paired RUN medians fell by
3.39–3.86% at budgets 1 and 2, with improvements in all six rounds
on both workloads. The budget-zero ranges include unity. The gap
against the historical interpreter remains open in ISSUE-521.
[Interpreter performance issue](../KNOWN_ISSUES.md#issue-521)

## Environment and reproduction

Apple M1 Pro, eight logical CPUs, macOS 14.6.1 (23G93), Xcode 15.4,
Rust and Cargo 1.99.0, and Python 3.12.5. Both native ARM64 release
builds target macOS 14.0 and passed strict signature checks with
Hardened Runtime and `allow-jit`. The machine was on AC power.
All twelve timing processes recorded UID 501, nice −5 and QoS `0x21`.
The 24 preflight probes measured 95.4–99.2% idle CPU, with
a median of 98.8%. The 37 in-run probes measured
85.1–86.8% idle CPU, with a median of 86.2%.

Extract the timing archive’s harness files into
`work/tmp/s3-40aj-interrupt-entry-guards/` in a checkout with the
pinned revision and the S3-40m, S3-40w and S3-40z data archives.
The archived `README.md` gives build, correctness and measurement
commands. `offline_audit.py` recomputes the result from the retained
intervals and verifies signed-build and test receipts.
