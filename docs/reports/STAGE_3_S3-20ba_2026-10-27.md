# S3-20ba — address32 SIB qword MOV with RBP index

## Scope and result

Added one exact singleton profile for `67 48 8B/89 /r sib [disp8|disp32]`: ModRM `mod=00/01/10,r/m=100`, low base RAX..RBX, index RBP, scale 1/2/4/8, data RAX..RBP, and instruction lengths 5/6/9. The effective-address size is Dword and the transferred value remains Qword. Existing address64 RBP-index and address32 SIB profiles remain separately admitted. The generic index whitelist was not broadened; stack/no-base bases, other indexes, extra prefixes, pairs, V3, Stage 2, and `od-isa` were not changed.

The decoder's `MemoryOperand` and `access_address_48` remain the sole address semantics. The supported target formula is `(low32(base) + low32(RBP) * scale + signed displacement) mod 2^32`, zero-extended before one contiguous eight-byte access. Runtime source validation checks the exact opcode/ModRM/SIB profile and decoded immutable metadata; it does not re-decode displacement bytes.

## Evidence

- Descriptor coverage runs both operations over all six data registers, four low bases, four scales, and no-displacement/disp8/disp32 lengths with signed boundaries. It checks decoded base/index/scale/displacement, direct V2 and shared IR site parity, byte-nine displacement effect, and invalid no-base/stack-base/index/prefix shapes.
- Host parity compares direct V2, shared IR, and interpreter CPU state/RAM/callback/retirement for all forms. Cases include pre-state aliases, ignored high halves, wrap, and a qword access beginning at `0xffff_fffc` with one contiguous callback.
- Host error cases inject an architectural memory fault and a backend memory error for load and store. They preserve CPU/RAM state and keep the fault class distinct while asserting the exact callback address and width. A successful RBP-data store followed by STOP commits the old full qword once.
- Bounded dispatch splits after the RBP-indexed singleton at budget 1, resumes from actual RIP through NOP and the existing two-instruction pair without replay, and validates exact callbacks. Partial windows 1..8 return fixture `BoundaryReached` with no retirement or memory effects.
