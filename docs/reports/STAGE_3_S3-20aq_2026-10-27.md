# S3-20aq report: indexed SIB with RSP base

## Scope

Added only 64-bit-address-size singleton `48 8B/89 /r sib [disp8|disp32]`
forms with ModRM `mod=00/01/10,r/m=100`, SIB base RSP, index RAX..RBX,
scale 1/2/4/8, data RAX..RBP and qword transfer width. Exact lengths are
4/5/8 bytes. The existing no-index SIB `0x24` stays a separate profile. No
address-size override, other base/index, pair or V3 form was added.

Admission in the checked block builder, shared IR, direct V2, runtime source
metadata and bounded dispatcher now agrees on this profile. Decoded
`MemoryOperand::access_address_48` remains the sole EA calculation. RSP-base
addressing uses the old RSP and old index; a load commits its destination only
after a successful access, and a store sends the full old data-register value.

## Evidence

The existing descriptor matrix now also checks RSP base with each low index,
all four scales, both memory operations, all six data registers, and no-disp,
disp8 and disp32 signed edges. It retains low-base indexed SIB coverage and
rejects the unsupported no-base/special and extended-index forms.

The host no-displacement matrix compares direct V2, shared IR and interpreter
for RSP base, each low index, every scale and all data registers. The signed
displacement host matrix compares full CPU/RAM state, exact callback targets,
callback counts and retirement for signed disp8/disp32 boundaries; it includes
data=RSP and data=index pre-state cases.

Host regressions check #SS for noncanonical RSP at the first and last qword
byte before memory callbacks; exact backend-error payload classification with
no state/RAM commit; a successful RSP-data store that remains committed when
its callback requests STOP; entry STOP with no access; and budget continuation
from the actual RIP through a NOP and the existing pair without repeating the
first read. Partial disp32 windows and unsupported SIB index forms produce no
publication, retirement or memory callback.
