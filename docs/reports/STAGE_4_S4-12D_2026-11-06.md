# S4-12d: CPU-owned CR0.WP translation handoff

## Scope

Adds an opt-in `PagedCpl0Cr0WpProbeV1` CPU/machine path for exact `MOV CR0,RAX`
and `MOV [RBX],RCX`. CR0 is limited to `0x80010033` (WP=1) and `0x80000033`
(WP=0); CR3 is CPU-owned, CR4 is `0x20`, EFER is `0xd00`, execution is CPL0,
single-vCPU and uncached. The store must fit one 4 KiB RAM page. Existing CR3,
legacy and paged profiles retain their allowlists.

Every successful CR0 write, including an identical-value write, commits once
and returns typed `TranslationContextChange::Cr0Write { old_cr0, new_cr0 }`.
The machine validates that effect against the active snapshot and committed
CPU state, rebuilds the immutable `Long64ProbeConfig`, then installs it before
the next STOP poll/fetch/access. Applying the effect performs no walk or A/D
update; the instruction fetch may already have made A updates.

Verified WP `1→0` permits the following supervisor store through an R/W=0
mapping. WP `0→1` produces a precise protection fault while retaining the
retired MOV CR0; the store does not commit data or D, while prior A updates may
remain. The successful R/W=0 case checks stored bytes and the committed-write
callback, without asserting a D-bit result. STOP immediately after MOV CR0
preserves retirement and leaves the operand leaf untouched before resumption.
Exact MOV CR0 at CPL1–3 faults with #GP(0) after fetch and does not retire;
machine quantum admission itself remains CPL0-only. The direct CPU entry rejects
ordinary stores at CPL1–3 before data access/retirement. Cross-page stores are
Unsupported before checking the end of the address range or touching data,
including starts at the upper edge of canonical address regions. Other invalid
encodings remain Unsupported in this bounded profile; exact LOCK `MOV CR0,RAX`
is classified as #UD after full fetch, preserving its prior classification in
the existing execution paths.

This slice does not implement other CR0 controls, PE/PG mode transitions,
EFER writes, TLB invalidation, exception delivery or CR2. Parent S4-12 and
Stage 4 remain open.
