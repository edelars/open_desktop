## Binary comparison and limits

`file` reports the same SHA-1 Build ID,
`338e542e384c46228f7a378babc0f9bb2b6a5997`, for `vmlinux` and
`vmlinux-debug`. A read-only ELF64 section-header parser compared 42 release
sections and 57 debug-ELF sections; the 38 common sections with `SHF_ALLOC`
and a non-`SHT_NOBITS` type had identical names, types, flags, addresses,
offsets, sizes and SHA-256 section bytes. This revalidates the previously
documented 38 allocated file-backed section equality. Apple LLVM `objdump -h`
was used only for a human-readable listing; it does not expose the GNU flags
needed for this comparison.

The signed `.dsc`, `linux_7.0.0.orig.tar.gz`,
`linux_7.0.0-38.38.diff.gz`, signed `Sources.xz`, signed `InRelease`, and
`apt-provenance.json` were not recovered. Consequently, the mirror download is
not authenticated by a recovered signed repository chain, and no
source/config-to-binary mapping is established. Matching Build IDs and the
38-section equality are comparison evidence only. No claim is made about
runtime alternative selection, Linux boot, or physical CPU behavior.

## Commands and environment limits

The source package can be re-fetched with:

```sh
curl -fL 'https://repo.huaweicloud.com/ubuntu/ubuntu/pool/main/l/linux/linux-source-7.0.0_7.0.0-38.38_all.deb' \
  -o work/vms/s2-00-ubuntu-26.04.1/source/linux-source-7.0.0_7.0.0-38.38_all.deb
```

The archive/config extraction commands are recorded in the JSON manifest. The
section comparison is a read-only Python 3 ELF64 little-endian parser over
section headers: it reads `e_shoff`, `e_shentsize`, `e_shnum` and `e_shstrndx`,
selects `SHF_ALLOC` sections excluding `SHT_NOBITS`, then compares the named
header fields and SHA-256 of each section's bytes. `readelf` is unavailable in
the environment; `objdump -h` is only a display aid. The exact parser used was:

```sh
python3 - <<'PY'
import hashlib
import struct
from pathlib import Path

def sections(path):
    data = Path(path).read_bytes()
    shoff = struct.unpack_from("<Q", data, 40)[0]
    shentsize = struct.unpack_from("<H", data, 58)[0]
    shnum = struct.unpack_from("<H", data, 60)[0]
    shstrndx = struct.unpack_from("<H", data, 62)[0]
    headers = [struct.unpack_from("<IIQQQQ", data, shoff + i * shentsize)
               for i in range(shnum)]
    string_header = headers[shstrndx]
    strings = data[string_header[4]:string_header[4] + string_header[5]]
    result = {}
    for name_offset, section_type, flags, address, offset, size in headers:
        end = strings.find(bytes([0]), name_offset)
        name = strings[name_offset:end].decode("utf-8", "replace")
        digest = None if section_type == 8 else hashlib.sha256(
            data[offset:offset + size]).hexdigest()
        result[name] = (section_type, flags, address, offset, size, digest)
    return result

release = sections("work/vms/s2-00-ubuntu-26.04.1/vmlinux-7.0.0-38-generic")
debug = sections("work/vms/s2-00-ubuntu-26.04.1/vmlinux-debug-7.0.0-38-generic")
common = [name for name in sorted(set(release) & set(debug))
          if release[name][1] & 2
          and release[name][0] != 8
          and debug[name][0] != 8]
mismatches = [name for name in common if release[name] != debug[name]]
print(len(release), len(debug), len(common), not mismatches)
assert (len(release), len(debug), len(common), not mismatches) == (42, 57, 38, True)
PY
```
