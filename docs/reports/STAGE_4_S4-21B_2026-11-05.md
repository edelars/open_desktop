# Stage 4 S4-21b: bounded paged probe quantum

## Результат

Принят bounded `PagedCpl0ProbeV1` с единым machine quantum
`run_paged_probe`. CPU entry `step_paged_probe` исполняет только пять точных
Long64 CPL0 форм:

- `48 8B 03` — `MOV RAX,[RBX]`;
- `48 89 0B` — `MOV [RBX],RCX`;
- bare `EC` — `IN AL,DX`;
- bare `EE` — `OUT DX,AL`;
- bare `F4` — `HLT`.

CPU проверяет profile admission и CR0/CR4. Machine проверяет CR3/EFER и
предоставляет page-aware memory. Quantum выполняет один decode на каждой
границе и применяет порядок выхода STOP → исчерпанный budget → fetch/decode.
Предыдущие инструкции остаются committed после STOP, budget exhaustion или
поздней ошибки. HLT коммитит halted state; следующий вызов на halted CPU
возвращается без fetch/effects, при этом HLT не трактуется как guest success.

Архитектурные faults сохраняют точную запись, включая PFEC, linear address,
access kind/origin и saved RIP. Page-table A/D writes и callbacks сохраняются.
Memory backend и PIO errors остаются отдельными результатами. Автоматической
exception delivery и CR2 update нет.

## Проверки и ревью

- `od-isa`: 2,014 unit tests и 25 integration tests прошли.
- `od-machine`: 116 tests прошли.
- Workspace all-targets check, `cargo fmt --all -- --check`,
  `python3 tools/check_layout.py` и `git diff --check` прошли.
- Независимое code review одобрило срез без замечаний P0–P3.
- `graphify update .` завершился успешно и обновил code graph; docs-aware
  semantic extraction после изменений документации не завершена.
- JSON evidence и локальные Markdown-ссылки проверены.

Сценарии включают store→load→OUT→HLT одним quantum и разделёнными quantum,
STOP/resume без повтора committed store/PIO, HLT no-op повторный вызов,
admission/allowlist, точные page faults после выполненного prefix, A/D bits и
callback ranges, а также раздельные backend/PIO failures.

## Границы

Это локальное Rust evidence. Оно не подтверждает boot собственного kernel или
Linux, IRQ/APIC, exception delivery/retry, CR2 update, полный жизненный цикл
vCPU или завершение S4-21/S4-24/S4-32. Stage 4 остаётся открытым.
