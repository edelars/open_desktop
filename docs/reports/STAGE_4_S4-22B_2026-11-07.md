# Stage 4 S4-22b: Paged vCPU clock and UART RX deadlines

`PagedVcpuSession` now owns one `VirtualClock`, constructed with an explicit,
nonzero `tsc_hz`. UART RX deadlines and dispatch use the clock's absolute
nanosecond domain; `dispatch_rx` no longer accepts an independent `now_ns`.
Execution and polling do not advance time.

The caller may advance time while the host session is `Active`, including when
the guest is halted. This does not wake the guest or dispatch RX while halted.
Pause, stop and terminal states reject advancement. Reset clears RX queue state
but preserves clock frequency and current time. Invalid frequency and checked
time/TSC overflow leave the clock unchanged. The runner uses an explicitly
named diagnostic frequency; it does not advertise Linux guest CPUID/MSR timing.
