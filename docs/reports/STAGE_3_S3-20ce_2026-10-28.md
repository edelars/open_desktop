# S3-20ce: Address64 RSI/RDI-base no-index SIB

Date: 2026-10-28  
Status: implemented; independent code review signed off with no remaining findings.

## Implemented scope

Added the exact qword singleton profile `48 8B/89 /r sib [disp8|disp32]` with ModRM `mod=00/01/10,r/m=100`, SIB `0x26` or `0x27`, RAX..RBP data register, and instruction lengths 4/5/8. Scale is one and the index is absent. The existing decoder-owned `MemoryOperand::access_address_48` supplies full-width old RSI/RDI plus signed displacement with u64 wrapping; RSP remains outside EA.

The same admission now reaches checked block construction, direct V2/shared IR metadata validation, immutable source matching and bounded dispatcher compilation. No Stage 2/ISA or owner/MMU code was changed.
