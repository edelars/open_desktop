# S3-36c: resident warm NOP-fallback comparison

## Result

Three sequential release-process runs completed on Apple M3 Max / macOS 26.7.1
(ARM64), using source revision
`53c058f135ddcf5722dbfbfa132a08bd5359038a` and source SHA-256
`7f116d2dd51f9e62de7e22491a85675db906046f051ec1154fd85c625752af56`.
The release preflight checked all 1,200 stored interpreter observations and
recomputed the frozen S3-34p corpus with SHA-256
`3fddc5c753f3d2884850468480ec68d13a6069d1aed16e8973e1acef56ffac1f` and
ordered input digest `fnv1a64:172fb17b01c502df`. It selected exactly 19
seed/index identities: ten cases with two native instructions followed by a
retired interpreter NOP, and nine cases with three native instructions
followed by a retired interpreter NOP. All exit with `BudgetExhausted`.

For these inputs, interpreter execution completed sooner in all three runs.
The run-level median-of-case-medians ranged from 5.22330 to 5.25895 for the
two-native stratum and from 4.31302 to 4.37645 for the three-native stratum;
these are cached-dispatch elapsed / interpreter elapsed ratios. This describes
only the frozen native-plus-NOP budget-exit cases; it is not a result for
general fallback, memory workloads, or full guest workloads.

## Timing

Each input used one capacity-one cache, prewarmed once and retained through
calibration and timing; that mapping was dropped before moving to the next
input. Each process retained 20 alternating interpreter/cached pairs per
input. Every retained timed interval was at least 200 ms per side; the
shortest observed sides by process were 217.665 ms, 218.218 ms, and 220.072 ms.
All pairs and discarded short attempts are present in the raw reports.

The ratio is cached-dispatch elapsed divided by interpreter elapsed. Per-case
spread is the report's IQR over the 20 paired ratios; the stratum IQR is over
case ratio medians. The implementation uses the lower middle value for an
even-sized median and the fixed sorted positions described in the suite
manifest.

Across the three processes, the two-native stratum medians span 5.22330–5.25895
(0.68% relative range); three-native medians span 4.31302–4.37645 (1.47%).
Within-case pair IQRs remain visible in every raw report, with per-process
means of 0.06888–0.08537 and maxima of 0.12224–0.13059. The suite does not
select a general cache/interpreter policy or establish a broader performance
result.

The prewarm produced one miss, compile, and publication per case. The eager
repeat eligibility check produced exactly one hit and zero misses, compiles,
publications, or replacements. Timed dispatches were checked as hit-only;
cache counters include the calibration call and discarded restart samples as
well as retained pairs. Resident emitted-code size ranged from 1,092 to 1,772
bytes per case. The current full cached-entry logical-size bound ranged from
6,001 to 9,061 bytes. The reported metadata-only logical high-water (3,329 to
5,029 bytes) uses a different accounting scope and must not be compared with
the full entry-size value. Neither is process RSS; allocator bookkeeping is
excluded.

## Host overlap and limits

The scored processes ran sequentially. Point-in-time process/load snapshots
show intermittent Stage 2 cargo/rustc activity in all three runs. Run 1
included several compiler/test overlaps, with one sampled rustc process near
86% CPU. Run 2 had cargo test launches and a short rustc sample near 15% CPU.
Run 3 had a short workspace-check overlap with two rustc processes near 20%
CPU, and a `python -m graphify update .` process sampled at 89.5% CPU in one
snapshot. The Graphify process's attribution and overlap duration are not
established from that point-in-time observation.
Sampled one-minute host load ranged approximately 2.8–5.5. Stage 2 launches
were not used as a stop condition, and no process was stopped.

The monitoring envelopes were reconstructed from executor results and
point-in-time snapshots. They do not form a continuous process log, and raw
paired samples have no wall-clock timestamps. The evidence therefore cannot
assign individual pairs to particular overlap windows or establish the causal
effect of concurrent work. Cross-process ratios are close, but there is no
controlled quiet comparison in this suite. The command sessions returned exit
code 0 for all three scored processes; separate executor log files were not
retained. The source fingerprint reports a clean source tree
(`source_tree_dirty: false`); working-tree state is unknown because
`git status` timed out after two seconds (`working_tree_dirty: null`). The persisted
originals contain one preflight and three scored reports with no recorded
excluded attempt; these files cannot establish whether unpersisted attempts
occurred.

This result does not cover memory fallback, general fallback frequency,
physical x86 comparison, the Mac mini, or whole-system performance. Mac mini
checks remain deferred until the end of Stage 3; S3-36 and S3-41 remain open.
