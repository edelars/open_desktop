# S3-20dg — exact address64 SIB dword stores at scales 2, 4, and 8

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `db20089` adds only the three exact three-byte singletons
`89 04 4B`, `89 04 8B`, and `89 04 CB` (`MOV [RBX+RCX*2|4|8],EAX`) through
shared typed IR. They use full-width RBX base and full-width RCX index at the
SIB-selected scale. Effective address calculation follows decoder-owned
address48 `access_address_48`. Each store writes low32 EAX in one contiguous
checked four-byte access; the guest instruction boundary is `A+3`.

The recorded fixtures cover exact source/site scale binding, PC-map boundary,
no replay, fault atomicity, STOP, and budget behavior. A noncanonical boundary
fixture asserts the decoded EA ends in `...fffe` and that the crossing access
raises `#GP`. This fixture was added without changing the shared preflight or
helper; no runtime defect is claimed.
