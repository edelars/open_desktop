# S3-20ec — exact RSP disp8 dword store

## Scope

S3-20ec admits the exact address64 four-byte singleton `89 44 24 ib`
(`MOV [RSP+disp8],EAX`) through the existing shared typed-IR checked-memory
store path. The SIB is scale 1 with no index and full-width RSP base. The
decoder-owned effective address adds the signed disp8 to RSP with wrapping
u64 arithmetic; one checked width-four write stores low32 RAX and commits
the guest boundary `A+4`.

The implementation is limited to exact admission, source/site metadata, the
typed-IR store predicate and host publication allowlist. It does not claim a
separate PC-map phase, broader address forms, production owner/MMU
integration, MMIO/SMC behavior, physical hardware behavior, or performance
improvement.
