# Stage 3 S3-33h: exact native LEA RAX,[RBX]

Date: 2026-10-30  
Status: bounded implementation; targeted checks and full local harness passed.
Independent code review passed; final report-linkage review is pending.

## Scope

This slice adds a separate uncached opt-in native path only for bare
`48 8D 03` (`LEA RAX,[RBX]`). Admission checks the exact source bytes and the
decoded W64 RAX destination, 64-bit address size, RBX base, and absence of
index/displacement/RIP-relative addressing. Equivalent SIB/displacement
forms, other registers, width/address-size variants, prefixes, truncation, and
branch targets inside the instruction are rejected.

Lowering is limited to `ReadGpr(RBX,W64)` → `WriteGpr(RAX,W64)` → one commit.
The path has no checked load, data-memory access, canonicality check, helper,
arithmetic effect, or flags operation. Full RFLAGS/definedness and any pending
flags descriptor and saved operands are preserved. Separate eager and
demand-flags candidate compile/dispatch APIs remain opt-in and uncached. No
Stage 2, `od-machine` owner/MMU, Mini, or performance changes are included.

## Evidence

- Exact admission and branch-boundary rejection are covered by
  `block::tests::lea_rax_rbx_admission_is_exact_and_separate_from_other_profiles`.
- Exact IR shape and eager/candidate compile output are covered by the od-jit
  lowering and compiler tests. The compiler test checks the following branch's
  PC map and requires no helper call.
- Host differential tests cover RBX zero, one, `u64::MAX`, signed extrema,
  unmapped/noncanonical values, full state and retirement, GPR canaries,
  definedness/full flags, and a memory probe that rejects data callbacks.
- Pending ADD/CMP → LEA → distinguishable JZ/JNZ paths check that the earlier
  flags writer remains authoritative; candidate PC-map statepoint evidence is
  asserted, with CMP operands chosen so a mistaken LEA flag write reverses the
  branch. LEA → NOP interpreter fallback → JZ/JNZ also checks pending flags
  across fallback and native/interpreter retirement; STOP and budget boundaries
  bracket the NOP. Consecutive LEAs, a successor writer, and terminal LEA are
  covered.
- Three exact local harness gates pin admission, compiler, and host test
  identities. The S3-33 gate selfcheck requires each identity exactly once in
  manifest, steps, and summary while preserving existing gates.
