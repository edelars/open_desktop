# Stage 4 S4-23d: generation-aware paged RX control

`PagedVcpuSession` now exposes its queue-local `EventGeneration` and the
read-only next RX deadline. Scheduling, cancellation and rescheduling require
the caller's expected generation. Stale requests are rejected before
lifecycle admission; current-generation mutations are allowed only while the
host is active and the guest is not halted. Deadline inspection is available
in every state. No deadline or control operation wakes HLT.

The generation identifies this queue instance only. It is not a cross-session
identity and does not prevent reuse of a key within the same generation.
Reset still clears queued payloads and increments generation; the session clock
remains intact.
