# S3-20x — RSP-base no-index SIB qword MOV with signed disp32

## Scope

The bounded singleton profile admits only `48 8B/89 /r sib disp32`, ModRM
`mod=10,r/m=100`, exact SIB `0x24`: RSP base, absent index, scale 1, signed
disp32, data RAX..RBX, qword data, 64-bit effective address and exact length
eight. Disp32 occupies source bytes 4..7, after the SIB. The source metadata
capacity already accommodates the instruction. Decoder `MemoryOperand` and
`access_address_48` remain the sole displacement and effective-address
semantics. No new emitter, pair/V3 change, data-buffer change, or ABI change is
included. The prior `[RSP]` and RSP+disp8 forms remain separately covered.

## Evidence

- The descriptor test covers load/store, RAX..RBX data registers and disp32
  MIN/-1/0/MAX. It checks decoded RSP/no-index/scale/displacement metadata,
  exact next RIP and full eight-byte source identity. Sources differing only in
  byte 7 decode to distinct displacements. Invalid SIB, ModRM, data register,
  prefix, truncation and trailing-byte variants are rejected.
- Direct V2, shared IR and interpreter match for both operations at all four
  displacement boundaries. A qword access at `0xffff_fffc` uses one contiguous
  callback, and another positive disp32/base sum wraps modulo u64 to canonical
  address zero. With RSP fixed, sources differing only in the high displacement
  byte issue callbacks at the expected distinct addresses
  `0x0000_7000_0100_5020` and `0x0000_7000_0200_5020`. Comparisons cover full
  CPU/RAM state, callback address/count and retirement; RSP/RBP/flags remain
  unchanged.
- Noncanonical RSP start and qword-end checks retain #SS; corresponding RBX
  controls retain #GP. Architectural faults make no memory callback and commit
  no CPU/RIP/RAM/budget/retirement state. AddressOverflow remains its host
  diagnostic and backend errors remain host errors. Entry STOP and budget zero
  prevent access; successful disp32 store+STOP remains committed once.
- Dispatcher composes the eight-byte singleton → bare NOP interpreter bridge
  → existing pair. Budgets 0..4 match interpreter state and RAM. Pre-entry STOP,
  STOP-RIP after the singleton, and continuation from actual RIP are checked;
  continuation does not repeat the access. Byte windows 1..7 return
  `BoundaryReached` with no effects. Invalid near-matches retire nothing and
  make no callbacks.
