# Stage 3 S3-33f: exact native SUB RAX, sign-extended imm8

Date: 2026-10-30  
Status: bounded implementation; independent review and full local harness run complete.

## Scope

This slice adds an opt-in uncached native path for only bare `48 83 E8 ib`
(`SUB RAX, sign-extended imm8`), for all 256 immediate bytes. Its separate
admission/profile does not extend generic arithmetic, INC, DEC, NEG, ADD, or
CMP profiles. Decoder-owned `Operand::Immediate` is checked against the source
byte's sign extension and is used directly by lowering.

Lowering emits Read RAX → W64 Const → W64 Subtract with a result and full
`FlagEffect::Arithmetic` → Write RAX → one Commit. Eager and demand-flags
candidate compilation and dispatch use the existing IR, emitter, statepoint,
and pending-flags machinery. No IR, ABI, emitter, allocator, shared-cache,
default-dispatch, Stage 2, `od-machine` owner/MMU, Mini, or performance changes
are included.

## Evidence

- Admission checks all 256 source bytes and the decoded sign-extended value;
  it rejects other group selectors, registers including R8, memory, width and
  prefix variants, `81`, accumulator encoding, truncation, and branch targets
  inside the immediate. Existing arithmetic profiles reject this SUB form.
- Lowering checks `00`, `01`, `7f`, `80`, and `ff` and asserts the exact IR
  sequence and decoded constant.
- Compiler checks cover eager and candidate code through a branch consumer,
  instruction count, code end, and PC-map boundaries.
- Host differential coverage compares complete state, RIP, and retirement
  against the interpreter. It includes immediate zero, `0-1`, `0-(-1)`, MIN−1,
  MAX−(-1), both incoming CF values, AF/PF, opposing old flags, DF and
  non-arithmetic preservation, and each immediate boundary.
- Pending CMP→SUB and ADD→SUB cases produce distinguishable JZ/JNZ paths. The
  tests cover candidate pending-statepoint evidence, terminal SUB, a successor
  full writer, budgets, and STOP before SUB, after SUB, and before the writer.
