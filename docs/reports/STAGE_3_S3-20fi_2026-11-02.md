# S3-20fi: address64 RAX-base Dword store with signed disp32

## Scope

This bounded runtime slice admits only the six-byte unprefixed form
`89 80 id` (`MOV [RAX+sign-extended disp32],EAX`) with Qword address size
and Dword transfer width. Effective address is the pre-instruction full
RAX plus signed disp32 with wrapping u64 semantics. The store payload is
low32 of the same original RAX. One contiguous checked four-byte write is
performed; all GPRs and RFLAGS are preserved, and successful retirement
commits `A+6`.

## Static review evidence

Runtime source `2c54a0a` and host/JIT coverage `4098ac1` passed independent
Sol/high static review after the coverage fixes. The JIT regression binds all
six source bytes and site metadata for signed displacement boundaries. The
host fixture compares interpreter and native CPU/RAM state and covers
full-width RAX addressing, low32 store payload, neighboring-byte sentinels,
entry guards, architectural/backend errors and retry, canonicality,
address-range overflow, and callback STOP after commit without replay.

These are source-review findings, not executed results. No behavior tests,
builds, formatting, Cargo checks, or Python harness were run. Exact JIT and
host gates remain pending. Harness S3-34ct pins those identities and passed
separate Sol/high static review; its gates were not run. See the
[normative JIT contract](../specs/JIT_CONTRACT.md#s3-20fi-exact-address64-rax-base-dword-store-with-signed-disp32),

and [S3-34ct report](STAGE_3_S3-34ct_2026-11-02.md).
