# Stage 3 S3-33c: exact native NEG RAX

## Result

Added a separate uncached opt-in path for exact bare qword `NEG RAX`
(`48 F7 D8`). `S0_09NopNegRaxAdmission` is independent of the existing
INC-only and DEC-only admissions. Eager and demand-flags compile and dispatch
APIs are separately named; no shared cache route or default policy changed.

Lowering is exactly Read RAX, W64 constant zero, W64 `Subtract(0, RAX)` with
`FlagEffect::Arithmetic`, Write RAX, Commit. NEG consumes no old CF and
replaces a pending full flags result in the demand-flags candidate. No ISA,
IR-kind, emitter/helper ABI, or shared flags-mask change was made.

## Coverage

- Admission accepts bare `48 F7 D8`, rejects truncated/prefixed/narrow forms,
  other registers including R8, memory, NOT, and branches into the encoding.
  INC-only, DEC-only, and NOP-only admissions reject NEG.
- Lowering has an exact operation-order assertion. Compiler tests exercise eager
  and candidate branch compilation and guest PC-map boundaries.
- Host comparison uses the interpreter for full CPU state and retirement with
  RAX `0`, `1`, `u64::MAX`, signed extrema, and `0x10`, `0x11`, `0x100`; both
  incoming CF values; CF set iff the operand is nonzero; OF at `i64::MIN`; and
  preserved DF/non-arithmetic RFLAGS bits.
- Direct terminal NEG starts with all six arithmetic status bits deliberately
  opposite to the interpreter-computed NEG result, confirming a full overwrite.
- The host scenario covers pending CMP→NEG→JZ/JNZ, both branch outcomes, NEG
  followed by ADD, terminal NEG, candidate budgets 0 through 5, STOP before NEG
  after CMP, and budget/STOP immediately after NEG. Native execution retires
  all selected instructions without interpreter replay. The demand-flags PC-map
  witness observes an inadmissible pending-flags statepoint before the branch.
- Existing `demand_flags_candidate_materializes_on_stop_unsupported_and_helper_failure_exits`
  verifies that helper contract failures remain host errors; S3-33c does not
  change that shared emitter/helper path.
