# S3-20fh — Address64 RAX-base disp32 Dword load

## Реализация

Добавлен узкий checked-load профиль для exact unprefixed `8B 80 disp32` длиной 6 байт. Compiler metadata и отдельный `CheckedDwordLoad` byte whitelist допускают этот ModRM; block, IR и runtime site profiles разрешают RAX как базу только в этой длине и signed disp32 форме. Runtime source matcher связывает все байты displacement с decoded site. Общий typed-IR publisher и runtime helper используются без изменения их API.

Добавлены compiler/source-binding regressions для `i32::MIN`, `-1`, `0`, `1`, `i32::MAX`, каждого из четырёх байтов displacement, PC-map boundary `A+6`, forged base/address-size/operand-size metadata и близких запрещённых кодировок. Host regression сравнивает interpreter и published JIT на high-half RAX и проверяет zero-extension, независимость RCX/RBX и flags, ровно одно contiguous чтение четырёх байтов, retry после backend `MemoryError`, entry guards, #GP(13) без чтения, адресное переполнение и callback STOP без повторного чтения.
