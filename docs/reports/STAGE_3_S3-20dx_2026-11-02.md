# S3-20dx — address-size-32 RBP-base dword checked load with disp32

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `4a1d40c` adds only the exact seven-byte singleton
`67 8B 85 id` (`MOV EAX,[EBP+disp32]`) to the shared typed-IR Dword-load
path. The decoder-owned address-size-32 operand uses low32 EBP plus signed
disp32, wraps the sum modulo 2^32, and zero-extends the starting effective
address. A successful checked read transfers exactly four contiguous bytes,
writes EAX with zero-extension into RAX, and advances the guest instruction
boundary to `A+7`. A transfer beginning at `0xffffffff` proceeds contiguously
across the 4-GiB boundary; the address-size wrap applies to the starting
address, not each byte of the transfer.

The JIT source/site test uses eight representative signed disp32 values and
mutates each of the four encoded displacement bytes to verify that the bytes
remain bound to their site. This is not an exhaustive sweep of all 2^32
possible disp32 encodings. The bounded host fixture covers eight
`(disp32, low32 EBP)` tuples, each executed with low and high full-width RBP
values. It compares native and interpreter CPU state and RAM.
