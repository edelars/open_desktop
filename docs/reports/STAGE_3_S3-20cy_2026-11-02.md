# S3-20cy — exact address-size-32 dword checked-memory store

**Status:** bounded implementation slice; S3-20 and Stage 3 remain open.

Runtime commit `2ee1955` adds only the three-byte singleton `67 89 03`
(`MOV [EBX],EAX`) to the shared typed-IR dword-store path. The decoder-owned
address-size-32 access calculation zero-extends low32 RBX before canonical
checking. The host store uses the low 32 bits of RAX as the payload for one
checked four-byte write.
