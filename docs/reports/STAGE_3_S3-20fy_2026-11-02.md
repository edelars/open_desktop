# S3-20fy: Address32 RCX-base Dword store signed disp8 `67 89 41 ib`

## Scope and contract

This slice is limited to exactly four bytes `[67,89,41,ib]`: `MOV
[ECX+signext(disp8)],EAX`, with `67` as the only prefix, Dword data and
address sizes, RCX as the addr32 alias base, no index, scale 1, and one signed
8-bit displacement.

The starting effective address is
`zero_extend((original_ECX + sign_extend(ib)) mod 2^32)`. The complete
original RCX is preserved. Execution performs one contiguous checked
four-byte write of the low32 of the original RAX; other GPRs and RFLAGS are
preserved, and successful next RIP is `A+4`. Only calculation of the starting
address wraps at 32 bits: transfer bytes after `0xffffffff` continue above
4 GiB without bytewise wrap. Existing memory/backend faults, entry guards,
retries, and callback STOP without replay remain in scope.

The accepted form does not include RCX disp32, indexed SIB, other bases or
sources, or additional prefixes. Preserve adjacent supported source/site
forms, including the addr32 RCX singleton store `67 89 01`. An extra byte
after the four-byte form remains a trailing-byte negative; truncated sources
remain rejected.

## Shared host helper risk

The shared host helper `rcx_base_dword_store_contract` currently recognizes
the addr32 form only as exact singleton `67 89 01` and ignores displacement.
Implementation must either extend exact recognition and the EA formula for
`67 89 41 ib`, or isolate a helper for this exact form. Preserve S3-20fw,
S3-20fq, S3-20fs, and S3-20fu contracts. This dependency is a review focus;
no host behavior is claimed by this planning report.

## Planned acceptance identities

- JIT: `memory_load_v2::tests::ir_dword_addr32_rcx_disp8_store_binds_all_signed_source_bytes_to_its_site`
- Host: `tests::s3_20fy_addr32_rcx_disp8_dword_store_uses_wrapped_ecx_and_low_eax_payload`
- Harness JIT gate: `s3_34dj_ir_addr32_rcx_disp8_dword_store_source_binding`
- Harness host gate: `s3_34dj_host_addr32_rcx_disp8_dword_store_wrapped_ecx_and_low_eax_payload`
- Fail-closed self-test: `test_s3_34dj_addr32_rcx_disp8_dword_store_gates_are_pinned_and_fail_closed`

The JIT source/site gate should bind all 256 displacement bytes to the exact
instruction site, verify signed displacement metadata and the `A+4` boundary,
and reject forged fields and bidirectional source/site mismatches. The host
gate should distinguish wrapped ECX from full64 RCX, store the low32 RAX
payload in one contiguous checked Dword write, preserve architectural state,
and cover address wrap, guard/fault retry and STOP without replay. Keep exact
trailing-byte and truncated-source negatives.

Expected harness totals after integration are 298 gates (288 acceptance and
10 lifecycle), 316 local steps, and 133 self-test names. These are target
counts only; the implementation, harness, and totals have not been verified.
