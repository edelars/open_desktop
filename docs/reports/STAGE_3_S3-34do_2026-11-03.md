# S3-34do — bounded value-only reducer for one S3-34dn artifact

## Scope and status

This is a documentation-only plan for a profile-specific reducer over one
validated S3-34dn artifact for `67 89 04 24`. No reducer implementation,
independent review, execution, or real artifact run is included. Stage 3
remains partial.

The original artifact must first reproduce twice from its saved CPU/RAM state
with deterministic observations and the exact recorded mismatch signature.
If original replay returns `not_reproduced`, stop and produce no reduced
artifact. Candidate mutation may change only non-address GPR values and bytes
already present in the mapped fixture RAM. Preserve source/profile, RIP,
effective address, RSP, flags, seed/index provenance, RAM address map/layout,
and the complete write callback (address, width/count, and bytes).

Enumerate no more than 256 distinct candidates in a deterministic order. Each
candidate starts from reset state and is replayed twice. Acceptance requires
matching observations across both candidate repetitions, a comparator mismatch
string exactly equal to the original artifact's `mismatch` field, and a
strictly lower popcount over mutable GPR and RAM values than the current
accepted input.
Select the accepted candidate with the lowest popcount; resolve ties by fixed
lexicographic serialization order. This bounded search does not claim global
minimality. If no candidate passes, report no reduction and write no artifact.

## Validation boundary

The existing `classify_replay` validates only the original artifact: it
compares complete observations against those recorded in the artifact, so
changed candidates cannot be accepted through it. Candidate validation needs
a separate profile-specific comparator that checks repeated candidate
determinism, exact stable mismatch signature, and all preserved fields. Do not
use `classify_replay` for candidate acceptance and do not generalize this into
a replay/reducer framework.

Write a reduced artifact with create-only semantics only after a candidate
passes every condition and has a strictly lower mutable-value popcount. Never
replace the original or an existing reduced artifact. The planned reducer
self-check is a fail-closed acceptance gate using labeled synthetic data. It
must not run or reduce a real S3-34dn artifact, and synthetic evidence cannot
establish runtime mismatch behavior.
