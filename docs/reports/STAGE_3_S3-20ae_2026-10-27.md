# S3-20ae — RSP as qword MOV data and signed-disp32 SIB base

## Scope and implementation

Admitted only exact eight-byte singleton `48 8B/89 A4 24 id`: ModRM
`mod=10/reg=4/rm=4`, SIB exactly `0x24` (RSP base, no index, scale 1), signed
disp32 in source bytes 4..7, qword data and 64-bit effective address. The
decoded `MemoryOperand` and `access_address_48` remain the only address
authority. No global GPR predicate, pair/V3 profile, source storage capacity,
frame layout or ABI changed. Existing no-displacement and disp8 forms remain
distinct.

## Evidence

- Descriptor/direct V2/shared IR validation accepts both opcodes at disp32
  MIN/-1/0/MAX, preserves all eight source bytes and rejects partial windows,
  invalid SIB, prefixes and trailing bytes. Exact load sources differing only
  in byte 7 retain different metadata and decode to different displacements.
- Host direct V2/shared IR/interpreter parity compares full CPU and RAM state,
  callback address/count and retirement for loads/stores. Entry RSP plus the
  signed displacement is independently asserted to equal target 32; successful
  load writes a distinct RSP value, while store payload is all eight bytes of
  old RSP. Byte-7 variants produce actual callback targets `0x01000040` and
  `0x02000040` from old RSP 64.
- Current noncanonical RSP yields #SS with exact payload and no data callback
  or architectural commit. A canonical qword start at `u64::MAX-3` retains the
  address-overflow host error; injected backend errors remain host errors and
  preserve architectural state. The exact native IR source is covered by the
  ARM64/macOS x19 canary at success, budget guard and fault exits.
- Dispatcher partial windows 1..7 and malformed SIB/prefix forms have zero
  block execution and no data callbacks. The sequential case loads a
  noncanonical RSP through `[RSP+0]`, commits at RIP+8 under both budget-one
  split and callback STOP, then faults #SS on `[RSP]` after resume without
  repeating the first read. The mixed singleton→NOP→pair case checks native
  and interpreter retirement counters separately and resumes without replay.
  Exact store `48 89 A4 24 FF FF FF FF` writes the old RSP at address 32; its
  successful callback raises STOP, returning at RIP+8 with one native
  retirement and the full store committed.
