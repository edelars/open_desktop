# S3-40s. Конфигурация пустых профилей для обычного RUN

[Проба S3-40r](STAGE_3_S3-40r_2026-11-19.md) измеряла отдельную
копию цикла и шага. Здесь две пробы на `e31c105` сохраняют по одному
телу `run_configured` и `step_configured` в Rust. Константный
параметр выбирает конфигурацию для обычного `execute::run`.
Исполнение с заданными профилями идёт через общее тело со значениями
вызывающей стороны. Аргументы `StepRuntime` для обычного вызова совпадают
с исходными. Пробный бинарник также содержит точку входа, которая
передаёт обычный вызов по исходной цепочке в общий режим.

В первом варианте пустая конфигурация получается через выведенный
`Default`. Во втором она задана ассоциированной константой
`ExecutionProfiles::EMPTY`. Константа параметризована временем жизни
профиля. Общая обёртка использует ту же константу как основание
структуры и передаёт исходные 12 параметров. Остальные поля сохраняют
прежние пустые значения. Сравнения выполнялись внутри каждого
подписанного release-бинарника на локальном Apple ARM64, macOS
26.7.1 и Rust/Cargo 1.99.0.

## Измерения и проверка

В каждом наборе четыре процесса провели по восемь чередующихся пар
на последовательность. Во всех 256 зачётных интервалах пройден порог
45 мс. Минимумы составили 89.482 мс для `Default` и 86.111 мс для
константы. Стороны внутри пары используют одинаковое число проходов
по 2 400 замороженным входам S3-34a. Совпали полное состояние, RAM,
порядок обращений и выход по бюджету. Для каждого входа проверены
27 комбинаций бюджета и STOP. Время включает расходы `Instant`.
Каждая точка входа имеет свою раскладку машинного кода.

| Вариант | Последовательность | Исходный вызов, медиана нс | Проба, медиана нс | Медиана 32 отношений [мин., макс.] |
|---|---|---:|---:|---:|
| `Default` | Store then load | 360.118 | 382.554 | 1.063 [1.038, 1.150] |
| `Default` | Load then store | 362.695 | 384.423 | 1.060 [1.037, 1.071] |
| Константа | Store then load | 373.508 | 261.190 | 0.700 [0.673, 0.714] |
| Константа | Load then store | 375.944 | 263.235 | 0.699 [0.671, 0.710] |

`Default` оказался медленнее во всех 64 парах. В измеренном машинном
коде специализированный шаг вызывает метод `Default::default`.
С константой проба быстрее во всех 64 парах. В её прологе шаг
резервирует ещё 3 360 байт стека, у общего шага резерв 3 936 байт.
Измерения относятся к двум конфигурациям кода в пробных бинарниках
и двум фиксированным потокам. Константа выбрана для следующей
проверки с отдельными регистровыми, соседними и профильными
сценариями и сравнением размера машинного кода.
[ISSUE-521](../KNOWN_ISSUES.md#issue-521)
