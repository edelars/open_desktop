# S3-36b — bounded S3-14 branch/helper warm profile

**Status:** three local release runs completed for five accepted branch/helper
fixtures. The warmed FIFO dispatcher remained slower than the interpreter on
this narrow profile. This is partial S3-36 evidence; it does not cover memory
workloads or complete the Stage 3 performance gate.

## Scope and method

The `od-bench warm-branch-helper` command accepts only the exact five-case
S3-14 list and its recorded trace, bound by SHA-256. The list contains four
conditional-branch boundary fixtures plus `s3_14_live_through_helpers`; it
excludes the budget-only control. Fixture admission and the recorded
interpreter/JIT outcome and retirement checks happen before timing. The runner
uses one prewarmed FIFO16 runtime and verifies cache-hit-only timed dispatcher
samples. Interpreter and dispatcher samples use the same work, alternate order,
and are calibrated to a shared sweep count. State reset and result validation
are outside timed calls.

The fixture set is branch/helper evidence only. It contains no memory access,
fallback, code invalidation, or resource-churn workload and cannot be used to
claim coverage for those paths.

## Results

The time values below use each report's integer-nanosecond
`median_ns_per_sweep`, for one five-case sweep. Each paired ratio is the median
of its report's `paired_interpreter_over_fifo_ratios` array; both variants in
each pair use the same sweep count.

| Variant | Run 1 (µs/sweep) | Run 2 | Run 3 | Median across runs | Range across runs |
|---|---:|---:|---:|---:|---:|
| FIFO(16) warm branch/helper dispatcher | 3.959 | 3.736 | 3.945 | 3.945 | 3.736–3.959 |
| Interpreter | 0.750 | 0.726 | 0.751 | 0.750 | 0.726–0.751 |
| Paired interpreter/FIFO elapsed ratio | 0.188420 | 0.192660 | 0.190055 | 0.190055 | 0.188420–0.192660 |

The interpreter was about 5.3× faster on this five-case profile. This is a
bounded result for these fixtures and timing boundaries; it does not predict
other guest programs or workloads.

Each run's prewarm recorded five misses, compiles, and publications with zero
evictions. All measured FIFO samples recorded hits and zero miss/compile/
publication/eviction deltas.

## Verification and limits

The implementation passed `cargo fmt -p od-bench -- --check` and
`cargo check -p od-bench --all-targets --offline`. Three release runs were
collected. Host power, thermal, and background-load telemetry was not recorded.
No Mini/physical x86 or Stage 2 checks were run.

The fixture profile does not measure memory execution, fallback frequency,
production RAM ownership, RSS/lifecycle, or resource churn. S3-36 remains
partial; broader Stage 3 acceptance is separate.
