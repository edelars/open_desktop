## Scope and method

The `od-bench warm-branch-helper` command accepts only the exact five-case
S3-14 list and its recorded trace, bound by SHA-256. The list contains four
conditional-branch boundary fixtures plus `s3_14_live_through_helpers`; it
excludes the budget-only control. Fixture admission and the recorded
interpreter/JIT outcome and retirement checks happen before timing. The runner
uses the existing resident FIFO16 warm path: deterministic entry-budget
selection, one retained FIFO runtime, hit-only timed dispatcher samples, and
alternating calibrated interpreter/dispatcher samples. The report will retain
raw paired timings, counters, timer scope and both input hashes. The existing
S3-17 `warm-first-run` profile remains frozen to its original full corpus.

The fixture set is branch/helper evidence only. It contains no memory access,
fallback, code invalidation, or resource churn workload and cannot be used to
claim coverage for those paths.
