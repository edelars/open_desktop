# S3-20ek — exact address-size-32 ESP-base dword store with signed disp32

## Scope

S3-20ek admits only the exact eight-byte singleton `67 89 84 24 id`
(`MOV [ESP+disp32],EAX`) through the shared typed-IR checked-store path. It
uses ESP as the SIB base, no index, scale 1, and a signed 32-bit displacement.
The effective address is `(low32(RSP) + sign_extend(disp32)) mod 2^32`, then
zero-extended. High RSP bits do not participate. A successful checked write
stores low32 RAX in four contiguous bytes and advances RIP to `A+8`; a span
starting at `0xffff_fffe` continues above 4 GiB rather than wrapping each byte.
