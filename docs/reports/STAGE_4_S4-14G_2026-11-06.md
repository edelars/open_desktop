# S4-14g: MOV CR3 with CR0.WP=0/1 in the diagnostic session

**Date:** 2026-11-06  
**Scope:** separate opt-in CPU MOV CR3 profile and feature-gated mutable-session
integration. Parent S4-14 and Stage 4 remain open.

## Behavior

`MovCr3WpLong64V1` / `step_mov_cr3_wp` admits only the exact bare `0F 22 D8`
(`MOV CR3,RAX`) form for CR0=`0x80010033` or `0x80000033`. CR4=`0x20`,
EFER=`0xd00`, Long64, one vCPU, canonical48/physical36, four-level 4 KiB
paging, running state and clear interrupt shadow remain fixed. The existing
`MovCr3Long64V1` / `step_mov_cr3` remains WP=1-only. Both entries share the
existing fetch, privilege, reserved-bit, commit and typed `Cr3Write` behavior.

`MutableTranslationProbeSession::execute_mov_cr3_wp` validates CPU
CR0/CR3/CR4 against the session snapshot before fetch. Fetch uses the pure
walker and bypasses the resident entry. A valid single retired `Cr3Write`
installs a validated replacement snapshot and clears the capacity-one cache
synchronously, including same-value writes. An unexpected post-retirement CR4
value, malformed effects, retirement-count mismatches and invalid replacement
snapshots clear and poison the session. A contradictory nonzero-retirement
result without `Cr3Write` returns a typed error and poisons; a zero-retirement
fault preserves the cache. The injected post-retirement CR4 mismatch test keeps
CR0 equal to the session snapshot and verifies clear plus poison. Fetch faults
preserve CPU/session snapshot and cache.

## Coverage and limits

Coverage includes both WP values; legacy WP=1-only admission; root A→B with a
resident hit, synchronous empty cache, then Walk→Hit on B; same-value CR3 after
a user-accessible read-only PTE remap; after same-value invalidation, Ring0
write succeeds at WP=0, WP=1 receives exact PFEC `0x03`, and WP=0 Ring3
receives exact PFEC `0x07`; matching stale Fetch-key bypass and exact fetch #PF with zero
retirement and unchanged CPU/cache; unchanged four page-table entries across
successful fetch/effect consumption; unusable replacement root deferred to the
next probe; CR3 source bits 36–63 rejected atomically; and session pre-state
mismatch, zero-retirement cache preservation, contradictory retirement poison,
and fail-closed post-retirement CR4 mismatch with matching CR0. Existing shared
MOV CR3 tests retain LOCK/CPL/fetch/prefix and legacy-path regression coverage.

This remains a bounded one-vCPU diagnostic cache experiment, not a production
TLB. Reset, EFER/other CR transitions, tracked A/D caching, PCID/global
semantics, JIT integration, SMP and performance are outside scope. Full S4-14
remains open.
