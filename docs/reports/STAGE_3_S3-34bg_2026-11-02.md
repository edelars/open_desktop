# S3-34bg — exact harness gates for S3-20dv addr32 RBP disp8 dword load

**Status:** bounded harness slice; S3-34 and Stage 3 remain partial/open.

Integrated harness commit `40876a7` adds mandatory exact gates for the
committed S3-20dv address-size-32 RBP-based dword load:

- `od-jit --lib`: `memory_load_v2::tests::ir_dword_addr32_rbp_disp8_load_binds_all_signed_source_bytes_to_its_site`
- `od-host --lib`: `tests::s3_20dv_addr32_rbp_disp8_dword_load_preserves_checked_state`

The gate commands are:

```text
cargo test --offline -p od-jit --lib memory_load_v2::tests::ir_dword_addr32_rbp_disp8_load_binds_all_signed_source_bytes_to_its_site -- --exact --test-threads=1
cargo test --offline -p od-host --lib tests::s3_20dv_addr32_rbp_disp8_dword_load_preserves_checked_state -- --exact --test-threads=1
```

Both exact Rust gates passed 1/1. The source/site JIT test binds all 256
encoded disp8 values to distinct identities. The bounded host fixture checks
the two signed edges (`-128` and `+127`) for low and high RBP values; it does
not repeat all 256 displacement cases. The harness pins only these two
identities. It does not add a separate PC-map gate or make an address-size-64
RBP `#SS` claim.
