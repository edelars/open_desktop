# S3-20ev: exact addr32 scaled RCX-indexed no-base SIB disp32 Dword loads

## Scope and semantics

This runtime slice admits only the exact eight-byte Dword-load singletons
with exactly the `67` address-size override prefix and no other prefixes:
`67 8B 04 4D disp32`, `67 8B 04 8D disp32`, and
`67 8B 04 CD disp32` (`MOV EAX,[ECX*2|4|8+disp32]`). The address-size-32
SIB has no base and uses ECX as its index at scale 2, 4, or 8. The effective
address is `zero_extend((low32(RCX)*scale + signed_disp32) mod 2^32)`. Each
checked read is one contiguous four-byte access, including the recorded
4-GiB crossing. EAX zero-extends into RAX; other GPRs and RFLAGS are
preserved, and the guest instruction boundary is `A+8`. Other prefixes,
scales, SIB shapes, and encodings remain outside this exact admission.

The exact JIT fixture is
`memory_load_v2::tests::ir_dword_addr32_rcx_index_no_base_sib_scaled_disp32_load_binds_all_source_bytes_to_its_site`.
The exact host fixture is
`tests::s3_20ev_addr32_rcx_index_no_base_sib_scaled_disp32_dword_load_uses_wrapped_scaled_ecx`.
Harness S3-34cg pins both identities.
