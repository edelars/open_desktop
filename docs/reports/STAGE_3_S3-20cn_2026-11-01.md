# S3-20cn — exact dword checked-memory load

**Status:** bounded implementation slice committed; S3-20 and Stage 3 remain open.

Commit `542b5b71f33bdfb114111d874b7f909204478ae6` adds the exact unprefixed
`8B 03` form (`MOV EAX,[RBX]`) through the checked-memory shared-IR path. The
profile is limited to this single instruction: it performs one four-byte read
and writes EAX with the architectural zero-extension into RAX. It does not
establish wider dword memory lowering, other address forms, or a general memory
compiler.
