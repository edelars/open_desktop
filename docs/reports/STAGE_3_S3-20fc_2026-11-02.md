# S3-20fc: address32 RAX-indexed no-base SIB Dword store

## Scope

This runtime slice adds one exact shared typed-IR Dword-store profile: the
eight-byte form `67 89 04 05 disp32`
(`MOV [low32(RAX)+sign-extended disp32],EAX`). Address size is Dword; SIB has
no base, RAX index and scale 1; transfer width is Dword. The effective
address is
`zero_extend_64((low32(original RAX) + sign-extended disp32) mod 2^32)`;
the stored payload is low32 of that same original RAX. A contiguous checked
four-byte write commits once and successful retirement advances to `A+8`.
The effective address wraps at 32 bits, while the bytes of the transfer remain
contiguous after the starting address.

The runtime change is integrated at `3de12be`. It expands the bounded shared
typed-IR store matcher for this exact profile and adds JIT source/site and host
fixture gates. The
[normative JIT contract](../specs/JIT_CONTRACT.md#s3-20fc-exact-address32-rax-indexed-no-base-sib-dword-store)
records the admitted shape and behavior.

## Static review evidence

Independent Sol/high static review passed. Static source inspection covered
the exact eight-byte source form, original low32 RAX for address and payload,
source/site and displacement-byte identity, high-half truncation, signed
displacements, 32-bit address wrap and contiguous dword writes near the 4-GiB
boundary. The host fixture source compares native and interpreter state/RAM
and contains pre-entry guard retries, backend-error no-commit/retry, and
callback STOP commit/no-replay cases.

These are review observations, not executed results. No behavior tests,
builds, formatting, Cargo checks, Python harness, or machine smoke were run.
Exact JIT/host gates remain pending. Harness S3-34cn pins the gate identities;
its static review passed after a count-assertion correction, but the harness
