# S3-30d strict dead-home reuse preflight

The signed ARM64 release passed all five native fixtures against the
interpreter on M3 Max and M1 Pro. Both allocator variants matched the full
guest state, retired count, budget and expected native exit on each fixture.
The pressure fixture also passed 28 STOP-RIP and budget continuation checks.
The normal eager FIFO16 sweep recorded five misses, compilations and
publications and 14 guest retirements. [S3-30c allocator census](STAGE_3_S3-30c_2026-11-20.md)

The experimental variant releases a register home when the previous value's
last use precedes the next definition. It chooses the lowest available home
from x9 through x12. Each temporary retains a fixed location, and the baseline
helper boundary plan determines which live values need capture. The
experimental compiler is gated by `s3-30-dead-home-candidate` and uses eager
flags for this preflight.

Each of the four branch controls emitted 1,112 bytes in both variants and
used a 192-byte frame and four static allocator transfer sites. The counts
describe the emitted code. The trace counts block visits, so instruction-level
transfer execution counts remain unknown. This preflight has no scored
timing. The allocator comparison still requires independent compile and
warm direct-entry measurements.
