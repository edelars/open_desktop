# Stage 3 S3-20ax report

## Scope and implementation

Added one bounded qword singleton profile: `67 48 8B/89 /r sib disp32`, with ModRM `mod=00,r/m=100`, SIB base field `101` (no base), index RAX..RBX, scale 1/2/4/8, and data RAX..RBP. The instruction is exactly nine bytes, uses Dword effective-address arithmetic, and transfers a Qword. It remains distinct from 64-bit indexed no-base S3-20aw and address32 absolute no-index S3-20av. No pair/V3, owner/MMU, Stage 2, or ISA changes were made.

Compiler admission, shared IR descriptors, host publication metadata, runtime validation, and the bounded dispatcher accept the same exact profile. Effective-address semantics remain owned by the decoded `MemoryOperand` and `access_address_48`: the low 32 bits of the index are scaled, the signed displacement is added modulo 2^32, and the result is zero-extended before one contiguous qword access. Runtime matching validates fixed source shape and decoder metadata from the immutable artifact; it does not re-decode displacement bytes.

## Evidence

- The JIT descriptor matrix covers loads and stores, all six data registers, four index registers, all scales, and disp32 MIN/-1/0/1/MAX. It verifies exact metadata, descriptor parity, and rejects unsupported RBP index/prefix/direct forms and partial windows 1..8.
- The host matrix compares direct V2, shared IR, and interpreter CPU/RAM state, callback addresses/counts, and retirement. It checks an independent low32 EA formula with nonzero high index halves, `data=index` pre-state behavior, full-width payloads, and two immutable artifacts whose ninth byte changes the computed target.
- Qword access at `0xffff_ffff` is checked as one contiguous callback. Architectural and backend failures preserve CPU/RAM state and carry the expected callback identity; a successful store followed by STOP remains committed exactly once.
- Dispatcher coverage runs the nine-byte singleton, NOP fallback, then the existing pair. Budgets 0..4, split continuation from actual RIP without replay, partial windows 1..8, and an unsupported RBP-index SIB neighbor are covered.
- Earlier negative fixtures that used SIB `0x05`, `0x0d`, or another now-valid low-index no-base form were changed to the unsupported RBP-index SIB `0x2d`; prior 20aw/20av behavior remains tested.
