# S3-20eq: exact RCX-indexed no-base SIB disp32 Dword store

## Scope and semantics

This runtime slice admits only the exact unprefixed seven-byte singleton
`89 04 0D disp32` (`MOV [RCX+disp32],EAX`): address64, SIB without a base,
RCX index at scale 1, and a Dword transfer. The decoder-owned effective
address is the full-width RCX plus sign-extended disp32 with wrapping u64
arithmetic. One checked contiguous four-byte write stores the low 32 bits of
RAX, and the guest instruction boundary is `A+7`. Neighboring prefixes and
SIB forms remain outside this exact admission.

The exact JIT fixture is
`memory_load_v2::tests::ir_dword_rcx_index_no_base_sib_disp32_store_binds_all_source_bytes_to_its_site`.
The exact host fixture is
`tests::s3_20eq_rcx_index_no_base_sib_disp32_dword_store_uses_signed_displacement`.
The fixtures were not executed for this slice; their exact harness identities
are pinned by S3-34cb.
