# Stage 3 S3-20bo: address32 indexed SIB with RSI/RDI base and RBP index

## Scope

This slice admits only singleton `67 48 8B/89 /r sib [disp8|disp32]`: ModRM `mod=00/01/10,r/m=100`, SIB base RSI or RDI, index exactly RBP, scale 1/2/4/8, data RAX..RBP, and instruction lengths 5/6/9. Address calculation is decoder-owned through `MemoryOperand::access_address_48`: `(low32(old_base) + low32(old_RBP) * scale + signed displacement) mod 2^32`, then zero-extension. The transfer and source data remain full qword; RSI/RDI bases are preserved, RBP is read as an index from pre-state, and a successful load to RBP commits only after the memory access succeeds.

This is a bounded fixture/uncached dispatcher profile. It does not add production owner/MMU integration, broaden the generic register whitelist, or change Stage 2, `od-isa`, pair/V3 admission, Mini, or performance scope.

## Evidence

- The `od-jit` descriptor matrix covers loads and stores for both bases, all six data registers and four scales, mod00 and signed disp8/disp32 boundaries. It checks decoded metadata and direct V2/shared IR admission, rejects neighboring encodings, and rejects partial windows.
- The host matrix compares direct V2 and shared IR with the interpreter for full CPU/RAM state, the independently calculated low32 target, callback address/count, and retirement. High halves of RSI/RDI/RBP are nonzero; `data=RBP` cases use its pre-instruction qword.
- Host cases verify a contiguous qword callback from `0xffff_fffc` across the 4 GiB boundary, 32-bit scale-product wrap (`low32(RBP)=0x8000_0001`, scale 8, disp8 -1 => EA `0x1007`) with RBP as the load destination, and distinct targets for fixed-register disp32 forms that differ in the final displacement byte.
- Architectural and backend failures cover load and store with no CPU/RAM commit and exact callback identity. Additional cases cover successful store+STOP, entry STOP, zero budget, partial windows 1..8, and dispatcher continuation across 5/6/9-byte forms from actual RIP without replay.
