# ADR-0015. Объём этапа 2 для этапа 8 (решения владельца 2026-11-22)

Статус: принято владельцем (пункты 1–6 — по ответам владельца; пункты 7–9 — по рекомендации, которую владелец поддержал).

## Решения

1. **Объём переписан.** Пункты плана этапа 2, которые загрузка Windows 11 на стенде этапа 8 не требует, переносятся в следующий этап. Родители, которые не проходят по новому объёму, закрываются только после выполнения своего нового объёма.
2. **S2-40 — базовая линия x86-64.** В объёме: SSE2…SSE4.2, POPCNT, CMPXCHG16B, LAHF/SAHF, PREFETCHW, SYSCALL/SYSRET, CRC32. Вне объёма (перенос): AVX/AVX2/AVX-512, BMI1/BMI2, AES-NI, PCLMULQDQ, SHA, XSAVE и остальные семейства из статической инвентаризации.
3. **CPUID-бит** объявляется только для реализованной и принятой задачи. До реализации бит равен 0.
4. **LM — длинный режим без режима совместимости.** WOW64 (32-битные приложения) — перенос в следующий этап.
5. **32-битный исполнитель над GuestMemory.** Охват определяется путями, которые реально исполняются при загрузке Windows на стенде. Полный исполнитель — перенос.
6. **FCS/FDS для выполненных x87-инструкций.** Эталон — целевой N5105 (селекторы сохраняются как 0000H). Расхождения с oracle на i5-3210M записываются явно.
7. **MASKMOVDQU с частичной маской.** Ограничение ISSUE-649 принято для этапа 8; контракт маскированной записи в GuestMemory — перенос.
8. **S2-32.** В объёме: написания FSTENV/FSAVE с префиксом FWAIT (9B). Перенос: 16-битные образы (префикс 66) и #MF для ожидающих исключений.
9. **S2-39.** В объёме: общие SSE/SSE2-формы в наборе CPL3. Перенос: JIT, #AC, MOVNTQ, MASKMOVQ. `#AC` перенесён в [ADR-0023, решение 4](ADR-0023-cpl3-execution-model.md#решение-4-ac-и-невыровненный-lock-моделируются-архитектурно) и реализован срезом C1 S7-32 (2026-11-27): требование выравнивания передаёт исполнитель по Table 7-7, [CPU_CONTRACT](../specs/CPU_CONTRACT.md#классификация-cpl3-adr-0023-срез-c1).

## Биты Windows-профиля

- Объявляются по мере приёмки задач-владельцев. SSE, SSE2, FXSR и MMX — после приёмки S2-39 в новом объёме.
- FPU, MSR, SYSCALL и LM объявляются после приёмки S2-28…S2-32, S2-26, S2-27 и S2-24 соответственно.

## Последствия

- Родители S2-32, S2-39 и S2-40 отмечаются только после выполнения их нового объёма и приёмки владельцем.
- Перенесённые пункты остаются в плане с пометкой «перенос: следующий этап» и не блокируют этап 8.
