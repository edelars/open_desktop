# Публичная host ABI

- `open_desktop/` — единый публичный C ABI между macOS-оболочкой и Rust-движком.
- Заголовки должны описывать версии, opaque handles, размеры/типы данных, владение памятью, ошибки и допустимые потоки вызовов.
- Здесь не размещать внутренние Rust-структуры, guest driver headers или wire formats.
- Не передавать через ABI Rust `String`, `Vec`, Swift objects и layout без заданного контракта.
- Реализации остаются в `crates/od-host/` и соответствующих библиотеках; протоколы сообщений — в `protocols/`.
- Не создавать фиктивный header до определения реального ABI.
