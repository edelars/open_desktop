Статус: **ни один сценарий не проверялся.** Windows в нашей VM пока не запускалась ([отчёт этапа 8](../../docs/reports/STAGE_8_REPORT.md)); все строки ниже — «не запускается» с пометкой «не проверялось». Строки заведены задачей S8-02 [плана этапа 8](../../docs/plans/STAGE_8.md); результаты пополняют задачи S8-24…S8-63. Методика доказательств — [WINDOWS.md](../../docs/testing/WINDOWS.md).

## Статусы

| Статус | Условие |
|---|---|
| не запускается | Сценарий не прошёл какую-либо фазу или ещё не проверялся (во втором случае в таблице стоит пометка «не проверялось») |
| запускается с ограничениями | Фазы пройдены с nonce-маркером текущего прогона, но есть записанное ограничение (производительность, часть функций, нестабильность); ограничение указано в отчёте |
| проходит приёмку | Сценарий пройден по критерию задачи без обходов, с маркером текущего nonce, хешами входов и ссылкой на отчёт |

Правила заполнения:

- Статус выше «не запускается» ставится только вместе с run-id, датой и ссылкой на отчёт; без run-id — только «не запускается».
- Результат, полученный с обходом ([WINDOWS.md](../../docs/testing/WINDOWS.md) §4.2: `LabConfig`, отключённый Secure Boot, удалённый TPM, `testsigning`, `nointegritychecks`, подмена файлов носителя), в статусе «проходит приёмку» не записывается; он описывается в отчёте как прогон с обходом.
- Artifact приложения — с SHA-256 издателя из [SUPPORT_MATRIX.md](../../docs/specs/SUPPORT_MATRIX.md). Это эталонный хеш; перед прогоном локальный файл сверяется с ним, а фактический хеш записывается в `run.json`.
