# Межкомпонентные проверки

- `cpu/` — наборы сценариев корректности CPU/JIT. `system/` — RAM/MMU/devices/boot/snapshots. `compat/` — проверка ОС и приложений. `fixtures/` — небольшие собственные входные данные с происхождением.
- Локальные unit tests хранятся рядом с кодом; эти каталоги не означают, что Cargo автоматически исполняет все лежащие здесь сценарии. Подключение реального harness должно быть явным.
- Общий testing-код — в `crates/od-testkit/`; исполняемые runners — в `tools/`.
- Не переносить production-реализацию в тесты и не использовать общий ошибочный helper как единственное доказательство корректности.
- Для x86 сверять только архитектурно определённое состояние и записанный профиль. Чужой эмулятор не заменяет физический oracle.
- Не добавлять тесты, утверждающие наличие ещё не реализованной функции. Не хранить установочные ISO, большие диски, чужие данные и секреты.
