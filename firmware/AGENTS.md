# Собственная firmware

- `uefi/src/` — собственная UEFI-реализация, таблицы ACPI/SMBIOS и необходимый freestanding код. `uefi/include/` — внутренние заголовки; `uefi/tests/` — локальные проверки.
- Это guest-target код с отдельной сборкой. Не подключать его в host workspace и не использовать Foundation/host std в firmware.
- OVMF/EDK II/SeaBIOS, их исходники и таблицы не копировать. Реализация собственная по зафиксированным спецификациям.
- Обзор требуемой виртуальной платформы — в `docs/specs/`; код предоставления интерфейса — здесь; модели host-устройств и RAM — в `crates/od-machine/`.
- Явно фиксировать boot entry, CPU state и поддерживаемый набор services. Не объявлять полный UEFI только по работающему загрузочному примеру.
- Собственное TPM-устройство на host не размещать в firmware: firmware использует описанный интерфейс устройства.
