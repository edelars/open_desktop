# od-testkit

Собственные инструменты проверки корректности.

Генерация входов, сравнение состояний и минимизация ошибок. Используется runners и проверками, не production runtime. Не заменяет независимое исполнение на физическом x86.

Статус: только каркас библиотеки; функциональность отсутствует. Читать ../AGENTS.md и ../../docs/PROJECT_LAYOUT.md перед реализацией. Зависимости добавлять вместе с фактическим использованием.
