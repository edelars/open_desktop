# od-storage

Хранение дисков и сериализация состояния.

RAW, будущий собственный CoW и формат контейнера снимка. Не управляет vCPU: согласованную остановку и сбор состояния организует od-machine. Rust layout не является дисковым форматом.

Статус: только каркас библиотеки; функциональность отсутствует. Читать ../AGENTS.md и ../../docs/PROJECT_LAYOUT.md перед реализацией. Зависимости добавлять вместе с фактическим использованием.
