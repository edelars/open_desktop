# od-tpm

Процессор команд vTPM 2.0: чистая логика без шины, MMIO, потоков, файлов, ОС-часов и ОС-энтропии (решение D8, [ADR-0009](../../docs/decisions/ADR-0009-vtpm-placement-and-crypto.md)).

Принимает байты команды, locality и время от владельца, возвращает байты ответа; ошибка гостевой команды — ответ с `TPM_RC`, не host-ошибка. Состояние делится на persistent (кодек snapshot `ODTPMSTA` v2 — чувствительные данные, см. VTPM.md) и volatile. CRB-устройство и выдача байтов state host-стороне — `od-machine` (S7-22).

Статус: фаза A (S7-21) — Startup/Shutdown, SelfTest, GetCapability, GetRandom/StirRandom, PCR (банк SHA-256, 24 PCR), Hash и hash/event sequences, ReadClock, password session. Фаза B, срез A (S7-23) — иерархии (Platform/Owner/Endorsement/Null, Lockout-авторизация): HierarchyControl/ChangeAuth, Clear/ClearControl; HMAC-сессии: StartAuthSession (unbound/bound к иерархии), FlushContext; база NV: DefineSpace/UndefineSpace/ReadPublic/Write/Read/WriteLock/ReadLock. Всё остальное отвечает `TPM_RC_COMMAND_CODE`.  Контракт, границы и список не сверенных мест — [docs/specs/VTPM.md](../../docs/specs/VTPM.md). Соответствие и сертификация TCG не заявляются. Фаза B, срез B (S7-23) — объекты и ключи RSA-2048/ECC P-256: CreatePrimary (детерминированный вывод из seed иерархии и шаблона), Create, Load, LoadExternal (только публичная часть), ReadPublic, Unseal (sealed data), EvictControl (persistent-объекты, пока только в памяти), Sign (RSASSA, ECDSA), VerifySignature; модули `object.rs`, `object_cmd.rs`; `outPrivate` защищён по формулам Part 1 с AES-128-CFB (`aes`, `cfb-mode`), приватный RSA — `rsa` без constant-time (ISSUE-064). Фаза B, срез C1 (S7-23) — RSA_Encrypt/RSA_Decrypt (RSAES, OAEP SHA-256, NULL), ECDH_ZGen, защита от подбора (DA: DictionaryAttackLockReset, DictionaryAttackParameters; `lockoutAuth`), snapshot `ODTPMSTA` v2 с auth иерархий, NV и persistent-объектами; модули `asym.rs`, `da.rs`, `snapshot.rs`. Snapshot содержит секреты в открытом виде (защита — S9-27). Policy-сессии, шифрование параметров, EK, контексты, Quote/Certify/GetTime, TPM2_HMAC — срез C2, не начат.
