# Инструменты разработчика

- `runner/` — headless запуск собственной машины/CPU на host.
- `x86-runner/` — независимое исполнение допустимых тестов на физическом x86.
- `image-tool/` — проверка/создание/восстановление собственного дискового формата.
- `build/` — объединение штатных toolchains, собственная генерация и упаковка.
- `bench/` — launchers и обработка измерений; временные данные — в `work/`, долговечные доказательства — в `docs/reports/data/`.
- `check_layout.py` — лёгкая проверка структуры репозитория; не превращать её в framework или универсальный linter.
- Исполняемый runner вызывает библиотеки; не копировать сюда decoder, interpreter, MMU и disk semantics.
- Инструменты не добавлять в корень. Новый Rust binary включать в Cargo workspace только после создания реального manifest/target.
- Python orchestration использует стандартную библиотеку. Не добавлять зависимости для простого чтения файлов и запуска штатных инструментов.
- Любые замеры должны сохранять вход, окружение, режим сборки и сырые значения. Не генерировать вымышленные benchmark results.
