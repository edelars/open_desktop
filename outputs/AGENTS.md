# Готовые deliverables

- Здесь размещаются подготовленные пользователю сборки, экспорты и отчёты для передачи.
- Исходный документ проекта хранится в `docs/`, исходный код — в назначенном компоненте. Копия в outputs не становится вторым источником истины.
- Сборочный scratch и промежуточные трассы размещать в `work/`, Cargo outputs — в `target/`.
- Generated deliverables по умолчанию не версионируются. Нельзя публиковать подписи, приватные ключи, образы ОС и пользовательские данные вместе с результатом.
