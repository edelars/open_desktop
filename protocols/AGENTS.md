# Межпроцессные и гостевые протоколы

- `control/` — launcher/UI ↔ VMHost. `guest/` — host ↔ guest agent/driver. `schemas/` — машиночитаемые собственные схемы только при реальной необходимости.
- Это нормативное место wire format. `docs/specs/` содержит контекст/ссылки, а не вторую независимую спецификацию тех же байтов.
- Описывать версию, порядок байтов, длины, ограничения, ID запросов, ошибки, повтор, разрыв соединения и совместимость.
- Публичный внутрипроцессный C ABI размещать в `include/`, не здесь.
- Генераторы собственных схем — в `tools/build/`; производный код не редактировать вручную и не считать первичной спецификацией.
- Не добавлять сторонний RPC/serialization framework и не строить универсальный протокол до появления реального потребителя.
